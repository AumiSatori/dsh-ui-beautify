# dsh-UI美化

显示名称为 **dsh-UI美化**。内部包名、安装链接和本机偏好键继续使用 `dsh-claude-beautify`，以兼容已有安装和展示选择。

为 DeepSeek Harness 提供受 Claude 桌面版启发的右上角会话侧卡，展示进度、输出和本次使用的工具与资源，并为底部输入栏提供可独立选择的玻璃样式。

面板入口位于**当前聊天列**右上角，直接复用 DSH 宿主的官方 `FishLogo` 组件，与数量或步骤提示一起显示。入口高度为 **24 CSS px**，和截图中的紧凑页眉按钮保持一致；文字固定为 13px、行高 18px，Logo 宽 16px 并保留官方比例，避免继承宿主大字号后撑高。空闲时默认收起，**鼠标悬停入口即可下拉展开，无需点击**。悬停预览在移出入口和卡片 220ms 后开始收起，经过 **180ms 渐隐、轻微上移和向上收合**后移除；跨过入口与卡片的间隙或返回卡片会取消收起，退场途中返回也会从当前画面平滑恢复，保留原卡片和缩略图。键盘焦点位于卡片内时会保持显示。点击入口可固定展开，再次点击、关闭按钮或 Escape 可收起；触屏和键盘保留点击操作。

**悬停预览或手动打开的面板，点击外部聊天区、空白处或其他控件时，会用 180ms 退场动画收起。安排任务步骤时自动展开的面板只能点 X 关闭**；点击外部、再次点击入口、移开鼠标或按 Escape 都保持展开，任务结束也不自动解除这一状态。同一聊天右侧的轮次导航及设置中的卡片样式选择区仍保持卡片打开。外部点击照常执行，不拦截事件、不把焦点拉回入口；面板内的栏目开合和文件预览不受影响。外部收起不会修改已保存的模块开合偏好。

**只有安排任务步骤时才自动展开**：运行过程中，任务清单从无到有，或步骤文字、顺序发生变化时，面板会下拉并保持显示，直到点 X 才收起。普通推理开始、工具调用、文件交付和仅更新步骤完成状态都不触发展开，打开旧会话也不因已有任务或输出自动弹出。本轮点 X 关闭后不再反复弹，下一轮实际安排步骤时才重新展开。有内容时才出现入口。

悬停预览与点击/排步骤的保持展开状态分别处理；悬停不会改写各会话的保持展开状态，切换会话会清理预览及待收起计时。卡片材质、细边框与布局参考 Claude 桌面版，支持深色主题和窄屏自适应。

**同一聊天滚到哪一轮，卡片就展示那一轮的任务、输出和已用资源**，也跟随右侧轮次导航。查看历史轮次时入口显示“第 X 轮”，任务使用该轮最后记录的清单，不混入其他轮次的文件或工具。后台正在进行的新计划不会替换所看的历史内容，也不会把已收起的历史卡片自动打开。返回最新轮次后恢复实时进度。

卡片打开时切换轮次，内容通过 **280ms 渐隐渐显、上下位移和 2–3px 模糊过渡**完成交接，条目略微错开进入，卡片高度同步平滑伸缩；快速切换会取消过期动画，最终显示最新选择。没有任务、输出或资源的轮次会保留已打开的卡片并显示空状态；记录缺失则提示“本轮记录尚未完整加载”。切换不会改写三个栏目及先前/后续步骤的开合偏好，减少动态效果或强制颜色模式下直接切换。

工作时入口显示“第 X 步，共 Y 步”，随当前任务更新。进度区统一使用 8px 小圆点：已完成为灰色实心，进行中为黑色实心，待处理为灰色空心；已完成和待处理文字统一灰色，进行中文字加深为黑色，并使用 700 字重加粗。全部完成后末步也保持灰色实心，不再单独放大或显示对勾。深色主题下进行中改用亮色，其他步骤保持灰色，维持相同的突出层级。

步骤圆点之间使用细灰色实线连接，“先前步骤”和“后续步骤”入口及相邻连接段使用虚线，收起更多步骤时仍可看出前后延续关系。连线随每行实际高度伸缩，支持长文字换行和步骤折叠动画，并在圆点及进行中弧光周围留出间距；没有对应折叠组时，首尾不额外延伸。深色主题同步调整连线颜色。

运行中当前步骤使用**稳定实心核心 + 单条黑色圆头旋转弧线 + 向外扩散的圆形光环**：旋转弧线约 130 度，不再附带灰色旋转弧线，深色主题随当前状态改为亮色。圆点、弧线和光环都由 SVG 圆形绘制，弧线两端使用圆头，避免角度渐变截口产生棱角；三个状态的核心外径均为 8px。外弧每 1.35 秒一圈，光环每 1.9 秒扩散一轮，核心保持不透明、不闪烁，也不改变文字和行的布局。文字保留从左向右扫过的柔和白光，每 2.4 秒一轮。动画只出现在运行中会话的进行中条目上，任务完成或会话停止运行后恢复静态圆点和文字；已完成及待处理条目不生成装饰层。

**多个步骤时默认只展示当前步骤附近的 3 步**，设置中可选 2 步。3 步通常为前一步、当前步和后一步，到清单首尾时自动补足；2 步优先保留当前步和后一步。自动跟随时保持当前步骤可见，没有进行中步骤时以首个待处理步骤为中心，全部完成后显示末尾步骤。超出范围的内容分别收进“先前步骤”和“后续步骤”，两组可独立展开或收起，无对应步骤时隐藏入口。两组开合及 2/3 步选择都保存为本机展示偏好，重新打开、切换会话、刷新或重启后沿用。

任务交接使展示范围前进时，列表使用 **280ms 竖向滚动交接**：旧条目向上离开，新条目从下方接入，像密码锁滚轮；返回前面的步骤时反向滚动。手动浏览使用 **180ms** 过渡，新输入直接更新最新目标，不等待上一段动画完成。展示区裁切边界内保持 2/3 步的范围，长文字导致高度变化时同步缓动，先前/后续分组也跟随伸缩。连续滚动复用同一过渡层，只保留当前仍可见的离场行；共享条目沿当前画面位置继续移动，不反复从透明状态淡入，也不积压过期动画。打开旧会话、重新打开面板和更改任务计划不重播旧交接。

任务展示区可用**鼠标滚轮、触控板、触屏上滑/下拉**翻看，也可聚焦后按上下方向键、Home、End。滚动距离按实际行高换算步数，每帧合并输入并保留不足一行的余量；快速滑动可一次跨过多步，直接追随最新位置，不再用 140ms 限速或把任意距离压成一步。手动浏览会停留在所选范围，新任务进展不会把视线拉回；标题旁出现“回到当前步骤”，点击后恢复自动跟随。查看其他步骤不会改动任务状态，右上角的“第 X 步”始终反映实际进度，先前/后续数量按当前所看范围更新。滚轮到达首尾时不再拦截，允许外层卡片继续滚动，不添加内部滚动条。浏览位置只留在当前页面内存，不改写模块开合偏好，不新增持久化的任务内容。系统开启“减少动态效果”或强制颜色模式时立即切换，进行中的滚动也会取消。

滚动期间暂停整张卡片的快照克隆，操作与动画结束后在空闲时合并更新一次，为后续轮次切换准备过渡画面；不在每帧重复复制折叠步骤、输出和工具区。快照仍只保存在当前页面内存，不写入聊天缓存。

下拉以 240ms 的垂直揭示配合轻微位移、渐显完成；每轮首次安排新步骤时会重播一次，卡片已打开时也会重播。外阴影与卡片一起渐入渐出，裁切范围为阴影留出空间，避免动画结束时阴影突然出现；退场中返回仍从当前画面平滑恢复。动画不抢焦点，不重建输出缩略图。悬停退场中的卡片退出键盘与辅助技术交互，切换会话、禁用插件或安排新步骤会取消旧退场。开启系统“减少动态效果”时直接展开、收起，并停用圆点的弧光、扩散光环和文字扫光。系统强制颜色模式下也停用这些装饰动画，保留可读的静态状态标记和文字。

默认宽度 **320 CSS px**，正文和标题 **13px**，次要文字 11–12px，内边距 16px。进度、输出、本次会话中已使用分为三个栏目，标题旁各有箭头，可独立展开或收起，栏目内不设滚动区。卡片高度随展开内容自然变化，全部收起时只保留标题和分隔线；整卡仅在超过窗口可用高度时滚动兜底。比例按同尺寸的 Claude/DSH 桌面截图对比后调整，避免宽度和字号被放大。

在 **设置 → dsh-UI美化 → 任务面板 → 卡片样式** 中可选择四种材质，顺序为**默认、透明玻璃、轻量玻璃、毛玻璃**。默认保留原始配色、边框与阴影，不改变基础样式；透明玻璃采用 iPhone Liquid Glass 风格的通透表面、边缘高光与轻悬浮阴影，在支持 SVG 背景滤镜的 Chromium 宿主中，通过位移贴图让卡片边缘真实折射背后的画面，中央保持清透，任务文字和图标独立呈现；轻量玻璃采用 CSS 柔和亮边、静态高光与 2px 背景模糊；毛玻璃保留 22px 背景模糊与柔和的扩散阴影。这是针对 DSH 网页界面的玻璃观感近似，实际效果随宿主渲染能力和卡片背后的内容变化。

切换立即生效，并平滑过渡背景、边框、阴影与通透程度，四种材质都适配浅色和深色主题。暗色主题下，透明玻璃使用低遮盖的清透底和亮边，毛玻璃参考 iPhone 控制中心的冷灰雾面、柔和反光与背景模糊，默认保留不透明的暖灰哑光；玻璃内部的按钮悬浮底色同样半透明。纯色背景无法显示模糊纹理，四种材质仍通过色面、通透度和边缘反光区分。

透明玻璃（`clear`）、轻量玻璃（`css`）和毛玻璃（`glass`）使用独立的浅色、深色前景配色，自动跟随 DSH 当前主题，无需分别选择材质。浅色下进行中任务为深色加粗，深色下为亮白加粗；已完成和待处理文字与圆点保持同一灰阶，并同步适配工具计数、先前/后续步骤、连线、分隔线、悬浮底色和加载扫光，避免深色玻璃上的辅助文字过暗。**默认（`milk`）保留原始配色、边框与阴影，不应用玻璃的前景配色。**

样式改变卡片材质及对应前景配色，保留宽高布局、任务与输出节点、栏目及步骤分组的开合选择。选择以 `cardStyle`（`clear` / `css` / `glass` / `milk`）保存，跨会话、刷新和同一浏览器的其他窗口继续沿用；旧版“液态玻璃”的 `glass` 选择继续对应毛玻璃，不改变原有磨砂偏好。旧设置没有该字段或字段值无效时回退为默认。宿主不支持 SVG 背景折射时，透明玻璃回退到通透背景与高光；开启“减少动态效果”时保留静态材质并直接切换，强制颜色模式下关闭折射、高光与模糊，使用不透明系统背景，保持文字与控件清晰可读。

液态折射与圆角距离场实现参考了 MIT 授权的 [rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react) 和 [shuding/liquid-glass](https://github.com/shuding/liquid-glass)，来源版本、版权及完整许可见随插件分发的 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。实现使用本地生成的 SVG 与位移贴图，不增加运行依赖，也不加载远端脚本、图片或字体。

**透明玻璃现在会响应交互**：鼠标或触笔移动时，柔和的表面反光跟随位置滑动，边缘折射由 12px 轻微增强到 14px；按下或触摸时增强到最多 16px，松开、取消触摸、移出卡片或窗口失焦后平滑复原。仅改变背景光学效果，文字、图标和卡片位置保持稳定，不拦截触屏滚动。输入按动画帧合并，复用已有折射贴图，静止后停止更新；切换材质、禁用插件时释放事件和临时样式。减少动态效果时使用静态折射，强制颜色模式下关闭玻璃光学效果。毛玻璃继续保留磨砂观感，默认继续保留原始材质。

栏目、“先前步骤”和“后续步骤”的折叠均使用 **280ms** 的高度缓动，配合内容渐隐和箭头旋转，卡片、下方步骤与栏目同步平滑伸缩；连续点击会从当前高度反向过渡。折叠步骤保持挂载，收起后从键盘导航和辅助技术中隐藏，近期步骤节点不因两组开合重建，输出缩略图也不会重新加载。系统开启“减少动态效果”时直接切换。

**进度、输出、本次会话中已使用的开合状态会自动记住**，作为本机通用展示偏好，重新打开面板、切换会话、刷新或重启后继续沿用；再次手动展开或收起会更新保存值。悬停预览和排步骤的自动展开不会覆盖这些选择。没有保存记录时三个栏目默认展开，旧版启用开关和宽度设置可直接兼容；同一浏览器的多个窗口同步展示偏好，任务内容仍按会话隔离。

**普通工具默认合并为一行摘要**，避免 `write`、`ops_bash`、`job_output` 等工具逐项撑高卡片。同名工具合并计数，摘要显示工具种数和总调用次数；仍有调用进行时，优先显示最新正在调用的工具名称，多个工具同时进行时附带数量提示。失败次数直接保留在摘要中，成功重试不会抹掉先前失败；宿主已停止而调用没有返回结果时标为“未返回”，不继续显示加载动画。Skills、记忆、网页搜索和 GitHub 仍保留独立资源行。

工具明细按用途配上不同的 SVG 图标和简短分类：命令、编辑、读取、图像、进程、交互、检索、协作、计划；例如 `ops_bash` 使用终端图标，`write`／`edit` 使用文件编辑图标，`read_image` 使用图片图标，`job_kill` 使用进程图标，`ask_user` 使用对话图标。每行保留原工具名、调用次数和状态，未知工具归为“其他”并使用通用扳手图标。收起的摘要默认显示工具箱，调用中随最新活跃工具切换对应图标；分类只改变展示，不改变统计、折叠记忆或各材质适配。

点击摘要可展开或收起工具明细，查看各工具调用次数和状态。明细使用高度伸缩、渐隐、位移及轻微模糊过渡，收起后高度归零，不留下空白；条目错开进入，连续切换可从当前画面反向过渡。明细内不增加滚动条，超出窗口时沿用整张卡片的滚动兜底。明细开合以 `toolDetails` 布尔值保存，跨会话、刷新和同一浏览器的其他窗口继续沿用；仅保存展示选择，不保存工具名或调用参数。

**轻量玻璃（CSS 适配版）**是四种卡片样式之一，和透明玻璃并列保留，方便实际体验后自行选择。它用柔和亮边、静态高光与 2px 背景模糊呈现玻璃观感，不生成 SVG 位移贴图、不做鼠标或触摸追光；深色底增加遮盖以提高亮图背景上的可读性。透明玻璃继续保留真实边缘折射和动态追光。两种类型都沿用明暗独立文字配色、栏目布局、文件预览与开合偏好，选择即时生效并以 `cardStyle: "css"` 独立保存。切换到轻量玻璃后，透明玻璃的折射在材质过渡结束时释放；减少动态效果时立即完成，强制颜色模式下改用系统颜色。实现由本插件独立编写，未引入第三方源码或运行依赖。

小圆按钮另外使用按原生尺寸缩放的 **4px 向下字形投影**，让图标或文字在玻璃内留下柔和字影，并加强内缘明暗层次。图标本身保持清晰，输入文字不应用该效果；这不是垂直镜像或屏幕捕获。深色主题使用深色投影，默认材质和强制颜色模式移除投影，不额外生成 DOM、位移贴图或持续动画。

## 内容来源

- **进度**：最新轮次订阅当前 Session 的 `todos` projection，历史轮次从该轮已加载的 `todo/write` 事件还原最后清单，以 `turn/start` 确认边界，空轮不继承上一轮的任务。默认展示当前步骤附近的 3 步（可设为 2 步），其余分为“先前步骤”和“后续步骤”独立折叠，记住各组开合。比较每次清单的步骤文字和顺序，在运行过程中真正新增或调整计划且正在看最新轮次时触发保持展开；仅改变状态不触发。首次看到的已有清单作为基线，单纯运行状态变化或工具/输出记录不触发。没有任务清单时隐藏整块进度；关闭按钮保留在首个有内容的栏目右侧。
- **输出**：仅展示所阅读轮次已记录的 `deliverables/presented` 文件，点击交给 DSH 的文件预览；不会从聊天正文或写文件工具猜测交付物。PNG、JPEG、WebP 与 GIF 会先读真实字节做缩略图：通过 `remote.workspaceFiles` 的 `stat`/`readBytes` 取文件（超过 4 MB 或读取失败就退回短类型字标），对象 URL 随卡片卸载释放；其余类型显示 ZIP、MD、MP4 之类的三字母字标。
- **本次会话中已使用**：读取所阅读轮次已加载的工具调用及结果，迟到的工具结果仍归入原调用所属轮次。Skills 和记忆文件读取只在成功后展示，网页搜索及 GitHub 保留独立资源行；普通工具按名称聚合为默认收起的一行摘要，明细列出调用次数、未返回调用和失败次数。调用 ID 去重，PTC 的开始、结算与重放不会重复计数；同名并发调用未全部返回时仍标为进行中。资源和计数都按所阅读轮次隔离。

只借用 DSH 已有的 Session binding 和已加载记录，不新开会话，不主动翻页或额外拉取历史，不读写磁盘聊天日志，也不执行工具。历史轮次是否加载由宿主的滚动和轮次导航决定；无法确认该轮边界或记录尚未加载时显示不完整提示，不拿其他轮次的内容填充。可用的部分资源基于已加载记录展示。任务与轮次快照只留在当前浏览器内存，不保存聊天副本、不上传；本机仅保存展示偏好。

原生任务节点仍由 DSH 的 React 管理；会话侧卡成功挂载后只隐藏原生清单，关闭插件会恢复原位。若当前宿主没有可用的页眉插槽，则保留 0.1 版本的原生任务清单定位方案，该回退卡片同样沿用所选材质；关闭插件后清理材质标记与样式，恢复原生清单外观。

## 环境

- Node.js 22.13 或更高版本。
- DSH Desktop，已验证安装包内 `@deepseek-ai/dsh-client-ui-conversation` 0.2.1-rc.2 的 TodoPanel。
- Git；测试需要开发依赖和 Chrome（或通过 `PLAYWRIGHT_CHANNEL` 选择本机其他 Playwright 浏览器渠道）。

插件运行本身没有额外 npm 依赖，React 由 DSH 提供。

## 安装与启用

将仓库放在长期保留的工具源码目录，然后执行：

```powershell
node scripts/profile.mjs install
node scripts/profile.mjs check
```

默认接入 `$env:DSH_HOME` 或用户目录下 `.dsh` 的 `desktop` profile，可用 `--profile <名称>` 指定其他已有 profile。

安装器建立 `node_modules` junction，登记 `link:` 依赖、锁文件及 `dsh.profile.bundles`，通过包内 `cordis.patch.yml` 挂载；**不改用户 patch 层**。重复安装幂等，遇到已被占用的插件目录或不认识的锁文件结构会停止并保留现场。

**首次增加插件后，需要完全退出 DSH（包括托盘）再启动**，让宿主重新发现客户端插件图。之后只改 `client.js` 时，通常在 DSH 窗口按 `Ctrl+R` 刷新即可。重启前应等当前任务结束。

打开 **设置 → dsh-UI美化**：

- 本页独立管理右上角任务面板与底部输入栏的样式。独立插件 `dsh-claude-slider` 使用自己的“推理滑块 (Claude)”设置入口，两个插件互不托管，无需合并补丁。
- 任务面板设置采用与推理滑块相近的圆角卡片、分组标题、柔和阴影和选项卡比例，并提供开启状态、当前材质、宽度及默认步数摘要，支持深色主题和窄屏排列。开关、材质选项、宽度和步骤下拉均为自绘控件，保留键盘操作及状态过渡。
- 启用或关闭右上角任务面板；关闭后立即恢复原位置。
- 鼠标悬停入口即可预览，移入卡片可继续操作；点击入口可固定展开。
- 手动打开或悬停预览时，点击面板外部即可带动画收起；排步骤时自动展开的面板只能点 X 关闭。点击到的外部控件仍正常响应。同一聊天的右侧轮次导航保持卡片打开，并以动画切换对应轮次的内容。
- 每轮实际安排新任务步骤时卡片自动下拉，直到点 X 才关闭；点 X 后本轮不再反复弹。切换聊天后返回仍保留自动展开的关闭规则，普通手动打开及悬停预览分别处理。
- 调整面板宽度（280–480 px，默认 320 px）；窄屏自动缩小。
- 在“卡片样式”中选择带边缘折射与高光的透明玻璃、轻量玻璃、毛玻璃或原始的默认样式，切换立即平滑生效，并记住选择；材质选择支持方向键、Home 和 End。进入设置时因外部点击已收起的卡片，会在选择材质时临时展开供预览；点击已选材质也能重新预览。预览期间编辑本页其他设置不会关掉卡片，关闭设置结束临时预览，保留原本固定展开的状态；没有内容或已禁用时保持隐藏。临时预览不写入展开记忆。
- 设置进度默认显示 2 或 3 个步骤（默认 3）；先前步骤和后续步骤分别折叠，开合及步数选择都会记住。
- 点击各栏目标题独立展开或收起，卡片随内容平滑调整高度；栏目内无滚动区。开合选择自动保存，刷新和下次打开继续沿用。
- 普通工具默认显示一行摘要，点击摘要查看明细；明细开合自动记住，当前调用和失败提示在摘要中可见。

## 输入栏样式配置

在 **设置 → dsh-UI美化 → 输入栏外观** 中直接选择样式，顺序与任务面板一致：**默认、透明玻璃、轻量玻璃、毛玻璃**。默认就是关闭美化，恢复宿主输入栏原来的外观，不再提供重复的“输入栏美化”开关；透明玻璃保留真实背景边缘折射与动态追光；轻量玻璃使用 CSS 柔和亮边、静态高光与 2px 背景模糊；毛玻璃使用 22px 背景模糊。选择即时生效。

输入栏里的**附件、麦克风、语音、发送／停止等圆形按钮**跟随同一个材质选择：透明玻璃为小按钮生成各自的边缘折射与追光，使用 4px 基础折射、最多约 5.34px 交互折射；轻量玻璃与毛玻璃沿用相应模糊和高光。蓝色主按钮使用带颜色的半透明玻璃，保留原生图标颜色、尺寸、圆角、位置、禁用状态及点击行为。模型、权限等带文字的选择器和弹出菜单保留原样；选择默认时移除按钮材质并释放滤镜。实现仅增强聊天输入栏中的已识别动作按钮，复用现有玻璃管理器与贴图缓存，不增加运行依赖，也不接管录音、语音或发送逻辑。

任务卡片与输入栏分别保存选择，支持方向键、Home、End、刷新和同一浏览器的其他窗口同步。新设置默认使用原始外观；已有材质选择继续保留，旧版关闭开关的状态迁移为默认，旧版仅开启轻量玻璃且没有材质字段的状态继续对应轻量玻璃。旧 `composerGlass` 字段只用于读取迁移，之后仅保存材质选择，不保留隐藏的开关。只需在 DSH 按 **Ctrl+R** 加载更新。

点击或聚焦输入栏时保持所选玻璃的中性亮边，不切换为蓝色描边；浅色、深色及三种玻璃材质一致。文字、光标颜色与按钮的键盘焦点提示沿用宿主设置。

**对话延伸到输入栏后方**是同一区域的独立开关，默认开启。开启后移除进行中聊天底部的不透明渐变，滚动中的对话能透过玻璃到达输入栏下方的工具按钮一排；关闭后立即恢复宿主遮罩。开关以 `chatUnderComposer` 布尔值保存，支持刷新与跨窗口同步，与任务面板开关和输入栏材质选择独立。只改变遮罩背景，沿用宿主已有的滚动范围、输入栏位置和末尾留白，最后一条消息仍可完整滚到输入栏上方。新建会话首页、需要阻挡交互的输入栏覆盖层保留原来的背景；强制颜色模式下使用不透明系统背景。

样式只作用于聊天底部 `data-composer-seat` 内的 `data-composer-card`，保持尺寸、圆角、文字与光标颜色，不替换编辑器或注册输入、发送、粘贴、附件和拖放事件。新会话和重新挂载的输入栏自动继承选择，不读取或保存草稿。使用内侧描边保持几何尺寸，无装饰遮罩覆盖按钮。仅透明玻璃创建背景 SVG 折射和追光；切换到其他样式后释放，默认和关闭时移除材质标记并恢复宿主外观。减少动态效果时直接切换，强制颜色模式下玻璃材质使用系统背景；卸载时清理样式并恢复原标记。

`npm run test:composer` 使用独立测试页覆盖四种样式及键盘选择、开关、编辑器和选区保持、组合输入状态、合成消息发送、文件选择/拖放、模型菜单、刷新/跨窗口、动态挂载、明暗窄屏、辅助功能及卸载恢复。按钮场景验证四种材质与明暗主题、每个小透镜的独立滤镜与折射上限、原生大小／位置／图标颜色、禁用点击、键盘焦点及默认恢复；语音按钮只切换合成状态，不申请麦克风权限。对话延伸开关另以输入栏底部工具行的真实像素变化验证，并核对滚动位置、尺寸与末尾留白不变、首页及覆盖层不受影响。设置 `DSH_ASAR` 后，在内存中核对已安装宿主的公开标记并使用真实 InputBar 与 ConversationRoot 样式；编辑交互仍是合成夹具，不向正在运行的聊天发送消息或上传文件。截图保存在 `composer/`。

## 与推理滑块插件独立使用

`dsh-claude-slider`（npm 第三方）独立注册“推理滑块 (Claude)”设置项。本插件不加载、导出或隐藏它的设置页；它的主题与参数继续由自身维护。

新安装无需修改推理滑块。如果曾使用旧版合并补丁，执行一次以下迁移，再刷新 DSH：

```powershell
npm run restore-slider   # 仅撤回旧版已知的设置合并改动
npm run check-slider     # 只读核对推理滑块恢复独立设置
```

迁移保留其他第三方源码改动和换行，已经独立时重复执行不写文件。遇到无法识别的上游结构或旧补丁变体会停止并保留现场；显式指定的路径不存在时不会转而修改其他副本。不安装推理滑块也不影响本插件。

## 卸载

```powershell
node scripts/profile.mjs uninstall
```

只移除本插件的链接、依赖、锁记录与 bundle 条目，保留仓库和其他插件，然后完全重启 DSH。运行中禁用本插件的客户端实例会清理观察器、样式和定位标记。

## 兼容边界

依赖 `conversation.session.header.utilities` 插槽和 Session projection/event source 接口。轮次识别结合 `turnOutline` projection、轮次导航的 `nav button[data-index][aria-current="true"]`，以及 `data-chat-following-tail`、`data-chat-turn`、`data-chat-flow`、`data-slot="conversation.chat.flow"`、`data-conversation-scroll` 等稳定 DOM 标记；导航未提供当前标记时按聊天滚动容器内的阅读位置回退。只观察宿主状态，不改写其滚动记忆或私有 store。

原生回退方案依赖稳定 DOM 标记 `data-testid="todo-panel"`、`data-conversation-content`、`data-conversation-session`、`data-composer-seat`，不依赖构建生成的 CSS 类名。未来宿主若移除原生定位标记，回退方案会保留原清单位置；轮次接口或标记变化时，需要重新核对历史内容跟随行为。

面板以浮层展示，展开时会覆盖右上角的一部分聊天内容。手动打开时可点击面板外部、页眉入口或关闭按钮收起；自动展开时只能点 X 收起。也可在设置中禁用面板。浏览器偏好按设备保存；不会把展示偏好同步到服务器。输出反映声明而非永久文件副本，源文件删除后预览由 DSH 报告错误。
