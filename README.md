# UI动效美化

GitHub 仓库名为 **dsh-ui-beautify**，显示名称为 **UI动效美化**。内部包名、安装链接和本机偏好键继续使用 `dsh-claude-beautify`，以兼容已有安装和展示选择。

为 DeepSeek Harness 提供受 Claude 桌面版启发的右上角会话侧卡，展示进度、输出和本次使用的工具与资源，并为左侧栏和底部输入栏提供独立选择的玻璃样式、圆角及动效。

聊天顶部的主题切换右侧提供 **专注模式** 按钮：点击后隐藏输入框、左侧栏、右侧面板及浮动的任务卡片／文件预览，只保留正文和顶部操作。再次点击或按 **Esc** 恢复；打开的菜单、设置对话框先处理各自的 Esc。模式只在当前页面生效，刷新后恢复常规界面；退出时保留宿主最新的侧栏宽度、展开状态、输入草稿与选区，不调用宿主开关，也不把开屏或材质偏好改成关闭。输入框只做淡出和 12px 位移，退场后一次性释放占位；专注时正文居中并保持进入前行宽，避免长历史重新换行。切换前一次测量目标位置，让正文居中、底部跟随与顶部操作的位移和淡出同步完成，释放占位的最后一帧不再跳位；退出时先在不可见状态恢复输入框和两侧面板，经过原生尺寸回调及布局更新后再开始淡入，从当前画面平滑接回原布局。不逐帧修改高度、内边距或模糊，减少重复布局与玻璃绘制。按钮在明暗主题下保持可辨，减少动态效果／强制颜色时直接切换。卸载插件或离开聊天页会恢复临时显隐与可访问性标记。

**设置 → UI动效美化** 按功能分为 **任务面板 / 输入栏 / 侧栏 / 开屏欢迎 / 全图背景 / 粒子背景 / 对话动效** 七个顶部 Tab，每次只展示当前分类。分类栏滚动时保持可见，切换时先淡出、再淡入并平滑调整内容高度；当前页面内重新打开设置会记住上次分类。Tab 支持方向键和 Home/End；窄屏改为单行横向滑动，选中项自动保持可见，避免多行分类栏遮住内容。减少动态效果或强制颜色下直接切换。切换只调整设置内容区，不改变聊天滚动、输入或会话。

### 全图背景

**设置 → UI动效美化 → 全图背景 → 选择图片或视频**，导入 JPG、PNG、WebP、GIF、MP4 或 WebM 后自动开启。背景覆盖整个窗口，可调整 **背景可见度（0–100%）/ 模糊（0–20）/ 铺满、完整显示或拉伸 / 居中或靠边**。可关闭并保留文件、恢复上一张，或清除当前选择。更换失败时保留原背景。

设置页使用独立的 **预览与文件操作 / 外观参数 / 声音** 区域。桌面预览与上传操作并排，两个滑条并排；手机改为单列，操作区保留间距，按钮及滑条触控高度至少 44px。效果缩略图始终占位，未导入时显示明确的示意背景；导入后以缩小的会话界面预览透明度、模糊、铺放及位置，关闭背景或刷新后也保留缩略图。缩略图仅是静态首帧，不运行第二个视频播放器。分段选项底块使用短弹簧曲线滑动，按钮按压回弹、新缩略图轻柔淡入；减少动态效果或强制颜色下立即切换。

**背景素材库 → 最近上传** 保留本机上传过的图片和视频，显示静态缩略图、文件名、类型与当前选中状态，点击即可切换。按上传时间从新到旧排列，切换不会打乱顺序或重复保存原文件；先显示 12 个，可点「显示更多」。刷新后保留，升级时自动迁移原来的当前背景和上一张。清除当前背景只清除选择，素材库里的文件继续保留；不自动删除旧上传。

图片最多 32MB，视频最多 256MB，画面最多约 3300 万像素。文件保存在当前浏览器的本机 IndexedDB 中，偏好只记录文件名和修订号，不上传、不把文件内容写进 localStorage；刷新后恢复，不同浏览器或不同站点地址之间不共享。素材库单独保存原文件，选择记录只引用修订号；保存失败时事务回滚，原背景和素材库均保留。视频循环播放且默认静音，可主动开启声音；自动播放不允许声音时回退静音。后台暂停，减少动态效果时静态显示，强制颜色模式下恢复原生界面。

背景层不接收输入事件，布局底色只在背景加载成功后透明；设置、菜单、工具卡片保留各自底色。可与粒子背景叠加。滚动和流式输出不逐帧扫描布局或重绘静态图片，调整外观复用同一素材；更换、关闭与卸载会释放播放器及文件 URL。交互参考 [beautiCode 的本机背景功能](https://github.com/starsstreaming/beautiCode/blob/main/docs/deepseek-harness.md)，使用本插件自己的设置入口与本机存储。

### 会话粒子背景

**设置 → UI动效美化 → 粒子背景** 可启停背景，选择 **DeepSeek Logo / 鲸鱼娘 / 自定义 SVG**。默认开启并使用宿主公开的 DeepSeek Logo 几何，默认数量 **9600**；粒子数可在 **500–20000** 内独立调整。旧默认 6400 首次升级时自动提高至 9600，其他自定义数量保持；之后手动改回 6400 也会保留。备用 Canvas 2D 绘图仍最多 4500 颗。粒子从人物或图形的四周沿不同弧线汇入，背景始终不接收鼠标或键盘事件。图形位于会话区域中央、输入框上方，跟随明暗主题和窗口宽度。

**转换进度** 滑条控制从 **0% 散开到 100% 完整成形**，与粒子数分别保存。默认使用 **跟随上下文**；也可选择 **手动调整**，或直接拖动滑条进入手动模式。手动支持滑动、精确输入、方向键每次 1%、Page Up/Down 每次 10%、Home/End 到两端，默认手动值 50%；没有上下文数据也可查看指定进度。切回跟随模式后保留手动值，重新打开设置、刷新或同一浏览器其他窗口均沿用选择；切换模式只更新当前画布目标，不重新加载图形。

滑条下方的 **当前上下文** 独立显示真实占用，手动模式或背景关闭时仍持续更新；未上报时显示等待数据。调节转换进度不改变粒子数量。

背景订阅当前会话的 `contextPressure`，与 DSH 原生占用环一致，优先使用 `projectedTokens`，否则使用 `pressureTokens`，除以 `contextWindow` 后四舍五入并限制到 0–100%。切换会话时重新绑定；跟随模式下，上下文压缩会让粒子退散，缺少有效的分子或容量时隐藏背景；手动模式保持指定转换进度。只读取计量投影，不读取或保存聊天正文、工具参数或会话标识到配置。

展开、收起左右侧栏只更新背景尺寸，保留同一画布、成形进度和运动相位，不重新播放聚拢或入场。布局切换导致会话容器或顶部计量订阅短暂重建时，最多保留 1.5 秒供同一会话复用；订阅短暂缺失时沿用最后一次真实读数，新读数（包括 0% 和压缩）立即生效。缓存与可见画布合计最多两个；离开超过保留时间、关闭背景或卸载会释放绘图资源，长期隐藏后重新显示也会正常恢复。

鲸鱼娘使用透明素材采样，手臂、发丝和双腿之间的背景空隙也保持透明；从汇入到完整成形始终绘制彩色粒子，不再叠加原图。完整成形后，粒子仍围绕各自采样位置轻微游动、闪烁，脸部降低移动幅度，整体轮廓保持稳定；WebGL2 / Canvas 2D 都保留此效果。隐藏、后台或设置遮挡时暂停，减少动态效果时静态显示。

跟随上下文模式的 **开始显示** 和 **完整成形** 默认分别为 **0% / 80%**。低于开始值时隐藏，达到完整值后保持完整；中间按 `(真实占用 - 开始值) / (完整值 - 开始值)` 连续变化。例如设置 20% / 60%，真实占用 40% 对应 50% 转换。开始值必须小于完整值，设置会自动保持有效区间；手动模式隐藏这两项并保留其值。数值控件支持直接输入、加减、方向键和 Home/End，Enter 保存、Esc 取消当前输入。

运行 `npm run test:particle-conversion` 验证手动/上下文转换、拖动与精确输入、独立数量、无上下文、跨窗口与刷新保留、背景关闭时的真实计量、明暗/窄屏和绘图回退；截图与结果保存在 `DSH_CLAUDE_OUTPUT_DIR/particle-conversion/`，默认使用项目集合目录的 `.scratch/claude-beautify/particle-conversion/`。

「导入 SVG」只接收本地静态 SVG，限 2 MB / 25000 节点。填充、描边、渐变、内部引用和透明背景可形成点云；脚本、事件、外部图片/字体/网络引用、嵌入 HTML 和动画不进入渲染，空白或非法图形保留原素材。SVG 经过清理后存入当前浏览器的 IndexedDB `dsh-ui-context-particles`，刷新后保留；偏好中只保存选择、数量、阈值、文件名和版本标识。可随时移除自定义文件并恢复 Logo，不修改插件运行配置或源文件。

每个可见会话最多一张背景画布，同时最多两个会话；WebGL2 每秒最多 30 帧、像素密度上限 1.25。无 WebGL 或图形上下文丢失时回退到最多 4500 颗的 Canvas 2D。后台、不可见或设置窗口遮挡时停止绘制；减少动态效果时只按占用变化绘制静态帧；强制颜色模式隐藏；关闭背景或卸载插件释放画布、GPU 资源、监听与临时标记。Logo 与自定义 SVG 完整成形时保留去底细节层；鲸鱼娘仅显示粒子。

运行 `npm run test:context-particles` 验证真实的插件设置入口、占用/阈值映射、会话隔离、压缩、Logo/鲸鱼娘/SVG、上传清理与持久化、明暗/窄屏、回退、减少动态效果和卸载清理；设置 `DSH_ASAR` 可使用本机宿主的准确 Logo 与布局样式。截图与验证结果在 `outputs/dsh-ui-beautify/context-integration/`（或 `DSH_CLAUDE_OUTPUT_DIR/context-integration/`），使用合成会话，不代表桌面客户端的业务会话已验收。已链接的本机 DSH 按 **Ctrl+R** 刷新后生效。

任务面板、输入栏、侧栏使用同一套四档材质预览卡片，统一布局、名称、开销标签及选中动效；按设置内容列宽显示四列、两列或单列。全部开关采用黑色开启轨道、灰色关闭轨道与白色圆钮，深色主题加强描边与键盘焦点对比；禁用状态保持淡化，强制颜色模式遵循系统配色。开销说明仍按各区域及小按钮玻璃开关分别计算，高开销继续标红。隐藏分类不挂载预览，离开时释放媒体解码及预览动画，配置仍自动保存。

面板入口位于**当前聊天列**右上角，直接复用 DSH 宿主的官方 `FishLogo` 组件，与数量或步骤提示一起显示。入口高度为 **24 CSS px**，和截图中的紧凑页眉按钮保持一致；文字固定为 13px、行高 18px，Logo 宽 16px 并保留官方比例，避免继承宿主大字号后撑高。空闲时默认收起，**鼠标悬停入口即可下拉展开，无需点击**。悬停预览在移出入口和卡片 220ms 后开始收起，经过 **220ms 渐隐、轻微上移和向上收合**后移除；跨过入口与卡片的间隙或返回卡片会取消收起，退场途中返回也会从当前画面平滑恢复，保留原卡片和缩略图。键盘焦点位于卡片内时会保持显示。点击入口可固定展开，再次点击、关闭按钮或 Escape 可收起；触屏和键盘保留点击操作。

**悬停预览或手动打开的面板，点击外部聊天区、空白处或其他控件时，会用 180ms 退场动画收起。安排任务步骤时自动展开的面板只能点 X 关闭**；点击外部、再次点击入口、移开鼠标或按 Escape 都保持展开，任务结束也不自动解除这一状态。同一聊天右侧的轮次导航及设置中的卡片样式选择区仍保持卡片打开。同一聊天的文件阅读面板也属于卡片的操作范围：打开 MD/HTML、切换源码、刷新和关闭阅读面板不会收起卡片；阅读期间鼠标移出卡片不触发悬停退场，也不会将悬停状态改成固定展开。外部点击照常执行，不拦截事件、不把焦点拉回入口。外部收起不会修改已保存的模块开合偏好。

**只有安排任务步骤时才自动展开**：运行过程中，任务清单从无到有，或步骤文字、顺序发生变化时，面板会下拉并保持显示，直到点 X 才收起。普通推理开始、工具调用、文件交付和仅更新步骤完成状态都不触发展开，打开旧会话也不因已有任务或输出自动弹出。本轮点 X 关闭后不再反复弹，下一轮实际安排步骤时才重新展开。有内容时才出现入口。

悬停预览与点击/排步骤的保持展开状态分别处理；悬停不会改写各会话的保持展开状态，切换会话会清理预览及待收起计时。卡片材质、细边框与布局参考 Claude 桌面版，支持深色主题和窄屏自适应。

**同一聊天滚到哪一轮，卡片就展示那一轮的任务、输出和已用资源**，也跟随右侧轮次导航。查看历史轮次时入口显示“第 X 轮”，任务使用该轮最后记录的清单，不混入其他轮次的文件或工具。后台正在进行的新计划不会替换所看的历史内容，也不会把已收起的历史卡片自动打开。返回最新轮次后恢复实时进度。

卡片打开时切换轮次，内容通过 **280ms 渐隐渐显、上下位移和 2px 模糊过渡**完成交接，条目略微错开进入，卡片高度同步平滑伸缩；快速切换会取消过期动画，最终显示最新选择。没有任务、输出或资源的轮次会保留已打开的卡片并显示空状态；记录缺失则提示“本轮记录尚未完整加载”。切换不会改写三个栏目及先前/后续步骤的开合偏好，减少动态效果或强制颜色模式下直接切换。

工作时入口显示“第 X 步，共 Y 步”，随当前任务更新。进度区统一使用 8px 小圆点：已完成为灰色实心，进行中为黑色实心，待处理为灰色空心；已完成和待处理文字统一灰色，进行中文字加深为黑色，并使用 700 字重加粗。全部完成后末步也保持灰色实心，不再单独放大或显示对勾。深色主题下进行中改用亮色，其他步骤保持灰色，维持相同的突出层级。

步骤圆点之间使用细灰色实线连接，“先前步骤”和“后续步骤”入口及相邻连接段使用虚线，收起更多步骤时仍可看出前后延续关系。连线随每行实际高度伸缩，支持长文字换行和步骤折叠动画，并在圆点及进行中弧光周围留出间距；没有对应折叠组时，首尾不额外延伸。深色主题同步调整连线颜色。

运行中当前步骤使用**稳定实心核心 + 单条黑色圆头旋转弧线 + 向外扩散的圆形光环**：旋转弧线约 130 度，不再附带灰色旋转弧线，深色主题随当前状态改为亮色。圆点、弧线和光环都由 SVG 圆形绘制，弧线两端使用圆头，避免角度渐变截口产生棱角；三个状态的核心外径均为 8px。外弧每 1.35 秒一圈，光环每 1.9 秒扩散一轮，核心保持不透明、不闪烁，也不改变文字和行的布局。文字保留从左向右扫过的柔和白光，每 2.4 秒一轮。动画只出现在运行中会话的进行中条目上，任务完成或会话停止运行后恢复静态圆点和文字；已完成及待处理条目不生成装饰层。

**当前任务转到下一项时，进度圆点用 300ms 水滴动画交接**：从上一项的位置拉出细尾、沿时间线下落，到下一项轻微压扁后收成正常的 8px 圆点。三行窗口没有滚动时也会播放；需要自动跟随时，列表稍后跟上水滴，避免滚动把下落抵消。路径按任务实际高度测量，支持长文字换行、连续进度更新和分两次发布的“完成 → 下一项激活”。当前轮次和全部轮次中正在运行的任务组均支持。

水滴仅在真实进行中任务发生交接时短暂绘制；首次打开、重开、切换会话、手动浏览历史和重复状态不补播。关闭卡片、折叠栏目、停止运行、改变窗口尺寸及卸载时释放临时 SVG，恢复正常圆点。减少动态效果、强制颜色或不支持 SVG 路径动画时直接更新。只预生成一次路径关键帧交给浏览器播放，不使用 WebGL、模糊融合或常驻 JavaScript 帧循环。

**多个步骤时默认只展示当前步骤附近的 3 步**，设置中可选 2 步。3 步通常为前一步、当前步和后一步，到清单首尾时自动补足；2 步优先保留当前步和后一步。自动跟随时保持当前步骤可见，没有进行中步骤时以首个待处理步骤为中心，全部完成后显示末尾步骤。超出范围的内容分别收进“先前步骤”和“后续步骤”，两组可独立展开或收起，无对应步骤时隐藏入口。两组开合及 2/3 步选择都保存为本机展示偏好，重新打开、切换会话、刷新或重启后沿用。

任务交接使展示范围前进时，列表配合水滴使用 **300ms 竖向滚动交接**：旧条目向上离开，新条目从下方接入；其他自动定位使用 280ms，返回前面的步骤时反向滚动。手动浏览使用 **180ms** 过渡，新输入直接更新最新目标，不等待上一段动画完成。展示区裁切边界内保持 2/3 步的范围，长文字导致高度变化时同步缓动，先前/后续分组也跟随伸缩。连续滚动复用同一过渡层，只保留当前仍可见的离场行；共享条目沿当前画面位置继续移动，不反复从透明状态淡入，也不积压过期动画。打开旧会话、重新打开面板和更改任务计划不重播旧交接。

任务展示区可用**鼠标滚轮、触控板、触屏上滑/下拉**翻看，也可聚焦后按上下方向键、Home、End。滚动距离按实际行高换算步数，每帧合并输入并保留不足一行的余量；快速滑动可一次跨过多步，直接追随最新位置，不再用 140ms 限速或把任意距离压成一步。手动浏览会停留在所选范围，新任务进展不会把视线拉回；标题旁出现“回到当前步骤”，点击后恢复自动跟随。查看其他步骤不会改动任务状态，右上角的“第 X 步”始终反映实际进度，先前/后续数量按当前所看范围更新。滚轮到达首尾时不再拦截，允许外层卡片继续滚动，不添加内部滚动条。浏览位置只留在当前页面内存，不改写模块开合偏好，不新增持久化的任务内容。系统开启“减少动态效果”或强制颜色模式时立即切换，进行中的滚动也会取消。

滚动期间暂停整张卡片的快照克隆，操作与动画结束后在空闲时合并更新一次，为后续轮次切换准备过渡画面；不在每帧重复复制折叠步骤、输出和工具区。快照仍只保存在当前页面内存，不写入聊天缓存。

下拉以 280ms 的垂直揭示配合轻微位移、渐显完成；每轮首次安排新步骤时会重播一次，卡片已打开时也会重播。外阴影与卡片一起渐入渐出，裁切范围为阴影留出空间，避免动画结束时阴影突然出现；退场中返回仍从当前画面平滑恢复。动画不抢焦点，不重建输出缩略图。悬停退场中的卡片退出键盘与辅助技术交互，切换会话、禁用插件或安排新步骤会取消旧退场。开启系统“减少动态效果”时直接展开、收起，并停用圆点的弧光、扩散光环和文字扫光。系统强制颜色模式下也停用这些装饰动画，保留可读的静态状态标记和文字。

默认宽度 **320 CSS px**，正文和标题 **13px**，次要文字 11–12px，内边距 16px。进度、输出、本次会话中已使用分为三个栏目，标题旁各有箭头，可独立展开或收起，栏目内不设滚动区。卡片高度随展开内容自然变化，全部收起时只保留标题和分隔线；整卡仅在超过窗口可用高度时滚动兜底。比例按同尺寸的 Claude/DSH 桌面截图对比后调整，避免宽度和字号被放大。

在 **设置 → UI动效美化 → 任务面板 → 卡片样式** 中可选择四种材质，顺序为**默认、透明玻璃、轻量玻璃、毛玻璃**。默认在浅色主题使用纯白背景与中性灰边框，输出图标、HTML 预览底栏及未就绪占位也统一为白底，悬停保留浅灰反馈；深色主题沿用原有深色表面；透明玻璃采用 iPhone Liquid Glass 风格的通透表面、边缘高光与轻悬浮阴影，在支持 SVG 背景滤镜的 Chromium 宿主中，通过位移贴图让卡片边缘真实折射背后的画面，中央保持清透，任务文字和图标独立呈现；轻量玻璃采用 CSS 柔和亮边、静态高光与 2px 背景模糊；毛玻璃保留 22px 背景模糊与柔和的扩散阴影。这是针对 DSH 网页界面的玻璃观感近似，实际效果随宿主渲染能力和卡片背后的内容变化。

切换立即生效，并平滑过渡背景、边框、阴影与通透程度，四种材质都适配浅色和深色主题。暗色主题下，透明玻璃使用低遮盖的清透底和亮边，毛玻璃参考 iPhone 控制中心的冷灰雾面、柔和反光与背景模糊，默认保留不透明的暖灰哑光；玻璃内部的按钮悬浮底色同样半透明。纯色背景无法显示模糊纹理，四种材质仍通过色面、通透度和边缘反光区分。

透明玻璃（`clear`）、轻量玻璃（`css`）和毛玻璃（`glass`）使用独立的浅色、深色前景配色，自动跟随 DSH 当前主题，无需分别选择材质。浅色下进行中任务为深色加粗，深色下为亮白加粗；已完成和待处理文字与圆点保持同一灰阶，并同步适配工具计数、先前/后续步骤、连线、分隔线、悬浮底色和加载扫光，避免深色玻璃上的辅助文字过暗。**默认（`milk`）浅色表面统一为白色，沿用原有文字配色及深色样式，不应用玻璃的前景配色。**

样式改变卡片材质及对应前景配色，保留宽高布局、任务与输出节点、栏目及步骤分组的开合选择。选择以 `cardStyle`（`clear` / `css` / `glass` / `milk`）保存，跨会话、刷新和同一浏览器的其他窗口继续沿用；旧版“液态玻璃”的 `glass` 选择继续对应毛玻璃，不改变原有磨砂偏好。旧设置没有该字段或字段值无效时回退为默认。宿主不支持 SVG 背景折射时，透明玻璃回退到通透背景与高光；开启“减少动态效果”时保留静态材质并直接切换，强制颜色模式下关闭折射、高光与模糊，使用不透明系统背景，保持文字与控件清晰可读。

液态折射与圆角距离场实现参考了 MIT 授权的 [rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react) 和 [shuding/liquid-glass](https://github.com/shuding/liquid-glass)，来源版本、版权及完整许可见随插件分发的 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。实现使用本地生成的 SVG 与位移贴图，不增加运行依赖，也不加载远端脚本、图片或字体。

**透明玻璃现在会响应交互**：鼠标或触笔移动时，柔和的表面反光跟随位置滑动，边缘折射由 12px 轻微增强到 14px；按下或触摸时增强到最多 16px，松开、取消触摸、移出卡片或窗口失焦后平滑复原。仅改变背景光学效果，文字、图标和卡片位置保持稳定，不拦截触屏滚动。输入按动画帧合并，复用已有折射贴图，静止后停止更新；切换材质、禁用插件时释放事件和临时样式。减少动态效果时使用静态折射，强制颜色模式下关闭玻璃光学效果。毛玻璃继续保留磨砂观感，默认继续保留原始材质。

栏目、“先前步骤”和“后续步骤”的折叠均使用 **280ms** 的高度缓动，配合内容渐隐和箭头旋转，卡片、下方步骤与栏目同步平滑伸缩；连续点击会从当前高度反向过渡。折叠步骤保持挂载，收起后从键盘导航和辅助技术中隐藏，近期步骤节点不因两组开合重建，输出缩略图也不会重新加载。系统开启“减少动态效果”时直接切换。

**进度、输出、本次会话中已使用的开合状态会自动记住**，作为本机通用展示偏好，重新打开面板、切换会话、刷新或重启后继续沿用；再次手动展开或收起会更新保存值。悬停预览和排步骤的自动展开不会覆盖这些选择。没有保存记录时三个栏目默认展开，旧版启用开关和宽度设置可直接兼容；同一浏览器的多个窗口同步展示偏好，任务内容仍按会话隔离。

**普通工具默认合并为一行摘要**，避免 `write`、`ops_bash`、`job_output` 等工具逐项撑高卡片。同名工具合并计数，摘要显示工具种数和总调用次数；仍有调用进行时，优先显示最新正在调用的工具名称，多个工具同时进行时附带数量提示。失败次数直接保留在摘要中，成功重试不会抹掉先前失败；宿主已停止而调用没有返回结果时标为“未返回”，不继续显示加载动画。记忆、网页搜索和 GitHub 保留独立资源行。

**多个 Skills 合并为一行“Skills · N 个”**，默认收起，点击或按 Enter/空格可展开各技能名称；只有一个技能时直接显示名称。技能明细沿用高度伸缩、渐隐、位移、模糊及逐项错开的动画，收起后高度归零，快速点击可反向过渡。开合偏好以独立的 `skillDetails` 布尔值保存，与工具明细互不影响，刷新和其他窗口同步；不把技能名称、路径或调用参数写入偏好。数量沿用已成功识别的资源记录，失败读取不计入 Skills。

面板顶部可切换 **当前轮次 / 全部轮次**，范围始终是当前聊天。当前轮次默认跟随正在阅读的消息，也可用上一轮、下一轮按钮单独浏览；点击“跟随阅读”恢复同步，不移动聊天正文。全部轮次汇总当前已加载的工具调用与失败次数，同一技能资源和同路径输出去重，输出保留最后一次声明；未加载完整时明确显示提示，不后台加载或修改会话记录。视图选择以 `summaryScope` 保存，刷新及其他窗口同步，不保存聊天内容。

范围按钮使用黑白配色：浅色为白底、黑色选中块，夜间为黑底、白色选中块。切换时选中块在 **280ms** 内拉伸、形成细颈并流向另一侧，随后尾部收拢；快速反向点击从当前轮廓接续。文字随实际流动底色反色，形变只绘制小型 SVG，不添加整块面板滤镜。减少动态效果和强制颜色时直接落位，缩放或改宽后重新对齐按钮，动画结束释放临时图层。

可选适配 [dsh-artifact-preview](https://github.com/nirvanaslash/dsh-artifact-preview)：已加载该插件时，输出区最近三份 HTML 网页显示封面、名称与预览入口，其余文件保留紧凑行；图片、Markdown、源码、CSV、JSON 等受支持文件点击后进入本插件的右侧阅读面板。面板用圆角、玻璃顶栏与明暗配色，支持预览/源码切换、刷新、拖宽、关闭和用 DSH 打开；展开、收起及内容切换都有过渡。内容通过所属会话的 workspace-files 服务读取，保留相对路径与会话归属，不借用当前窗口的工作目录，也不依赖旧版 `/dsh-files/static/` 路由。无需增加 Artifact 依赖或修改 profile；未安装、尚未加载、不支持的类型或无法挂载阅读面板时，保留 DSH 原生的会话资源打开方式。该适配只接管本插件输出区入口，不修改第三方源码。

封面只读取已声明交付的 HTML（每份上限 **512 KiB**），以 **640×320** 的静态画面等比缩放到 2:1 封面，不执行脚本、不加载外部资源。右侧 HTML 阅读面板使用隔离沙箱，支持自包含页面的内联脚本、样式和 data/blob 图片，禁止访问宿主页面及网络；依赖外部资源的文件可选择用 DSH 打开。阅读文本上限 **2 MiB**、图片 **8 MiB**，CSV 最多显示 500 行数据。过大或读取失败时显示可重试的说明与原生打开入口。折叠输出模块时不启动新封面读取，关闭阅读面板、切换会话或卸载时取消未完成的内容请求并释放图片 URL；不保存文件或聊天内容到偏好。深色、窄屏和全部轮次视图沿用卡片材质与布局。

阅读面板有独立的 React 异常边界。预览组件异常时取消读取并回到原生文件打开方式，顶部会话入口继续显示；页头会话钩子不可用时也保留任务与输出入口。`npm run test:artifact` 在旧版文件路由全部返回 404 的独立测试页中检查真实文件内容渲染，同时覆盖无配套插件、先后加载、原生回退、会话隔离、错误重试、大小限制、窄屏夜间、拖宽、动画中间帧、减少动态效果与资源清理。设置 `DSH_ASAR` 后，额外加载已安装宿主的实际 ConversationHeader、ConversationSessionHeader 与样式，检查刷新后标题、标签、入口，以及可选钩子缺失和预览渲染异常时页头继续显示。设置 `DSH_ARTIFACT_CLIENT` 为已安装 `dsh-artifact-preview` 的 `lib/client.js`，可加载配套插件实际代码验证兼容；未设置时使用接口契约夹具。截图位于 `DSH_CLAUDE_OUTPUT_DIR/artifacts/`，这些是独立页面测试，不代表正在运行的桌面客户端已验收。客户端更新后在 DSH 中按 **Ctrl+R** 刷新；配套插件首次安装需按其说明重启宿主。

全部轮次中的**任务按轮次分组**，先显示所有分组的任务总数与完成数，每组再显示完成数/任务数，最近一组默认展开，其余可分别展开。每轮只取最后一次有效 `todo/write` 的任务列表，更新和重排不额外累加；新轮次没有写任务时不会继承上一轮的列表。不同轮次的同名任务仍各自保留，历史未完成状态不会冒充当前正在执行；仅当前轮次真实活跃的工具使用调用中动效。任务分组开合与范围切换带动画，减少动态效果和强制颜色时直接切换。

工具明细按用途配上不同的 SVG 图标和简短分类：命令、编辑、读取、图像、进程、交互、检索、协作、计划；例如 `ops_bash` 使用终端图标，`write`／`edit` 使用文件编辑图标，`read_image` 使用图片图标，`job_kill` 使用进程图标，`ask_user` 使用对话图标。每行保留原工具名、调用次数和状态，未知工具归为“其他”并使用通用扳手图标。收起的摘要默认显示工具箱，调用中随最新活跃工具切换对应图标；分类只改变展示，不改变统计、折叠记忆或各材质适配。

点击摘要可展开或收起工具明细，查看各工具调用次数和状态。明细使用高度伸缩、渐隐、位移及轻微模糊过渡，收起后高度归零，不留下空白；条目错开进入，连续切换可从当前画面反向过渡。明细内不增加滚动条，超出窗口时沿用整张卡片的滚动兜底。明细开合以 `toolDetails` 布尔值保存，跨会话、刷新和同一浏览器的其他窗口继续沿用；仅保存展示选择，不保存工具名或调用参数。

**轻量玻璃（CSS 适配版）**是四种卡片样式之一，和透明玻璃并列保留，方便实际体验后自行选择。它用柔和亮边、静态高光与 2px 背景模糊呈现玻璃观感，不生成 SVG 位移贴图、不做鼠标或触摸追光；深色底增加遮盖以提高亮图背景上的可读性。透明玻璃继续保留真实边缘折射和动态追光。两种类型都沿用明暗独立文字配色、栏目布局、文件预览与开合偏好，选择即时生效并以 `cardStyle: "css"` 独立保存。切换到轻量玻璃后，透明玻璃的折射在材质过渡结束时释放；减少动态效果时立即完成，强制颜色模式下改用系统颜色。实现由本插件独立编写，未引入第三方源码或运行依赖。

小圆按钮统一使用 **Lens 清透边缘**，移除旧的蓝色实底、按钮毛玻璃和向下字形投影。按钮中央直接透出浏览器真实背景，边缘使用 Lens WebGL2 的折射、色散和追光；没有 WebGL 时保留透明中心和 CSS 亮边。图标改用宿主的明暗前景色，按下／录音状态使用主题强调色，保持清晰可读。

鼠标悬浮只增强中性亮边与随指针移动的反光，不显示蓝色悬浮框；按下时调整内缘明暗，不移动或缩放原生按钮。蓝色焦点提示只在键盘聚焦时显示，录音／切换状态只改变图标强调色。

## 全局动效风格

插件统一使用偏 macOS 的克制动效：大面板柔和停稳，小开关和选中条带轻微弹性；展开与收起沿同一空间方向，连续操作尽量接续当前画面。设计参考 Apple 官方 [Motion](https://developer.apple.com/design/human-interface-guidelines/motion)、[Animate with springs](https://developer.apple.com/videos/play/wwdc2023/10158/) 和 [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。以下参数是本插件的 Web 适配，不是 Apple 系统内部参数。

共享参数保存在 `src/motion.js`：快捷反馈 180ms、小控件 220ms、材质 240ms、内容与面板 280ms、模型回复 300ms，列表错开 24ms。大区域使用无回弹的临界阻尼弹簧，小控件回弹幅度低于 1%；颜色和退场使用统一缓动。支持 CSS `linear()` 的浏览器使用预先采样的弹簧曲线，其他环境回退到贝塞尔曲线。曲线由 CSS/WAAPI 播放，不新增持续 JavaScript 帧循环；现有动画会在完成、反向切换、减少动态效果或卸载时按各自生命周期清理。

设置卡片错开进入；侧栏按钮移除夸张放大和扩散圆环；消息改为短距离上浮，无末段回落。减少动态效果、强制颜色、输入焦点、草稿、原生滚动及玻璃材质开关继续沿用已有规则。

## 开屏动效

宿主的启动顺序是：创建隐藏的桌面窗口 → 启动后端 → 显示前端加载页 → 挂载未绑定会话的首页 → 工作区、会话列表就绪后恢复上次选择 → `Session.openState` 从 `loading` 进入 `open` → 历史与真正的输入栏就绪。首页的中央输入框可能只是恢复期间的临时状态，`data-content-phase="active"` 本身也不代表历史已经读完。

页面首次可见时先出现独立欢迎层，默认上方柔和呈现宿主原生 **DSH Logo**，下方用本机“**萝莉体**”（内部字体名 **Lolita**）写出“**欢迎回来**”，书写约 **1.7 秒**，停留 **200ms**。浅色主题使用统一黑色 Logo 和墨迹，深色主题反白以保持清晰。Logo 直接使用宿主导出的路径和比例，不在插件内复制品牌素材。最终字形直接由原生字体渲染，书写路径从小尺寸字形中估算，用遮罩逐步显露；字体文件本身不提供真实笔顺。欢迎层无需等待会话 DOM 挂载，遮住恢复期间短暂出现的首页输入框；原生窗口按钮和侧栏开关保持原位。不复制或打包本机字体，无外部字体、图片或网络依赖；其他电脑未安装该字体时使用系统字体。

在 **设置 → UI动效美化 → 开屏欢迎** 中可独立开关、选择“Logo ＋ 书写欢迎”或“动图 / 短视频”。书写模式可单独隐藏 Logo、修改欢迎文字（最多 **32 个字符**，支持完整的 `DeepSeek Harness`）、填写其他已安装字体名，并选择 **轻快 1.2 秒 / 适中 1.7 秒 / 舒缓 2.4 秒 / 慢速 3.2 秒 / 更慢 4.0 秒** 的书写速度。文字和字体编辑后离开输入框即自动保存，下次刷新或启动生效；关闭欢迎层不会禁用新消息等其他动效。局部“播放欢迎预览”使用相同字体与笔迹参数，不覆盖当前聊天。配置沿用插件本机展示偏好，刷新和多个窗口保持同步。

素材模式支持上传 **GIF、APNG/PNG、WebP、MP4、WebM**，提供“完整显示 / 铺满裁切”、更换及移除素材。文件不超过 **20MB**，视频不超过 **15 秒**；每边不超过 **4096px**，总面积不超过 **830 万像素**。建议使用 1080p 以下、2–5 秒的素材。短视频静音播放一次，动图按设置播放 **2 / 3 / 5 秒**，随后淡出并衔接中间内容、输入框、左侧栏入场；素材模式不叠加 Logo 或欢迎字。素材缺失、读取超时或无法解码时自动回退为书写欢迎，始终可点击或按键跳过。无效或超限文件不会替换已保存的素材。

上传文件以 Blob 保存在当前设备、当前 DSH 页面来源的 **IndexedDB** 中，不发送到服务器；本机偏好只保存模式、适配、时长和版本标识。清除该来源的浏览器数据会删除素材，换设备或切换到不同来源需重新上传。设置中的素材预览默认冻结为静态画面，点击播放才持续解码；播放结束、窗口隐藏、关闭设置、跳过开屏和卸载时均释放视频、计时器及临时 URL。视频和动图会增加解码与显存开销，设置中用**红色“较高开销”标签**标注；全屏素材退场只淡出，不附加全屏模糊。

书写期间并行观察真正内容：只读订阅 `uiWorkspace.selection` 判断是否恢复上次会话，再由原生 Header 的 `useSession` 提供 `openState`；未获得该状态时，使用原生历史加载提示兜底。**欢迎层不等历史加载**：写完固定停留 **200ms**，文字轻微上移、淡出，背景用 **300ms** 退去。内容已就绪时，中间内容延后 **70ms**，用 **300ms** 上移 **12px**、淡入；输入框延后 **220ms**，用 **420ms** 上浮 **24px**、从 **3px** 模糊变清晰；侧栏分组延迟 **340–436ms**，每组错开 **24ms**，从左侧 **22px** 处用 **420ms** 进入。默认速度下欢迎层约 **2.2 秒**内退去，全部入场约 **2.8 秒**；历史较慢时先显示原生加载状态与可用控件，真正内容到达后补入场，输入框和侧栏不重播。已确认 `open` 的空会话不会因空历史提示继续等待。插件不改写上次会话、不发起会话选择，也不接管历史加载。

每个页面只播放一次欢迎与入场；之后切换会话、主题、设置或重新启用插件不重播，刷新页面才重新准备。后台窗口等首次可见再播放；恢复目标尚未出现时只暂时遮住未绑定会话的首页输入框，有 **6.5 秒**首页兜底，不延长欢迎层。迟到内容的观察上限 **30 秒**，期间主界面可正常使用。点击“跳过”、欢迎层空白、原生控件或按键都会立即释放欢迎层与动画，键盘事件继续交给原来的控件，不改焦点、草稿、选区或滚动位置。减少动态效果、强制颜色、不支持动画或动画异常时直接展示。隐藏窗口、离开页面和卸载都会清理观察器、计时器、恢复标记与动画，不留下内联尺寸或合成层提示。

字形计算只在启动和设置预览时短暂运行，单字使用 **160×128** 的临时画布，骨架收缩最多 **24 轮**、路径最多 **48 条**；重复字形在当次绘制内复用，不增加常驻绘制循环。长历史和密集视图不创建整段历史的动画层；超过 **1.5 个窗口高度**或 **400 万物理像素**时，只在视口内做 **4 次**命中检查，最多让 **4 个可见消息块**轻微入场，不枚举全部历史。单个动画对象最多检查 **96 个后代节点**。输入框和导航独立入场；内容突然增长时立即取消大图层。

`npm run test:startup` 使用独立页面与已安装宿主的 AppFrame、ConversationRoot、HeroShell、SidebarRoot、InputBar 样式，检查真实中间帧的笔画、三组入场顺序、位移和模糊，以及自然播放、固定侧栏按钮、首次交互、草稿/选区/滚动保持、首页和普通面板、延迟挂载、异常退出、单次播放及卸载恢复，并验证本机 Lolita 字形、黑墨与深色反白、自定义文字和速度。`npm run test:welcome` 验证实际设置入口、无原生 select/checkbox/radio/range、配置保存、键盘、跨窗口同步、连续预览、窄屏、辅助功能和关闭设置后的清理。`npm run test:welcome-media` 使用合成 GIF、带音轨 MP4 和 WebM 验证本机存储、真实播放帧、静音单次播放、素材替换、文件限制、适配、异常回退及解码资源释放；设置 `DSH_ASAR` 后同时核对已安装宿主的真实 Logo。测试不刷新正在运行的 DSH 聊天。排查实际客户端时，可只读查看 `window[Symbol.for('dsh-ui-beautify.startup-status.v2')]` 的阶段、退出原因、笔画和入场计数；该对象不保存会话 ID 或聊天内容。

宿主“首次点击长期没有窗口”属于桌面壳层：原版 `createMainWindow` 创建隐藏窗口，后端就绪才显示，期间的再次激活也会被忽略。`scripts/desktop-startup-feedback.mjs` 可检查或在桌面版完全退出时应用等长补丁，提前显示原生加载窗口、允许加载中再次唤起，不改变后端、登录或更新流程。默认只读；应用需显式 `--apply`、`--asar` 和位于源码库外的 `--backup-dir`。锚点、进程或完整性检查失败会拒绝写入。补丁会被应用升级覆盖，应纳入客户端补丁库维护；其效果是提前给出窗口反馈，后端本身的初始化耗时仍然存在。

## 顶部视图切换动效

顶部“对话 / 轨迹 / 上下文”使用一条持续挂载的液体指示条：在 **280ms** 内前缘先拉伸流向目标，细尾随后收拢，左右切换都有水滴形变；连续反向点击会接续当前的位置、宽度与轮廓。指示条按宿主原生底线的边距、高度和基线定位，并换算页面缩放与祖先变换，避免动效偏移。形变仅作用于底线的小型 SVG 路径。轻量视图同时淡入、沿切换方向轻移 **14px**，内容过渡仅使用透明度和位移，避免整页模糊的栅格开销。仅装饰宿主的 `data-conversation-tabs`，内部详情页的其他标签不受影响。

长对话、密集上下文和高分辨率的大页面自动只保留指示条动效，内容由宿主直接切换。内容区定位复用缓存，固定控件检查最多读取 **96 个节点**；超过 **1.5 个窗口高度**或 **400 万物理像素**的内容不创建动画层，动画中途内容突然增大时也会立即释放。检查节点数不会随历史消息数量增长，不复制聊天记录、不创建快照。

原生按钮和视图仍由宿主控制，输入框、草稿、焦点、选区和滚动位置保持原样；含固定定位控件的视图使用淡入，保持控件的定位基准。初次加载、切换会话、流式追加和重复点击已选标签不重播；减少动态效果或强制颜色时直接显示，卸载会还原原生指示条并取消所有临时动画。

`npm run test:tabs` 可从 `DSH_ASAR` 读取已安装宿主的 ConversationSessionHeader、DefaultConversationViews 组件和 ConversationRoot 样式，检查液体形变的多个中间帧、双向水滴与细尾、缩放/分数边框/横向滚动下的实际底线对齐、自然播放、快速反向切换、嵌套会话隔离、延迟挂载、键盘操作、滚动与输入保持、明暗/窄屏/RTL、辅助功能和卸载恢复。性能回归使用 **1.08 万节点**的长对话与密集内容，断言样式读取有上限、常规同步复用定位、重内容只动画指示条，以及高像素密度和内容增大时释放大图层。设置 `DSH_TABS_PROFILE=after` 可另输出定位查询次数、样式读取次数、动画层尺寸和帧间隔，保存在 `performance-after.json`。会话和内容均使用本地演示数据，不刷新正在运行的 DSH 聊天；截图和指标位于 `conversation-tabs/`（可通过 `DSH_CLAUDE_OUTPUT_DIR` 指定输出目录）。

## 对话分轮卡片

在 **设置 → UI动效美化 → 对话动效 → 对话分轮样式** 可选择 **默认 / 轻盈卡片 / 极简分隔**，默认排在最前并保留宿主外观。轻盈卡片用浅底色、细边框与 20px 圆角（窄屏 18px）区分轮次；极简分隔只增加留白与 1px 分隔线，不绘制整轮底板。两种样式在明暗主题下独立配色，不再跟随侧栏材质。

两种样式均不使用背景模糊、折射滤镜、阴影、Canvas 或持续动画。保留宿主的原始消息节点、轮次锚点、文件和复制操作；不包裹、复制或移动聊天内容。轮次之间保留 **24px** 间距，正文沿用宿主配色。轻盈卡片仅在内容尺寸变化时更新对应底板高度；极简分隔不观察或测量内容高度，流式文字不触发全历史扫描，空闲时没有持续帧循环。

升级保留原有开关：之前关闭分轮玻璃的仍使用默认外观，之前打开的迁移为轻盈卡片；新安装默认关闭。内部保留 `turnGlass` 作为开关字段，新增 `turnCardStyle` 独立保存 `soft` / `line`，选择默认时保留上次样式。

### 分隔装饰自定义

选中“极简分隔”后，可在“自定义分隔装饰”里选择原始细线、彩色细线或“艺术字”。艺术字使用左侧逐字轻晃的 **DeepSeek Harness** 与一条分隔线；右侧内置鲸鱼娘已移除，设置预览和聊天正文均不再显示，也不再预留人物高度。旧的“鲸鱼娘与艺术字”选择自动沿用艺术字，颜色和动效偏好保留；默认仍为原始细线。不叠加第二条线，不改变宿主正文里的进度/表格边框。

动效仅在装饰自身进入可见区域、页面前台且系统允许动态效果时播放；离屏、关闭动效和减少动态效果时暂停，没有持续 JavaScript 帧循环。普通细线模式仍不测量回复高度；艺术字保留紧凑的轮次间留白，不覆盖文字或操作。

“导入自己的动图”支持 2MB 以内且边长不超过 1024 像素的 GIF、APNG/PNG 和 WebP；只有主动导入后才显示右侧图片并预留高度。素材保存在本机 IndexedDB，设置只记录版本号，不写入文件内容或本地路径；暂停时使用静态预览并释放动图播放源，可一键移除自定义动图，恢复纯艺术字与分隔线。

“CSS 自定义”支持 `.line`、`.brand`、`.letter`、`.mascot` 和 `@keyframes`，点击“应用 CSS”后保存。每个装饰都有独立的 Shadow DOM，CSS 不会改到消息、设置按钮或其他插件。可用下面的规则调整颜色、字重和右侧角色尺寸；不支持 `@import`，动图使用本地导入入口。

```css
.line { height: 2px; background: linear-gradient(90deg, #79b7e7, #c9a3e7); }
.brand { color: #849fd0; font-weight: 800; }
.divider { --divider-mascot-width: 118px; --divider-speed: 2.2s; }
```

`npm run test:turn-divider` 检查装饰替换、字母/摆脚中间帧、CSS 隔离、动图保存和暂停、窄屏、设置保存与卸载。截图在 `DSH_CLAUDE_OUTPUT_DIR/turn-divider/`。

新轮次使用 280ms 渐入与轻微上移，历史加载、同轮续写以及待发送消息转为正式消息不重复播放。减少动态效果时停用入场过渡，强制颜色模式使用系统底色与边框。`npm run test:turn-cards` 检查实际卡片尺寸、间距、动画中间帧、长对话开销、原生操作、设置开关与卸载清理；设置 `DSH_ASAR` 可读取本机宿主的 ChatView 样式和公开标记验收，内容使用合成消息。截图保存在 `DSH_CLAUDE_OUTPUT_DIR/turn-cards/`。

## 对话动效

选择默认时，会同时清除底板、轮次间距、临时尺寸与定位高亮；消息节点重建或保留旧界面后也不会恢复旧装饰。已关闭时重新出现的旧消息节点不会绘制底板，重新启用前会先清理旧标记。

分轮样式支持**双击快速定位**：双击正文或卡片空白区，将这一轮对齐到聊天可视区顶部约 24px；受滚动边界限制时停在最近可达位置。向前、向后的跳转均使用 **300ms** 平滑滚动，并配合底板或分隔线的轻微位移，目标以中性细边提示。连续双击其他卡片从当前滚动位置继续，不回到上次起点；滚轮、触摸、滚动按键、其他点击、切换会话或窗口失焦立即停止。按钮、链接、输入框、代码区与已有控件的双击行为保持原样。减少动态效果时直接定位，选择默认或卸载时移除监听与临时样式；各聊天列独立滚动，仅在这段跳转期间按帧更新位置。

发送消息、模型回复使用类似聊天软件的新消息入场：用户消息从右下方约 18px 上浮，约 280ms；模型回复从左下方约 16px 上浮，约 300ms。两者淡入并从 0.99 倍平滑恢复至原大小，平稳停下，不再有末段回落。仅改变透明度、位移和轻微缩放，不改变消息高度，也不接管原生滚动或输入焦点。首次发送进入新会话同样适用。

模型的空白回复节点等待第一段实际内容出现后入场一次，后续流式字词和段落正常追加。待确认的本地消息被正式记录替换时不会重复入场；打开会话、加载历史、翻看旧轮次和同一消息重挂载保持直接显示。新消息若正等宿主滚动到可见区域，最多等待 600ms，由可见性观察器触发，不逐帧轮询、不改滚动位置；正在阅读历史或仍不可见的消息不补播。

在 **设置 → UI动效美化 → 对话动效 → 新消息入场动效** 中关闭或开启，默认开启，独立于任务面板和玻璃样式，保存为本机 `messageMotion` 展示偏好。点击同一区域的 **播放预览**，可用相同动画参数直接比较消息和回复的效果，不发送消息。系统开启“减少动态效果”或强制颜色模式时直接显示；切换会话、关闭动效和卸载插件会取消临时动画。实现只记录当前页面的消息标识与节点，不复制聊天内容，不创建消息快照，不添加持续帧循环或第三方动效依赖。

验证：`npm run test:messages` 从本机 DSH 的原生定义读取 `assistant-step` 标记，并实际渲染其 `AssistantMarkdown` 组件，验证新建过程分组内的流式首段不会被误当历史。另覆盖首次发送、待确认消息替换、历史与同轮补载、稳定标识重挂载、插槽 `display:contents`、会话切换、动效开关、减少动态效果、强制颜色和卸载清理。`test:composer` 检查设置中的预览确实使用同一组 280/300ms 动画。截图输出到 `.scratch/claude-beautify/<版本>/message-motion/`（设置 `DSH_CLAUDE_OUTPUT_DIR`），不入库。

## 内容来源

- **进度**：最新轮次订阅当前 Session 的 `todos` projection，历史轮次从该轮已加载的 `todo/write` 事件还原最后清单，以 `turn/start` 确认边界，空轮不继承上一轮的任务。默认展示当前步骤附近的 3 步（可设为 2 步），其余分为“先前步骤”和“后续步骤”独立折叠，记住各组开合。比较每次清单的步骤文字和顺序，在运行过程中真正新增或调整计划且正在看最新轮次时触发保持展开；仅改变状态不触发。首次看到的已有清单作为基线，单纯运行状态变化或工具/输出记录不触发。没有任务清单时隐藏整块进度；关闭按钮保留在首个有内容的栏目右侧。
- **输出**：仅展示所阅读轮次已记录的 `deliverables/presented` 文件，点击交给 DSH 的文件预览；不会从聊天正文或写文件工具猜测交付物。PNG、JPEG、WebP 与 GIF 会先读真实字节做缩略图：通过 `remote.workspaceFiles` 的 `stat`/`readBytes` 取文件（超过 4 MB 或读取失败就退回短类型字标），对象 URL 随卡片卸载释放；其余类型显示 ZIP、MD、MP4 之类的三字母字标。
- **本次会话中已使用**：读取所阅读轮次已加载的工具调用及结果，迟到的工具结果仍归入原调用所属轮次。Skills 和记忆文件读取只在成功后展示，网页搜索及 GitHub 保留独立资源行；普通工具按名称聚合为默认收起的一行摘要，明细列出调用次数、未返回调用和失败次数。调用 ID 去重，PTC 的开始、结算与重放不会重复计数；同名并发调用未全部返回时仍标为进行中。资源和计数都按所阅读轮次隔离。

只借用 DSH 已有的 Session binding 和已加载记录，不新开会话，不主动翻页或额外拉取历史，不读写磁盘聊天日志，也不执行工具。历史轮次是否加载由宿主的滚动和轮次导航决定；无法确认该轮边界或记录尚未加载时显示不完整提示，不拿其他轮次的内容填充。可用的部分资源基于已加载记录展示。任务与轮次快照只留在当前浏览器内存，不保存聊天副本、不上传；本机仅保存展示偏好。

原生任务节点仍由 DSH 的 React 管理；会话侧卡成功挂载后只隐藏原生清单，关闭插件会恢复原位。若当前宿主没有可用的页眉插槽，则保留 0.1 版本的原生任务清单定位方案，该回退卡片同样沿用所选材质；关闭插件后清理材质标记与样式，恢复原生清单外观。

- Node.js 22.13 或更高版本。
- DSH Desktop，已验证安装包内 `@deepseek-ai/dsh-client-ui-conversation` 0.2.1-rc.2 的 TodoPanel。

## 安装与启用

将仓库放在长期保留的工具源码目录，然后执行：

```powershell
node scripts/profile.mjs install
node scripts/profile.mjs check
```

默认接入 `$env:DSH_HOME` 或用户目录下 `.dsh` 的 `desktop` profile，可用 `--profile <名称>` 指定其他已有 profile。

安装器建立 `node_modules` junction，登记 `link:` 依赖、锁文件及 `dsh.profile.bundles`，通过包内 `cordis.patch.yml` 挂载；**不改用户 patch 层**。重复安装幂等，遇到已被占用的插件目录或不认识的锁文件结构会停止并保留现场。

**首次增加插件后，需要完全退出 DSH（包括托盘）再启动**，让宿主重新发现客户端插件图。之后只改 `client.js` 时，通常在 DSH 窗口按 `Ctrl+R` 刷新即可。重启前应等当前任务结束。

打开 **设置 → UI动效美化**：

- 本页独立管理右上角任务面板与底部输入栏的样式。独立插件 `dsh-claude-slider` 使用自己的“推理滑块 (Claude)”设置入口，两个插件互不托管，无需合并补丁。
- 设置页与「设置管理」保持相同的视觉规范：图标与 21px 页标题、16px 圆角卡片、20px / 22px 卡片留白、灰调子区块、轻阴影、42px × 24px 自绘开关，以及同一套菜单边框、主题色和动效。页面分别组织任务面板、输入栏、侧栏与消息动效；材质预览、性能标记、键盘操作和深色 / 窄屏适配继续保留。
- 启用或关闭右上角任务面板；关闭后立即恢复原位置。
- 鼠标悬停入口即可预览，移入卡片可继续操作；点击入口可固定展开。
- 手动打开或悬停预览时，点击面板外部即可带动画收起；排步骤时自动展开的面板只能点 X 关闭。点击到的外部控件仍正常响应。同一聊天的右侧轮次导航保持卡片打开，并以动画切换对应轮次的内容。
- 每轮实际安排新任务步骤时卡片自动下拉，直到点 X 才关闭；点 X 后本轮不再反复弹。切换聊天后返回仍保留自动展开的关闭规则，普通手动打开及悬停预览分别处理。
- 调整面板宽度（280–480 px，默认 320 px）；窄屏自动缩小。
- 在“卡片样式”中选择带边缘折射与高光的透明玻璃、轻量玻璃、毛玻璃或原始的默认样式，切换立即平滑生效，并记住选择；材质选择支持方向键、Home 和 End。进入设置时因外部点击已收起的卡片，会在选择材质时临时展开供预览；点击已选材质也能重新预览。预览期间编辑本页其他设置不会关掉卡片，关闭设置结束临时预览，保留原本固定展开的状态；没有内容或已禁用时保持隐藏。临时预览不写入展开记忆。
- 设置进度默认显示 2 或 3 个步骤（默认 3）；先前步骤和后续步骤分别折叠，开合及步数选择都会记住。
- 点击各栏目标题独立展开或收起，卡片随内容平滑调整高度；栏目内无滚动区。开合选择自动保存，刷新和下次打开继续沿用。
- 普通工具默认显示一行摘要，点击摘要查看明细；明细开合自动记住，当前调用和失败提示在摘要中可见。

## 输入栏样式配置

在 **设置 → UI动效美化 → 输入栏外观** 中直接选择样式，顺序与任务面板一致：**默认、透明玻璃、轻量玻璃、毛玻璃**。默认就是关闭美化，恢复宿主输入栏原来的外观，不再提供重复的“输入栏美化”开关；透明玻璃保留真实背景边缘折射与动态追光；轻量玻璃使用 CSS 柔和亮边、静态高光与 2px 背景模糊；毛玻璃使用 22px 背景模糊。选择即时生效。

输入栏里的**模型选择按钮，以及附件、麦克风、语音、发送／停止等圆形按钮**由同一区域的 **小按钮玻璃材质** 开关独立控制。开启时按钮使用清透 Lens，不继承输入框的染色或模糊；模型按钮展开的菜单和模型列表使用同套玻璃亮边与半透明背景，增加轻微背景模糊，保证文字、搜索与选项清晰。关闭时恢复原生按钮和菜单，并释放全部按钮画布与绘制场景。可搭配任意输入框样式，包括“默认输入框 + 玻璃小按钮”和“玻璃输入框 + 原生小按钮”。原生尺寸、圆角、位置、禁用状态及点击行为保持不变，模型名与下拉箭头保持清晰；权限选择器与其他弹出菜单保留原样，不接管模型选择、录音、语音或发送逻辑。模型按钮与小按钮共用绘制场景，模型菜单复用 CSS 玻璃材质，不增加独立 WebGL 场景。

同样兼容可选的 `dsh-claude-slider` 模型选择器：它替换了宿主原生按钮，且菜单没有原生的 ARIA 关联，因此按它自身的模型按钮标签和同一组件内的 `.dcs-model-menu` 定位。模型按钮使用上述 Lens 亮边，点开的模型列表使用半透明背景、12px 背景模糊与短暂的淡入、位移和轻微缩放；推理强度按钮及其面板继续由滑块插件管理。关闭小按钮玻璃或卸载美化插件会还原，滑块的错误恢复按钮不会被当作模型选择器。未安装滑块时仍走宿主原生适配，不新增运行依赖。

设置 `DSH_SLIDER_CLIENT` 为已安装 `dsh-claude-slider` 的 `lib/client.js` 后，运行 `npm run test:slider-glass` 可使用配套插件实际代码检查识别、模型选择、草稿保持、开关恢复、明暗窄屏、禁用状态与菜单中间帧。测试只使用独立页面和合成模型目录，截图保存到 `DSH_CLAUDE_OUTPUT_DIR/slider-glass/`。

开关以 `composerButtonGlass` 保存，支持刷新、跨窗口同步及新挂载的输入栏。首次升级保留旧版的按钮外观：此前使用玻璃输入框的开启，默认输入框的关闭；之后切换输入框材质不再改动按钮开关。新安装默认关闭小按钮玻璃。

每个输入栏的按钮共用一个局部 WebGL2 场景，范围只覆盖按钮行；变化后按需绘制，空闲不持续绘制。Lens 边缘使用当前局部背景色，中央直接透明，不捕获聊天文字、草稿、图片或视频，也不生成整页截图。离屏、关闭按钮玻璃、强制颜色和卸载时释放相关资源。上游 MIT 模块保存在 `vendor/lens/`，适配代码在 `src/lens-actions.js`；修改后运行 `npm run build:lens` 生成客户端内嵌代码，`npm run check:lens` 核对一致性，运行时不加载远程脚本。

设置页在三组材质旁标注相对开销：透明玻璃和毛玻璃为较高开销；轻量玻璃为较低开销，但输入栏开启小按钮玻璃时显示为中等开销。面板宽度标注面积影响，对话延伸标注滚动时的叠加开销，侧栏与消息入场标注短时开销；另说明日夜按钮和任务运行状态有小范围持续动画。标注不是设备跑分，实际负担取决于显卡、分辨率、窗口大小和背景变化。希望节省资源时可选“轻量玻璃 + 关闭小按钮玻璃”。

**较高开销使用红字、淡红底及红色细边框标注**，深色模式使用更亮的红字；低、中等及短时开销保持中性色。标注仍保留文字说明，强制颜色模式遵循系统配色。

外观同步会跳过无关插件节点和普通流式段落；控件挂载、材质、主题及相关滚动仍正常更新。小按钮的几何与局部背景没有变化时，不重新上传纹理或启动绘制；改变位置只更新几何，改变尺寸、局部颜色或主题才更新对应资源。未变脏的空输入槽不重复显示和测量。透明玻璃贴图只在边缘计算曲面，中间填充中性法线，保留原有像素输出与贴图尺寸上限。

`npm run test:performance` 验证不变按钮行重复同步 20 次不上传纹理、不重启 GPU 绘制，空槽重复同步 30 次不改变显隐或重新测量，无关节点更新和流式段落追加不触发全套外观扫描，同时检查鼠标追光、背景变化、按钮替换、移动、改宽、动态材质挂载和卸载。它记录隔离夹具中的 API 调用次数，不代表整机 CPU/GPU 占用率；`npm test` 另核对四种尺寸的贴图与优化前逐像素输出一致。

**默认材质下的运行开销**：材质选择默认不会停用粒子背景或历史轮次跟随。历史消息索引现在只在消息结构、轮次或显隐变化时重建；滚动通过二分查找定位，600 条消息每次只需约 9–10 次消息位置读取，普通流式段落和其他面板滚动不再重扫历史。粒子按定时器申请绘制帧，占用变化时保留最多 30 帧/秒（Canvas 2D 24 帧/秒），稳定汇聚时降到 12 / 8 帧/秒；鲸鱼娘完整成形后仍以此低频率游动，Logo 和自定义 SVG 完整成形后停止连续绘制，占用、主题、尺寸或素材变化时恢复。CPU 回退跳过透明粒子的轨迹与圆点绘制，不改变粒子数量偏好。

`npm run test:reading-performance` 使用 600 条合成消息检查位置读取上限、流式追加、无关滚动、隐藏行、原生轮次导航和末尾跟随。`npm run test:particle-performance` 检查 WebGL2 / Canvas 2D 的空闲帧、完整成形休眠、重复同步、暂停、恢复、减少动态效果、尺寸更新和卸载。指标保存在 `DSH_CLAUDE_OUTPUT_DIR/reading-performance/` 与 `particle-performance/`；这些是隔离浏览器的调用计数，不代表运行中 DSH 的整机占用率。

任务卡片与输入栏分别保存选择，支持方向键、Home、End、刷新和同一浏览器的其他窗口同步。新设置默认使用原始外观；已有材质选择继续保留，旧版关闭开关的状态迁移为默认，旧版仅开启轻量玻璃且没有材质字段的状态继续对应轻量玻璃。旧 `composerGlass` 字段只用于读取迁移，之后仅保存材质选择，不保留隐藏的开关。只需在 DSH 按 **Ctrl+R** 加载更新。

点击或聚焦输入栏时保持所选玻璃的中性亮边，不切换为蓝色描边；浅色、深色及三种玻璃材质一致。文字、光标颜色与按钮的键盘焦点提示沿用宿主设置。

**对话延伸到输入栏后方**位于同一区域。输入栏选择**默认**样式时，这项会自动关闭并恢复宿主底部遮罩；旧设置中“默认样式 + 开启”的组合也按关闭处理。玻璃样式下可手动开启或关闭，切回默认后再选玻璃不会自动重新开启。开启后移除进行中聊天底部的不透明渐变，滚动中的对话能透过玻璃到达输入栏下方的工具按钮一排；关闭后立即恢复宿主遮罩。开关以 `chatUnderComposer` 布尔值保存，支持刷新与跨窗口同步，与任务面板开关独立。只改变遮罩背景，沿用宿主已有的滚动范围、输入栏位置和末尾留白，最后一条消息仍可完整滚到输入栏上方。新建会话首页、需要阻挡交互的输入栏覆盖层保留原来的背景；强制颜色模式下使用不透明系统背景。

样式只作用于聊天底部 `data-composer-seat` 内的 `data-composer-card`，保持尺寸、圆角、文字与光标颜色，不替换编辑器或注册输入、发送、粘贴、附件和拖放事件。新会话和重新挂载的输入栏自动继承选择，不读取或保存草稿。使用内侧描边保持几何尺寸，无装饰遮罩覆盖按钮。仅透明玻璃创建背景 SVG 折射和追光；切换到其他样式后释放，默认和关闭时移除材质标记并恢复宿主外观。减少动态效果时直接切换，强制颜色模式下玻璃材质使用系统背景；卸载时清理样式并恢复原标记。

`npm run test:composer` 使用独立测试页覆盖四种样式及键盘选择、开关、编辑器和选区保持、组合输入状态、合成消息发送、文件选择/拖放、模型菜单、刷新/跨窗口、动态挂载、明暗窄屏、辅助功能及卸载恢复。按钮场景验证实际 WebGL2 渲染、四按钮共享的局部画布、透明中心、无实色底／旧 SVG 滤镜、原生大小／位置、前景可读、禁用点击、键盘焦点及默认释放；语音按钮只切换合成状态，不申请麦克风权限。对话延伸开关另以输入栏底部工具行的真实像素变化验证，并核对滚动位置、尺寸与末尾留白不变、首页及覆盖层不受影响。设置 `DSH_ASAR` 后，在内存中核对已安装宿主的公开标记并使用真实 InputBar 与 ConversationRoot 样式；编辑交互仍是合成夹具，不向正在运行的聊天发送消息或上传文件。截图保存在 `composer/`。

## 白天与黑夜主题

聊天顶部右侧工具区提供 **70 × 30 CSS px 的玻璃日夜开关**，位于任务进度入口旁。白天显示太阳与轻移的云，黑夜显示月亮与闪烁星点；点击或聚焦后按空格、Enter 即可切换，玻璃圆钮在两端平滑滑动。

页面使用 **600ms 从按钮位置展开的圆形主题过渡**，搭配轻微淡入与无回弹、缓缓收住的弹簧曲线，减轻全屏突然变黑或变白的感觉。小圆钮仍使用共享的 280ms 反馈，通过独立的 View Transition 图层移动和交接太阳、月亮。全屏时长是本插件针对大面积颜色变化的调整，并非 Apple 系统的精确参数；曲线预先生成，由 CSS/WAAPI 播放，不增加持续 JavaScript 帧循环或额外全屏模糊。连续点击以最后一次选择为准，不排队；动画结束或插件卸载后清除临时图层名和状态。浏览器不支持 View Transitions 时，背景过渡也放慢至 600ms，保留小开关的反馈；系统启用减少动态效果或强制颜色时直接切换。

主题读写使用 DSH 原生 `theme.getTheme()`／`theme.setTheme()` 与 `theme/change` 事件，和宿主的外观设置保持一致，其他窗口及系统跟随状态也会同步到按钮。首次点击后保存为明确的浅色或深色选择，不另建主题配置，不修改聊天、草稿或任务数据。原生主题服务不可用时隐藏入口，任务面板继续工作。

`npm run test:theme-switch` 检查按钮材质与位置、原生接口调用、真实页面过渡和圆钮移动的中间帧、键盘、连续切换、刷新及跨窗口同步、空会话、任务面板关闭、减少动态效果、强制颜色、兼容回退、失败恢复和动画中卸载清理。截图位于 `theme-switch/`。

可选输入插件未渲染可见控件时，会自动收起它的活动槽和多余间隔；异步加载或重新显示控件后恢复原间距。空壳、隐藏按钮不会占位，已显示但暂时禁用的按钮及纯文本状态仍保留。动态变化使用 240ms 宽度、间距及渐隐过渡，减少动态效果时直接切换；卸载美化插件后恢复宿主原结构。

## 兼容边界

依赖 `conversation.session.header.utilities` 插槽和 Session projection/event source 接口。轮次识别结合 `turnOutline` projection、轮次导航的 `nav button[data-index][aria-current="true"]`，以及 `data-chat-following-tail`、`data-chat-turn`、`data-chat-flow`、`data-slot="conversation.chat.flow"`、`data-conversation-scroll` 等稳定 DOM 标记；导航未提供当前标记时按聊天滚动容器内的阅读位置回退。只观察宿主状态，不改写其滚动记忆或私有 store。

原生回退方案依赖稳定 DOM 标记 `data-testid="todo-panel"`、`data-conversation-content`、`data-conversation-session`、`data-composer-seat`，不依赖构建生成的 CSS 类名。未来宿主若移除原生定位标记，回退方案会保留原清单位置；轮次接口或标记变化时，需要重新核对历史内容跟随行为。

面板以浮层展示，展开时会覆盖右上角的一部分聊天内容。手动打开时可点击面板外部、页眉入口或关闭按钮收起；自动展开时只能点 X 收起。也可在设置中禁用面板。浏览器偏好按设备保存；不会把展示偏好同步到服务器。输出反映声明而非永久文件副本，源文件删除后预览由 DSH 报告错误。

这是独立的 DSH 扩展，与 Anthropic、Claude 或 DeepSeek 官方没有隶属关系。入口使用宿主提供的官方 Logo 组件，不额外复制或打包其品牌资源。
