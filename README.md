# DSH Claude Beautify

为 DeepSeek Harness 提供受 Claude 桌面版启发的右上角会话侧卡，展示进度、输出和本次使用的工具与资源。

面板入口位于**当前聊天列**右上角，显示文件图标与数量。空闲时默认收起，**鼠标悬停入口即可下拉展开，无需点击**。悬停预览在移出入口和卡片 220ms 后开始收起，经过 **180ms 渐隐、轻微上移和向上收合**后移除；跨过入口与卡片的间隙或返回卡片会取消收起，退场途中返回也会从当前画面平滑恢复，保留原卡片和缩略图。键盘焦点位于卡片内时会保持显示。点击入口可固定展开，再次点击、关闭按钮或 Escape 可收起；触屏和键盘保留点击操作。

每轮推理开始时仍自动下拉展开并保持显示，有内容时才出现入口；本轮手动收起后，后续任务更新不再反复弹，下一轮推理重新展开。悬停预览不改写各会话的固定展开状态，切换会话会清理预览及待收起计时。白色卡片、细边框与布局参考 Claude 桌面版，支持深色主题和窄屏自适应。

工作时入口显示“第 X 步，共 Y 步”，随当前任务更新。进度区统一使用 8px 小圆点：已完成为灰色实心，进行中为黑色实心，待处理为灰色空心；已完成和待处理文字统一灰色，进行中文字加深为黑色并稍加字重。全部完成后末步也保持灰色实心，不再单独放大或显示对勾。深色主题下进行中改用亮色，其他步骤保持灰色，维持相同的突出层级。

运行中当前步骤的圆点有轻微的中性光晕呼吸，实心部分保持不透明；文字保留从左向右扫过的柔和白光，每 2.4 秒一轮，表示正在处理。白光只出现在运行中会话的进行中条目上，任务完成或会话停止运行后恢复静态文字。较早步骤折叠，默认保留当前步骤前的两步及后续步骤。

下拉以 240ms 的垂直揭示配合轻微位移、渐显完成；每轮推理会重播一次，卡片已打开时也会重播。动画不抢焦点，不重建输出缩略图。悬停退场中的卡片退出键盘与辅助技术交互，切换会话、禁用插件或新一轮推理会取消旧退场。开启系统“减少动态效果”时直接展开、收起，并停用圆点呼吸和文字扫光。系统强制颜色模式下也停用扫光，保留可读的静态文字。

默认宽度 **320 CSS px**，正文和标题 **13px**，次要文字 11–12px，内边距 16px。进度、输出、本次会话中已使用分为三个栏目，标题旁各有箭头，可独立展开或收起，栏目内不设滚动区。卡片高度随展开内容自然变化，全部收起时只保留标题和分隔线；整卡仅在超过窗口可用高度时滚动兜底。比例按同尺寸的 Claude/DSH 桌面截图对比后调整，避免宽度和字号被放大。

栏目和“先前步骤”的折叠均使用 **280ms** 的高度缓动，配合内容渐隐和箭头旋转，卡片、下方步骤与栏目同步平滑伸缩；连续点击会从当前高度反向过渡。历史步骤保持挂载，收起后从键盘导航和辅助技术中隐藏，近期步骤节点不因历史开合重建，输出缩略图也不会重新加载。系统开启“减少动态效果”时直接切换。

**进度、输出、本次会话中已使用的开合状态会自动记住**，作为本机通用展示偏好，重新打开面板、切换会话、刷新或重启后继续沿用；再次手动展开或收起会更新保存值。悬停预览和每轮推理的自动展开不会覆盖这些选择。没有保存记录时三个栏目默认展开，旧版启用开关和宽度设置可直接兼容；同一浏览器的多个窗口同步展示偏好，任务内容仍按会话隔离。

## 内容来源

- **进度**：订阅当前 Session 的 `todos` projection，折叠较早的已完成步骤，点击“先前步骤”展开。以 Session `running` 从空闲到运行的转换识别新一轮推理；若内容稍后才到，届时补做下拉，不显示空卡片。没有任务清单时隐藏整块进度；关闭按钮保留在首个有内容的栏目右侧。
- **输出**：仅展示已记录的 `deliverables/presented` 文件，点击交给 DSH 的文件预览；不会从聊天正文或写文件工具猜测交付物。PNG、JPEG、WebP 与 GIF 会先读真实字节做缩略图：通过 `remote.workspaceFiles` 的 `stat`/`readBytes` 取文件（超过 4 MB 或读取失败就退回短类型字标），对象 URL 随卡片卸载释放；其余类型显示 ZIP、MD、MP4 之类的三字母字标。
- **本次会话中已使用**：读取当前 Session 已加载的工具调用及结果。Skills 和记忆文件读取只在成功后展示，失败或进行中的工具标明状态；重复工具去重。

只借用 DSH 已有的 Session binding，不新开会话，不额外翻页读取历史，不读写磁盘聊天日志，也不执行工具。历史没有完全加载时显示“基于已加载的会话记录”。任务数据只留在当前浏览器内存，不另存、不上传；本机仅保存展示偏好。

原生任务节点仍由 DSH 的 React 管理；会话侧卡成功挂载后只隐藏原生清单，关闭插件会恢复原位。若当前宿主没有可用的页眉插槽，则保留 0.1 版本的原生任务清单定位方案。

## 环境

- Node.js 22.13 或更高版本。
- DSH Desktop，已验证安装包内 `@deepseek-ai/dsh-client-ui-conversation` 0.2.1-rc.2 的 TodoPanel。
- Git；测试需要开发依赖和 Chrome（或通过 `PLAYWRIGHT_CHANNEL` 选择本机其他 Playwright 浏览器渠道）。

插件运行本身没有额外 npm 依赖，React 由 DSH 提供。

## 安装与启用

将仓库放在长期保留的工具源码目录，然后执行：

```powershell
node scripts/profile.mjs install
node scripts/profile.mjs check
```

默认接入 `$env:DSH_HOME` 或用户目录下 `.dsh` 的 `desktop` profile，可用 `--profile <名称>` 指定其他已有 profile。

安装器建立 `node_modules` junction，登记 `link:` 依赖、锁文件及 `dsh.profile.bundles`，通过包内 `cordis.patch.yml` 挂载；**不改用户 patch 层**。重复安装幂等，遇到已被占用的插件目录或不认识的锁文件结构会停止并保留现场。

**首次增加插件后，需要完全退出 DSH（包括托盘）再启动**，让宿主重新发现客户端插件图。之后只改 `client.js` 时，通常在 DSH 窗口按 `Ctrl+R` 刷新即可。重启前应等当前任务结束。

打开 **设置 → Claude 美化**（与推理滑块插件共用的同一个设置项）：

- 上半部分是推理滑块的设置页（由 `dsh-claude-slider` 提供，本插件负责托管）；下半部分是本插件的任务面板设置。
- 启用或关闭右上角任务面板；关闭后立即恢复原位置。
- 鼠标悬停入口即可预览，移入卡片可继续操作；点击入口可固定展开。
- 每轮推理开始时卡片自动下拉展开；本轮手动收起后不再反复弹，下一轮再展开。
- 调整面板宽度（280–480 px，默认 320 px）；窄屏自动缩小。
- 点击各栏目标题独立展开或收起，卡片随内容平滑调整高度；栏目内无滚动区。开合选择自动保存，刷新和下次打开继续沿用。

## 与推理滑块插件合并

`dsh-claude-slider`（npm 第三方）原本自己注册一个“推理滑块 (Claude)”设置项，和本插件的“Claude 美化”并排。为了让侧栏只留一个入口，本插件把它的设置页嵌进自己的设置项里渲染，它则不再单独注册。

这需要在它的客户端 bundle 里做两处小改（导出设置页组件、在有人托管时不再注册自己的 section）。补丁脚本是幂等的，装完或升级 npm 包后执行一次：

```powershell
npm run patch-slider     # 打补丁（已打过会提示 already patched）
npm run check-slider     # 核对补丁是否还在，缺失时退出码为 1
```

如果补丁丢了，设置项会退回两项、且合并页里显示“推理滑块插件未启用”，面板设置不受影响；重新执行 `npm run patch-slider` 即可恢复。本插件没有装 `dsh-claude-slider` 时同样显示提示，不会报错。

## 卸载

```powershell
node scripts/profile.mjs uninstall
```

只移除本插件的链接、依赖、锁记录与 bundle 条目，保留仓库和其他插件，然后完全重启 DSH。运行中禁用本插件的客户端实例会清理观察器、样式和定位标记。

## 状态与产物

- 展示设置：当前浏览器 `localStorage["dsh-claude-beautify:settings:v1"]`，只保存启用开关、面板宽度及三个模块的开合布尔值，不含会话标识、任务文本、文件名或聊天内容。
- 安装前的 profile 配置备份：工作区 `data/dsh-claude-beautify/install-backups/`，不入 Git。可通过 `DSH_CLAUDE_DATA_DIR` 更改。
- 渲染测试截图：工作区 `outputs/dsh-claude-beautify/`，不入 Git。可通过 `DSH_CLAUDE_OUTPUT_DIR` 更改。
- 不创建聊天缓存、任务副本或后台服务。

## 兼容边界

依赖 `conversation.session.header.utilities` 插槽和 Session projection/event source 接口。原生回退方案依赖稳定 DOM 标记 `data-testid="todo-panel"`、`data-conversation-content`、`data-composer-seat`，不依赖构建生成的 CSS 类名。未来宿主若移除这些标记，回退方案会保留原清单位置。

面板以浮层展示，展开时会覆盖右上角的一部分聊天内容，可点击页眉入口收起或在设置中关闭。浏览器偏好按设备保存；不会把展示偏好同步到服务器。输出反映声明而非永久文件副本，源文件删除后预览由 DSH 报告错误。

这是独立的 DSH 扩展，与 Anthropic、Claude 或 DeepSeek 官方没有隶属关系；不包含它们的商标图片或专有资源。
