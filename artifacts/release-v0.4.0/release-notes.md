dsh-UI美化 0.4.0 整合本轮完成的组件、背景与对话美化功能，并包含已完成的全屏快捷键图标对齐修复。

- 设置采用组件布局、全局布局、对话布局三组两级分类；工具栏支持排序与显示配置。
- 统一侧栏、输入栏、任务卡及图标材质，补齐回车、回复、详情、状态与会话切换过渡；侧栏收放保留粒子状态。
- 开屏支持字符 Logo、单文件代码、动图/视频，明暗主题独立记忆；背景参数、窗口/全屏宽度分别保存。
- 整合内置鲸鱼娘 51 个动作、动图包导入与思考文案；仅打包实际运行 WebP 素材，未附原始 PNG 或用户素材。
- 配置导入导出、恢复默认及撤销；任务卡 Artifact 阅读与交付登记提示。交付提示可通过宿主配置 deliverableNudge: false 关闭。

验证：52 组回归全部通过（665 项检查输出，含兼容别名重复执行）；实际 DSH 设置页与 51 个动作接入通过，运行客户端与发布文件一致。

兼容声明：DSH >=0.2.1-rc.2、<0.3.0，Node.js >=22.13。已验证 Windows / Chrome 与本机 Electron；其他平台尚未作实机保证。玻璃、背景和高密度粒子的实际性能取决于场景与设备。安装不执行构建钩子，无运行时 npm 依赖。

安装：下载 dsh-ui-beautify.tgz 后通过 DSH 插件管理安装，按提示重载。完整功能与边界见仓库 docs/RELEASE-0.4.0.md。升级保留本机偏好与导入素材；旧无保护实例请完全退出 DSH 后重开一次。
