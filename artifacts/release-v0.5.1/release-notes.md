# dsh-UI美化 v0.5.1

修复回车发送、左侧栏开合与“思考”展开时的跳动和卡顿，升级保留现有偏好与导入素材。

- 多行草稿回车后，正文与输入框收起连续衔接；桌面端卡片外观改用位移动画，减少长草稿清空时的停顿，并修复行替换时的错位与回跳。
- 侧栏开合按钮不再在起步帧强制计算全部图标布局；玻璃风格下，左上按钮组的位置与尺寸保持稳定。
- 在对话底部展开“思考”等详情时，被点击标题保持原位，内容向下展开；滚轮、触摸和翻页键可立即接管滚动。

发布检查：220 个 JavaScript 文件语法检查、132 项 Node 回归、客户端构建复现及安装包内容检查通过。浏览器与真实桌面界面验收未在本次发布重复执行；开发实测与完整范围见仓库 `docs/RELEASE-0.5.1.md` 和 `docs/validation-0.5.1.json`。

安装：在 DSH 插件安装入口使用本 Release 的 `dsh-ui-beautify.tgz`；带版本的 `dsh-ui-beautify-0.5.1.tgz` 内容相同。`SHA256SUMS.txt` 提供校验值。已安装 0.5.0 的客户端刷新即可；从更早版本升级时，需按 0.5.0 说明完整重启一次以载入文件服务。

本版不包含工作区尚未发布的“镜海”背景等实验内容，已有版本、标签和安装包不覆盖。
