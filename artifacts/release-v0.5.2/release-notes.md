# dsh-UI美化 v0.5.2

修复启动后与切换会话后首次回车发送仍会出现的跳动，升级保留现有偏好与导入素材。

- 切换会话后首次发送，宿主渲染新行占用主线程期间正文不再整体下跳；滑动从屏幕当前位置连续接上。
- 宿主短暂移除回显消息再插入正式行时，对话不再先落一行再弹回；被替换的行与相邻行同步滑动。
- 收录：页头“…”菜单开合动画、任务面板三个模块开关、输入栏上拉菜单透明度。

发布检查：219 个 JavaScript 文件语法检查、131 项 Node 回归、发送协调（13 个场景，含新增回显空档与长任务续接）及输入栏 / 消息动效浏览器回归、客户端从发布源码重建、安装包内容检查均通过。开发实测与完整范围见仓库 `docs/RELEASE-0.5.2.md` 和 `docs/validation-0.5.2.json`。

安装：在 DSH 插件安装入口使用本 Release 的 `dsh-ui-beautify.tgz`；带版本的 `dsh-ui-beautify-0.5.2.tgz` 内容相同。`SHA256SUMS.txt` 提供校验值。已安装 0.5.x 的客户端刷新即可。

本版不包含工作区尚未发布的“镜海”背景等实验内容，已有版本、标签和安装包不覆盖。
