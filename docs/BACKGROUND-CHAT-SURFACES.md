# 自定义背景下的聊天表面

「已编辑文件」卡片的表头常态保留高亮底色，悬停时不再额外变亮；表头下方、文件行之间及展开入口上方使用细分隔线。列表正文继续透明，跟随明暗主题，保留原生预览与键盘焦点。

启用「全图背景」后，行内代码、原生「已编辑文件」卡片、消息中的文件附件与交付文件卡片会使用随明暗主题变化的半透明底色，替换突兀的纯白填充。交付文件卡片按宿主的 `data-presented-file` 标记适配，使用更柔和的灰蓝填充和克制的悬停亮度；图标底座与操作区也降低白色填充。卡片标题、文件路径和底部消息操作沿用宿主正文／次要文字语义颜色，增删数量保持明确的正负标记和适合当前主题的颜色。

样式不增加额外背景模糊或常驻绘制。原生文件列表展开／收起、差异预览入口、键盘焦点与单文件卡片保持原有行为；长行内代码可在窄屏换行，文件路径沿用原生省略处理。关闭自定义背景后立即恢复原样，不改写任何设置或素材。

适配只作用于聊天中的行内代码、文件附件、文件改动卡片及消息操作区；代码块和其他插件设置保留各自样式。减少动态效果与强制颜色可用。

设置 `DSH_ASAR` 后运行 `npm run test:background-surfaces`，从本机安装包临时读取原生 ChangedFiles 组件与样式，在内存中加载并以合成会话核对明暗、窄屏、列表交互、键盘、强制颜色及关闭背景恢复。测试与截图默认保存到集合目录 `.scratch/`，不保存真实会话、运行配置或导入媒体。

`npm run test:background-presented` 使用安装包内真实的 `PresentedFileCard` 组件和 `Deliverables` 样式，另外核对双卡片布局、窄屏单列、独立预览／文件按钮、悬停提示、打开中与失败状态。保留宿主的原有卡片几何、状态动效和操作，不依赖宿主构建生成的类名哈希。
