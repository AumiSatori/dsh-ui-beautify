# 纯背景模式

聊天顶部主题切换右侧的图片图标打开「纯背景模式」，替换此前保留聊天文字的「专注阅读」行为。

开启后，聊天文字、表格、工具记录、输入框、项目名、顶部标签、两侧面板和浮动预览一并淡出，只保留背景、已有粒子效果与右上角并排的两个小卡片：黑白主题切换和退出。两张卡片同为 44px 淡色方框、圆角和阴影一致，明暗主题各一套配色；黑白切换转发到宿主的主题切换按钮，不需要重新绑定主题服务。点击退出卡片或按 Esc 返回。打开的菜单和对话框先处理各自的 Esc。

模式开启时移除插件背景层的模糊，图片／视频／HTML 背景按原铺放和位置清晰显示。退出后自动恢复保存的背景可见度和模糊值，不改写设置。第三方 HTML 文件内部自行绘制的效果仍由该文件决定。

切换只隐藏界面分支，不替换或重新加载背景与粒子画布，不改变聊天区占位和保存的窗口宽度。隐藏界面不能聚焦或点击；退出后恢复原来的草稿、选区、阅读位置和辅助功能属性。背景与粒子的移动继续遵循原有开关、可见性和减少动态效果设置；本模式没有常驻绘制循环。

只在当前页面生效，刷新、离开聊天页面或停用插件后恢复普通界面。未配置背景时显示当前主题底色。

设置 `DSH_ASAR` 后运行 `npm run test:focus`：使用本机原生顶部组件、完整插件和合成媒体，检查文字全隐藏、无模糊、背景／粒子节点保留、连续反向、草稿与选区恢复、窄屏、减少动态效果、强制颜色、长会话的空闲行为和卸载清理。`test:focus-header`、`test:focus-performance` 兼容入口执行同一套包含顶部及长历史覆盖的专项验收。截图和结果放在集合目录 `.scratch/`。
