# 自定义开屏

设置 → dsh-UI美化 → 全局布局 → 开屏欢迎。

- **默认 · Logo 字符填充**：使用宿主的 Harness 鲸鱼 Logo 轮廓，以真实字符填充并逐行显现。可修改填充字符和速度。没有图片底层，完成后不保留绘制循环；旧版书写模式会自动迁移到这里。
- **自定义代码**：像 HTML 自定义背景一样，粘贴代码或导入单文件 HTML、CSS、JavaScript。导入后可先预览，点击“应用代码开屏”才保存。代码和动图素材各自保存，切换类型或恢复默认不删除素材。
- **动图 / 短视频**：保留现有 GIF、APNG、WebP、MP4、WebM 播放方式。

明暗主题分别记忆开屏类型、素材、代码、速度、铺放与开关；旧的单套偏好会先沿用到两种主题。媒体按版本保存在本机，切换主题或替换日间素材不会覆盖夜间素材。

## 代码文件约定

文件不超过 2MB。HTML 可以包含内嵌 CSS 与 JavaScript；单独的 CSS 或 JavaScript 会被包成 HTML 文档。图片、字体、视频与第三方库需内嵌，不能引用外部网址、相邻文件、CDN、Node.js、DSH 服务接口或模块入口。

渲染区域等于当前窗口可用区域（排除桌面标题栏）。使用 `vw`、`vh`、`clamp()`、弹性布局或 Canvas 的 `innerWidth` / `innerHeight` 随窗口变化。文件本身写死的像素坐标不会自动转换为响应式布局。

代码完成时可调用：

```js
window.dshWelcomeDone()
```

不调用也会按设置的最长播放时长（3–15 秒）退场。播放完成后由美化插件淡出并衔接原生界面；按 Escape 或点击“跳过”随时退出。资源加载失败、代码出错或素材缺失时回到默认字符 Logo。减少动态效果与强制颜色下不运行开屏。

代码存储在单独的本机 IndexedDB，不写入普通设置，不与背景库混用。只在明确播放预览或启动时创建隔离 iframe；不允许读取宿主 DOM、存储或网络。预览完成、停止、切分类、隐藏页面、关闭设置或卸载时移除 iframe、消息监听和计时器。

## 与参考项目的关系

[LeeRolling/dsh-chat-wallpaper](https://github.com/LeeRolling/dsh-chat-wallpaper) 提供“开机动画 → 全屏视频 → 淡出 → 聊天背景”的衔接。该项目本身不是通用代码开屏加载器，其客户端入口依赖 DSH ModuleLoader、服务端接口，以及另一插件的离场信号，不能把 `lib/client.js` 直接导入为开屏文件。

本次沿用独立前景开屏、结束后露出聊天背景的结构；使用美化插件自己的生命周期，不额外安装参考插件。若同时启用其他全屏开屏插件，仍可能产生叠层与时序冲突，应只让一套插件管理开屏。

## 验证

`node test/welcome-code-browser.mjs` 检查字符 Logo 与真实宿主轮廓、字符中间帧、文件导入和本机持久化、独立背景状态、预览结束资源释放、宿主与网络隔离、误发完成消息、代码错误回退、窗口缩放、明暗/窄屏/键盘焦点和减少动态效果。默认字符、媒体播放、恢复默认与完整客户端构建另有回归。
