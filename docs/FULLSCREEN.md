# F11 全屏

在 DSH 主页面按 F11 进入全屏，再按 F11、Esc，或点击左上角「退出全屏」返回窗口。全屏不自动记为下次启动状态。使用浏览器与 Electron 支持的标准 Fullscreen API，不修改安装包或创建窗口控制服务。

全屏时收起 Windows「应用 / 编辑」菜单和标题栏留白，左上角保留原生侧栏按钮；侧栏收起后保留原生新会话按钮，退出全屏按钮排列在它们右侧。点击结果和侧栏动效仍由宿主处理，不复制按钮，不重新挂载对话。退出后恢复窗口布局。输入草稿、选区和全屏/窗口各自的内容宽度记忆保持原有逻辑。

只接管没有修饰键的 F11；按住按键不反复切换，不接管输入法组合键、其他插件已经处理的快捷键，或正在独立全屏的产物与视频。浏览器自身的原生窗口全屏继续交给浏览器退出。暂时拒绝全屏时显示简短提示，可再次尝试。

## F11 不会因为一次异常就失效

进出全屏依赖原生窗口过渡：桌面宿主把窗口全屏状态镜像到 `<html data-fullscreen>`，这个镜像可能比 HTML 全屏退出更晚；Electron 的窗口过渡也可能让一次请求迟迟不返回。连按几下、正好卡在过渡中间时状态会短暂对不上。控制器因此按下面几条工作，任何一种情况都能在下一次按键恢复：

- **请求有时限**：一次全屏请求只占住 450ms，随后自动放开；另有看门狗在最迟约 0.9 秒后重新对齐状态，不会留下永久的「请求中」标记。
- **桌面里由自己说了算**：识别到桌面宿主（`window.dshDesktop` 或桌面 UA）时，不用宿主的全屏镜像否决 F11 —— 桌面唯一的窗口全屏来源就是本插件的 HTML 全屏，残留标记最多让样式慢半拍，不会再挡住按键。
- **浏览器仍交给原生**：浏览器里继续把无修饰键 F11 让给浏览器自己的窗口全屏，并接受 `display-mode: fullscreen` 与宿主标记；只在「上一次让出之后状态毫无变化」时接管一次，避免残留状态把 F11 永久锁死。
- **残留标记自清**：退出全屏后若插件标记还在、文档其实已不在全屏，同步时清掉它，不残留全屏样式。
- **失效的产物全屏不挡路**：别的元素仍挂着全屏但节点已不在文档里时，先退出它再响应 F11，而不是一直拒绝。
- **焦点回来就对齐**：窗口重新获得焦点时同步一次状态。

验证：`DSH_ASAR` 指向当前安装的 DSH `app.asar`，运行 `node test/fullscreen-browser.mjs`。该验证使用安装版原生 AppFrame / SidebarRoot 组件和样式，内容、草稿均为演示数据；覆盖 F11 进退、连续按键、侧栏反向、重新挂载、原生新会话、产物全屏兼容、拒绝重试、残留全屏标记、永不返回的全屏请求、窄屏、明暗、键盘焦点、减少动态效果、强制颜色及卸载清理。
