# 页头菜单过渡

会话页头的文件夹按钮旁下拉、含“下载 Session 日志 / 反馈”的“…”更多操作菜单，以及更多会话视图菜单有展开、关闭动画。打开时淡入、位移和轻微模糊一起过渡，关闭时接续当前画面退场。快速开关会从正在显示的状态接回。

子智能体和后台任务列表保留宿主原来的底色、边框、阴影、字体和透明度，开合只使用位移与缩放，动画结束后释放临时变换。此前添加的淡入、淡出与模糊过渡已从这两处移除。

子智能体入口支持再次点击收起，键盘 Enter 或空格重复激活也可收起。悬停展开、点选子会话、点击外部和 Escape 仍沿用宿主操作。修复会调用原生关闭处理，同时清理固定展开状态、悬停计时器并恢复焦点。

菜单内容、定位、应用选择、点击外部关闭、Escape 和焦点操作仍由宿主处理。宿主立即卸载菜单时，只短暂保留不可交互、对辅助技术隐藏的视觉副本，退场后删除，不延迟实际关闭。

同时识别宿主挂到 `body` 的弹层和渲染在页头内的菜单；后者从实际按钮识别，保留原生定位。只在操作该页头菜单期间观察对应页头，关闭后解除，不添加正文子树监听。

减少动态效果、强制颜色、窗口隐藏、关闭美化或卸载插件时停止并清理动画。

此功能随 0.4.5 发布。单独更新客户端动效时刷新 DSH 界面即可加载；从 0.4.4 升级整个插件时，须完整重启 DSH，以载入同版新增的文件剪贴板服务。

验证使用已安装宿主的原生菜单、`SessionLogDownloadHeaderAction` 和文件夹组件与合成数据，在独立无头浏览器中检查开合中间帧、快速反向、下载/反馈回调、点击外部和键盘关闭、明暗主题、小窗口、减少动态效果、页头观察范围与资源清理：

```sh
npm run test:header-menu-motion
npm run check:lens
```

测试需通过 `DSH_ASAR` 指定已安装宿主的 `app.asar`。没有自动操作正在使用的 DSH 桌面窗口。
