# 页头菜单过渡

会话页头的文件夹按钮旁下拉与“…”更多菜单加入展开、关闭动画。打开时淡入、位移和轻微模糊一起过渡，关闭时接续当前画面退场；快速开关会从正在显示的状态接回。

菜单内容、定位、应用选择、点击外部关闭、Escape 和焦点操作仍由宿主处理。宿主立即卸载菜单时，只短暂保留不可交互、对辅助技术隐藏的视觉副本，退场后删除，不延迟实际关闭。

减少动态效果、强制颜色、窗口隐藏、关闭美化或卸载插件时停止并清理动画。动效只处理这两个页头菜单，不接管设置页、消息右键或其他浮层。

开发目录更新后刷新 DSH 界面即可加载。已发布的 0.4.4 包不包含这次未发布的增量。

验证使用已安装宿主的原生菜单组件与合成数据，在独立无头浏览器中检查开合中间帧、快速反向、点击外部和键盘关闭、明暗主题、小窗口、减少动态效果与资源清理：

```sh
npm run test:header-menu-motion
npm run check:lens
```

测试需通过 `DSH_ASAR` 指定已安装宿主的 `app.asar`。没有自动操作正在使用的 DSH 桌面窗口。
