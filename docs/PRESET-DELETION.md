# 本机预设与素材删除

开屏历史（包括本机示例）、最近上传的图片/视频/HTML 背景、保存的配置预设及每个导入动图包均有独立的「删除」按钮。开屏媒体、粒子图片与 SVG 的删除也使用同一确认提醒。

删除入口使用卡片末端的红色小纸篓，开屏位于卡片右侧内部，背景与名称、铅笔同排。图标 16px，点击热区至少 44px。点击后先显示完整名称、影响范围、「取消」与「确认删除」。默认焦点在取消，Esc 可取消并返回删除按钮；处理期间阻止重复提交，失败后保留确认和错误，允许重试。支持明暗主题、窄屏、减少动态效果及强制颜色。

- 开屏历史删除会清理内容相同的重复记录及日夜、定时/交互四个槽位的引用；正在使用的开屏恢复默认字符 Logo，编辑草稿保留。刷新后已删除项不会重新出现。
- 背景删除会移除原文件和历史索引，清理日夜配置中的当前及上一张引用；使用该素材的一侧关闭背景，其他背景保留。「清除背景」仍仅取消当前选择，保留素材库。
- 配置预设删除只移除该快照及快照中的备份，不改变当前已应用设置与素材。
- 删除导入动图包时一并移除包内素材；仅当正在使用它时切回默认鲸鱼娘。
- 内置的系统恢复入口（「默认值」、默认鲸鱼娘）保留；导入和本机保存的条目都可删除。

删除无法撤销，需要保留的素材应先通过全局配置导出备份。

验证：`node --test test/preset-delete.test.mjs test/welcome-theme.test.mjs test/welcome.test.mjs`；`npm run build:lens`、`npm run check:lens`。浏览器验证使用集合目录 `.scratch/ui-preset-delete/verify-page.mjs` 的合成样例与实际 DSH 设置页，不删除已有素材。
