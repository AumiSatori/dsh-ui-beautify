# 0.4.0 功能与兼容说明

本版以 v0.3.72（2189a39）为稳定基线，整合已接入本机的 UI 开发功能，以及开屏主题记忆、窗口适配、轨迹宽度和会话过渡分支中遗漏的实现。全屏快捷键导致新会话图标上移的修复包含在内。安装包仅含运行文件与实际使用的鲸鱼娘动作包，不含原始 PNG、录制工程、用户素材或运行配置。

## 能调整什么

| 范围 | 可配置内容 | 边界 |
| --- | --- | --- |
| 任务面板 | 开关、独立材质、布局、展开细节、进度与产物展示 | 依赖宿主本轮实际记录；不扫描磁盘或把普通回复猜成交付物 |
| 交付登记提示 | 宿主配置 deliverableNudge 可关闭；deliverableNudgeText 可替换提示内容 | 默认会提醒模型用 present 登记交付文件；不读取或修改用户 AGENTS.md，也不保证模型一定执行 |
| 输入栏 | 默认、透明、轻量、毛玻璃；小按钮材质；对话延伸至输入栏后方 | 关闭入口或样式不改变原生发送、权限和模型行为 |
| 侧栏与工具栏 | 材质、覆盖布局、顶部对齐、右侧收放柄、工具图标顺序与可见性 | 隐藏入口不等于停用功能；未出现的宿主入口不能凭空创建 |
| 对话 | 分轮卡片、分隔、明暗独立气泡、自定义配色与 CSS、消息与详情动效 | 流式文本不逐字重播入场；历史长页面优先保持滚动和性能 |
| 思考动图 | 内置 51 个动作、包/文件夹导入、筛选、随机、大小、透明度、文案与用时位置 | 只替换思考图标与文案，不控制模型思考；用户包留在本机 |
| 开屏 | 字符 Logo、速度；代码或动图/视频；明暗独立选择、启用状态、铺放与时长 | 页面来源内保存；代码需单文件内嵌资源，不能访问宿主或网络 |
| 背景与粒子 | 明暗独立背景、透明度、模糊、铺放、声音；粒子种类与密度；纯背景查看 | 设备、分辨率、解码和大面积玻璃决定实际开销；高密度不保证同帧率 |
| 全局配置 | 分类记忆、恢复默认及撤销、配置导入导出、可选本机素材备份、窗口/全屏宽度独立记忆 | 默认导出不携带素材；恢复默认保留已导入文件 |

## 动效与性能

回车后输入框收起、用户消息入场、模型回复和工具行进入、详情展开、任务状态切换、统计浮层、侧栏收放与纯背景模糊切换均使用连续过渡。快速反向从当前帧接回，切换侧栏保留粒子场景。跨会话过渡只作用于受限的可见滚动区域，不复制整份历史。

默认材质不启用额外折射。透明玻璃需要额外绘制；轻量玻璃使用较轻的 CSS；毛玻璃的负担取决于面积和背后变化，不能笼统保证比透明玻璃更快。关闭功能、隐藏页面、切分类与卸载时释放对应资源；减少动态效果与强制颜色采用静态或系统色降级。

## 不能由插件保证的部分

- 宿主 DOM、插槽或原生控件改版，可能需要适配；本版不是对未来所有 DSH 版本的保证。
- 浏览器/Electron 全屏的许可、窗口系统时序、媒体编码支持和设备 GPU 性能由平台决定。
- 偏好及素材按浏览器来源保存；localhost 与其他来源、不同设备之间不会自动共享。
- 第三方开屏、背景、CSS 和 Artifact 插件可能竞争同一层或同一控件；避免同时接管同一功能。
- 原生文件操作依赖宿主能力。本插件不会自动开放文件系统权限，也不会重新启用宿主隐藏的文件卡片预览按钮。

## 发布与回退

版本分支为 release/v0.4.0，标签 v0.4.0 指向实际发布提交。安装包包含已构建客户端，无安装脚本与运行时 npm 依赖。当前兼容声明为 DSH >=0.2.1-rc.2、<0.3.0，验证环境为 Windows / Chrome 与本机 Electron；其他系统未作实机保证。详细结果见 validation-0.4.0.json。

旧实验目录和未提交现场原样保留。本版采用已完成实现；早期自动弹出交付物的原型、重复目录、探针及提高常驻帧率的试验不进入发布。回退可安装旧的 v0.3.72；请先导出配置，旧版可能无法识别新增选项。
