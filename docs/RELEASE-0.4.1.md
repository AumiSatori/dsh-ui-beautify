# 0.4.1 修复版

本次以 0.4.0 为基础，发布已完成的侧栏和顶部布局修复：

- 侧栏收缩时，其他会话完成、等待回答或失败以独立动态图形提醒；点击或展开后退出。提示等收缩完成后再出现。
- 侧栏边缘箭头常驻，展开时顶部“新会话”按钮与下方内容同步淡入。
- 顶部设置入口去重；更多视图按钮保留在标签同行，正文紧贴头部分割线。
- 输出文件图标去掉细框；顶部加粗、加深分割线恢复宿主原生样式。

发布包从已提交源码独立构建。任务面板自动展开和开屏主题行为沿用 0.4.0，未包含本机其他在研功能。

升级保留偏好与导入素材。使用 DSH 插件页现有安装来源更新，按宿主提示重载；源码链接版更新后刷新窗口。安装包不执行构建钩子，无运行时 npm 依赖。

验证结果见 validation-0.4.1.json。安装包随附 SHA256SUMS.txt；许可与兼容范围沿用 0.4.0。
