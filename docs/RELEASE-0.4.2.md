# dsh-UI美化 0.4.2

本版增加本机配置预设、欢迎语与开屏自定义，完善任务面板和对话动效。

- 在“全局配置”中保存当前设置及本机素材，命名并快速切换预设；内置“默认值”预设保留已导入素材，支持撤销上次应用。部分素材切换后需要刷新界面。
- 在“对话布局 → 欢迎语”自定义文字、LOGO、预览版标签和样式，可随机选择文案或通过代码生成文字；提供按时间问候的示例。
- 自定义开屏的定时和交互代码按日夜主题分别保存，支持本机历史切换，并提供手势开屏示例。开屏、背景和气泡标记当前主题及编辑目标；开屏和背景主题卡片可同步切换宿主主题。Desktop 提供可选提前开屏补丁。
- 新增自定义消息入场动画，完善过程分组展开动效；本轮新登记交付物时任务面板自动展开，点击右上角入口可关闭，输出阅读和 HTML 封面也得到改进。
- 顶部更多视图菜单保持在标题行；补充粒子、背景、开屏、主题和输入栏等设置说明。修复夜间主题按钮悬浮对比度不足，以及短对话发送时的滚动补偿抖动。
- 七元素开屏示例只供本机使用，不随插件分发，也不会自动写入预设；用户自己保存的本机代码开屏仍可在历史列表切换。

兼容范围沿用 DSH `>=0.2.1-rc.2 <0.3.0-0`。安装包不包含运行配置、聊天记录、测试输出或用户素材。安装和兼容说明见 [README](https://github.com/AumiSatori/dsh-ui-beautify/blob/v0.4.2/README.md) 与 [交付说明](https://github.com/AumiSatori/dsh-ui-beautify/blob/v0.4.2/docs/DELIVERY.md)。
