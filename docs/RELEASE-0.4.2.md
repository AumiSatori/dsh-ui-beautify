# 0.4.2 流式输出与滚动平滑版

本次以 0.4.1 为基础：

- **流式文字渐显**：回答生成时新文字以平滑的节奏逐字淡入，模型一次吐出的大段约一秒内均匀打完，不再整段或逐字硬跳。在「对话布局 → 对话动效」中开关，可选轻柔、标准、明显三档并播放预览，默认开启轻柔。
- **跟随滚动平滑**：输出过程中已输出的内容按出字节奏匀速上滑；回答结束时尾栏出现不再先跳后回；思考期间往上翻看不再卡顿。
- **多行草稿回车不再抖动**：发送时正文缓动与输入框收缩共用一条时间线。
- 0.4.1 发布后的源码对齐修复（移除仅本机私用的开屏示例、补齐导出、`client.js` 可复现构建）一起发布。

只处理主页面原生对话，DS Bot 等其他插件的界面不受影响。不包裹或改写宿主文本节点、不改排版；减少动态效果和强制颜色时直接显示，回答结束后没有常驻动画。

升级保留偏好与导入素材。使用 DSH 插件页现有安装来源更新，按宿主提示重载；源码链接版更新后刷新窗口。安装包不执行构建钩子，无运行时 npm 依赖。

验证结果见 validation-0.4.2.json。安装包随附 SHA256SUMS.txt；许可与兼容范围沿用 0.4.0。
