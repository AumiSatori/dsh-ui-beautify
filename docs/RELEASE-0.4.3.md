# dsh-UI美化 0.4.3

本版在 0.4.2 的流式输出与滚动平滑功能上，加入本机配置预设、欢迎语和开屏自定义，并修复交互细节。

- **配置预设**：在“全局配置”中命名、保存、切换、重命名和删除本机预设；内置默认值预设，支持撤销应用与含本机素材的配置导入导出。
- **欢迎语与开屏**：欢迎语支持随机文字、代码、LOGO 和样式；定时与交互开屏按日夜主题分别保存，支持手势示例、代码草稿和本机历史。可选 Desktop 提前开屏补丁仍须退出 Desktop 后应用。
- **对话和任务面板**：新增自定义消息入场动画及过程分组展开过渡；新交付物触发任务面板展开后，仍可点击入口关闭；完善输出阅读与 HTML 封面。
- **合并交互修复**：短对话发送不再触发多余的滚动补偿，跨越输入栏边界时继续平滑；保留 0.4.2 流式渐显、跟随平滑和多行输入收缩补偿；侧栏快速反向切换及时改变运动方向，夜间主题按钮悬浮文字更清晰。

升级保留本机偏好与导入素材。插件不分发或自动添加私有开屏示例。安装包无运行时 npm 依赖、无安装期构建钩子。兼容范围为 DSH `>=0.2.1-rc.2 <0.3.0-0`。

60 组自动回归全部通过，记录 710 项检查（含兼容命令别名的重复执行），使用 DSH 0.2.1-rc.3 原生组件和独立无头 Chrome；本轮未操作桌面进行体验验收。

验证记录见 [validation-0.4.3.json](validation-0.4.3.json)，安装与刷新方式见 [README](../README.md) 和 [交付说明](DELIVERY.md)。
