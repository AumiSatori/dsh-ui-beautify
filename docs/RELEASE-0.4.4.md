# dsh-UI美化 0.4.4

修复切到“全局配置”时，下方“配置导入与导出”区域抖动的问题。

- 本机预设异步载入后，列表连同间距平滑撑开，下方区域随高度连续移动。
- 分类切换结束时，先衔接加载后的实际高度，再释放临时高度，避免突然跳变。
- 动画完成、切换分类或减少动态效果时清理动画与临时样式。

6 组针对性回归、137 项检查通过，覆盖即时及延迟载入、深色窄窗口、真实中间帧、快速切页、配置预设及导入导出。本轮使用合成内容和独立无头 Chrome，未操作桌面进行体验验收。详见 [验证记录](validation-0.4.4.json)。
