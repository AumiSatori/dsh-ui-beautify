# dsh-UI美化 0.4.4

本版修复全局配置切页时的抖动和卡片裁切，改进页签与会话切换，提供文件全文复制和动图格式示例下载，并优化视频背景、玻璃滚动与次要文字的可读性。

## 全局配置切页抖动

- 本机预设异步载入后，列表连同间距平滑撑开，下方“配置导入与导出”区域随高度连续移动。
- 切页进场保持已经显示的卡片完整，避免下方区域先露出、又被裁回、再展开。分类切换结束衔接实际高度，并清理动画与临时样式。

## 对话页签下划线

- 原标签下划线两端向中心收至零宽，再在新标签中心向两侧展开，不再拉长滑过标签之间的空隙。
- 收拢约 100ms，展开约 180ms，使用不同的非匀速缓动；双向切换和快速反向点击接续当前画面。

## Artifact 文本复制

- 文本阅读卡片工具栏增加“复制”，复制当前文件的完整原文，保留换行、缩进及空文本。
- JSON、Markdown、CSV 复制原始内容；CSV 预览行数限制不影响全文复制，HTML 提供“复制源码”。
- 复制成功短暂显示“已复制”，失败可重试；切换文件、重新加载或关闭时清理反馈，图片和视频不显示文本复制按钮。

## 思考动图格式示例下载

- 导入区新增“下载格式示例 ZIP”，直接保存包含 `manifest.json`、可播放精灵图、中文制作说明和素材授权的完整示例包。
- 可直接导入 ZIP 或解压后导入文件夹；说明同时提供普通 GIF / APNG / WebP 的制作格式，下载本身不改变当前选择。
- 示例嵌入客户端，保存时无需访问外部网站；构建时复用内置素材并检查说明与 ZIP 一致。

## 背景可读性、滚动与会话切换

- 会话内滚动和思考展开只更新任务面板位置，减少整页同步及重复图标识别；输入栏与玻璃保持原位。
- 切换会话时正文以 300ms 淡入并上移 10px；历史内容晚到时在 900ms 窗口内等待，减少动态效果时直接切换。
- 全图背景默认开启“文字自动加深”，按可见区背景提高次要、三级及说明文字的对比度，保留正文和代码配色及文字层级。图片复用取样，视频使用低频缩略采样，HTML 背景保持原色；关闭开关或背景后恢复原配色。

## 升级与兼容

升级保留本机偏好和导入素材。源码链接版更新后按 Ctrl+R 刷新；安装包用户通过插件管理器更新后按宿主提示重载。安装与刷新方式见 [README](../README.md) 和 [交付说明](DELIVERY.md)。

兼容 DSH `>=0.2.1-rc.2 <0.3.0-0`、Node.js 22.13+。安装包包含预构建客户端，无运行时 npm 依赖或安装期构建钩子。鲸鱼娘示例附带素材来源和授权，建议个人非商业使用。

62 组自动回归全部通过，记录 736 项检查（含兼容命令别名重复执行及单独输出 JSON 指标的性能组）。发布验证记录见 [validation-0.4.4.json](validation-0.4.4.json)。自动回归使用已安装的 DSH 原生组件、合成内容和独立无头 Chrome；真实桌面体验仍待验收。提前开屏和启动反馈是单独的可选宿主补丁，本轮不修改宿主安装包。
