# dsh-UI美化 0.4.4（开发中，未发布）

本版本继续累计修改，收到明确发布指令后再统一创建 Release、上传安装包并核对市场下载。当前记录包含以下两项已合入主分支的修改。

## 全局配置切页抖动

- 本机预设异步载入后，列表连同间距平滑撑开，下方“配置导入与导出”区域随高度连续移动。
- 分类切换结束时，先衔接加载后的实际高度，再释放临时高度；动画完成、切换分类或减少动态效果时清理动画与临时样式。

## 对话页签下划线

- 原标签下划线两端向中心收至零宽，再在新标签中心向两侧展开，不再拉长滑过标签之间的空隙。
- 收拢约 100ms，展开约 180ms，使用不同的非匀速缓动；双向切换和快速反向点击接续当前画面。

合并后 7 组针对性回归、168 项检查通过，验证记录见 [validation-0.4.4.json](validation-0.4.4.json)。本轮使用合成内容和独立无头 Chrome，真实桌面体验仍待验收。
