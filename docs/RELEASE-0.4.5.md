# dsh-UI美化 0.4.5

本版在 0.4.4 上新增文件右键菜单的“复制文件”和“打开方式”，修复文件图标点击，并为页头文件夹与更多菜单增加过渡。

## 文件右键菜单

- 输出行和 Artifact 卡片共用“复制文件”：本机 Windows 将实际文件写入系统文件剪贴板，可粘贴到资源管理器等支持文件粘贴的应用；“复制路径”继续只复制路径文字。
- “打开方式”列出宿主已注册的应用，标记默认项，选择后使用对应应用打开；不更改系统默认关联。宿主缺少能力或没有可用应用时显示说明。
- 操作期间防止重复提交，失败后可重试；关闭或重新打开菜单后忽略过期回调。支持方向键、Home、End、返回和 Esc，长应用列表可滚动，窄屏菜单约束在视口内。
- 文件复制服务仅接受本机窗口请求，验证文件路径与类型，通过隐藏的限时进程写入文件剪贴板；不执行用户路径中的命令。自动测试验证原生文件格式时不改写用户当前剪贴板。

## 文件图标与页头菜单

- 正文文件卡片的应用图标交回宿主原生文件按钮处理，避免点击“打开文件”被图片放大监听误认；原有打开方式下拉继续可用。
- 会话页头的文件夹下拉与“…”更多菜单增加展开、关闭过渡，保留原生定位、操作和键盘行为。减少动态效果或关闭美化时立即释放动效。

## 升级与兼容

**升级后须完整退出 DSH（含托盘）并重新启动一次，以载入新增的本机文件剪贴板服务；仅 Ctrl+R 不足。** 本机偏好与导入素材保留。

“复制文件”仅支持本机 Windows；远程访问与其他系统会提示不可用。“打开方式”使用宿主提供的应用列表和打开接口。真实桌面上的资源管理器粘贴与应用启动单独验收，自动回归不代替实机操作验证。

兼容 DSH `>=0.2.1-rc.2 <0.3.0-0`、Node.js 22.13+。安装包包含预构建客户端，无运行时 npm 依赖或安装期构建钩子。代码与可选素材许可沿用 0.4.4，详见 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)。

64 组自动回归全部通过，记录 768 项检查（含 118 项 Node 检查及兼容命令别名的重复执行）。本次使用已安装的 DSH 0.2.1-rc.5 原生组件、独立无头 Chrome 和合成内容，覆盖菜单、动画中间帧、明暗与窄屏、配置和配套插件集成。发布验证记录见 [validation-0.4.5.json](validation-0.4.5.json)。安装与下载方式见 [交付说明](DELIVERY.md)。
