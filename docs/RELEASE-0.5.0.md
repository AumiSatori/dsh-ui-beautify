# dsh-UI美化 0.5.0

本版以 0.4.6 为基线，整合当前工作副本的文件操作、预设与素材管理，以及连续流式优化。

## 连续流式

- 在「对话布局 → 对话动效 → 流式文字渐显」中增加「连续流式优化」，默认开启，可关闭对照原来的吐字节奏和滚动路径。
- 小批文字使用更快的基础跟进速度，随积压量平缓追赶；按完整字素处理表情与组合字符，复用尾部文字节点并及时清理高亮范围。
- 流式跟随采用可连续衔接的弹簧轨迹。普通长回答超过单行绘制预算时，改用附近的内容块；过大的代码、表格、媒体和思考块继续使用原生滚动。
- 保留宿主 Markdown、真实滚动位置、手动阅读和减少动态效果的控制方式。关闭优化会保留共用的文字缩短及资源清理修复。

## 预设与素材

- 开屏历史、背景素材、配置预设、导入动图包、粒子图片与 SVG 使用统一的删除入口和就近确认，显示名称、影响范围及错误反馈。
- 删除开屏历史会同步清理重复记录及明暗主题、定时和交互模式的引用；删除背景会清理相关选择引用，其他素材保留。
- 删除配置快照不改变当前已应用设置；删除正在使用的导入动图包时恢复默认动图。系统默认项保留。
- 本版安装与启动不会自动执行任何素材或预设删除。具体删除范围见 [预设与素材删除](PRESET-DELETION.md)。

## 文件操作

- 输出与 Artifact 文件菜单增加重命名和移入 Windows 回收站，提供文件名校验、同名保护、重复操作限制、取消及错误反馈。
- 文件操作服务只接受本机请求，不提供文件夹操作；修复 Desktop 转发请求缺少 Origin 时本机文件复制服务不可用的问题。
- 新服务需要完整重启 DSH，单独刷新页面无法载入服务器入口。

## 检查与升级

本次按用户要求由用户自行进行功能、界面及性能验收。发布只执行 JavaScript 语法、客户端构建与导出一致性、差异和安装包内容检查；未重新运行功能回归，不宣称性能提升幅度或已确认没有功能影响。实际执行记录见 [validation-0.5.0.json](validation-0.5.0.json)。

升级保留现有偏好与导入素材。预构建包没有运行时 npm 依赖或安装期构建钩子；兼容范围与 0.4.6 相同。已有版本、标签及发布产物保持不变。
