# dsh-UI美化 0.5.1

本版以 0.5.0 为基线，修复回车发送、左侧栏开合与「思考」展开时的跳动和卡顿。不新增设置项，升级保留现有偏好与导入素材。

## 回车发送

- 修复 0.5.0 起开启流式跟随时，多行草稿回车后正文先停住约 300ms、输入框收完才追上的问题；收缩期间正文从当前画面连续滑到落点。
- 修复发送过程中某一行被替换或参与动画的行变化时，个别行错位或整屏一帧回跳约 12px 的问题。
- 输入框从多行收回时，真实布局一次到位，只让卡片外观副本用位移下滑。宿主会把输入区高度写入整段对话继承的变量，原先逐帧改变高度会让整页每帧重算样式（桌面端每次约 30ms）；长草稿清空时主线程被占用，动画也不再停顿或跳落。
- 发送时不再在每次 React 提交中强制排版，只在对话行增删时取样；会话切换仍立即取消。

## 左侧栏

- 点击侧栏开合按钮时不再立即重算全部图标布局，起步帧不再多出约 20ms 的强制排版。
- 玻璃图标风格下，左上角的切换与新会话按钮组固定在底层：收起时显示，开合时位置和尺寸不变，展开时被侧栏覆盖，侧栏内 Logo 旁仍有收起按钮、下方保留「新会话」。

## 「思考」与详情展开

- 停在对话底部点开「思考」等详情时，被点击的标题保持在原位，内容向下展开，不再被贴底跟随整段推到上方；滚轮、触摸、点击或翻页键立即交还滚动。

## 检查

实际执行记录见 [validation-0.5.1.json](validation-0.5.1.json)：本次发布执行 JavaScript 语法、客户端构建与导出一致性、Node 回归及安装包内容检查。修正一条未包含 0.5.0 新增流式管线字段的旧测试断言，并覆盖默认、兼容及无效管线值。

发送、侧栏和详情修复沿用已整理的开发提交；发送动效的开发实测记录见 [发送动效协调](SEND-MOTION-COORDINATION.md)。本次发布未重新执行浏览器和真实桌面界面验收，不把已有开发记录计为本次新测试。

已有版本、标签及发布产物保持不变。
