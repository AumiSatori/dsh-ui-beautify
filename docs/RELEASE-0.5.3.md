# dsh-UI美化 0.5.3

本版新增会话搜索与正文文件引用右键菜单，修复图片预览层级和 macOS 工具栏、侧栏兼容问题。升级保留现有偏好与导入素材。

## 会话内搜索

- 按 Ctrl+F（macOS 为 ⌘F）搜索当前会话已加载、已展开的内容，支持高亮、计数、上下处跳转、Enter / Shift+Enter、F3 和 Esc 关闭。
- 选中文字后打开搜索可自动填入；流式内容更新时重新匹配，不改写宿主消息文本节点。
- 页头搜索按钮默认位于昼夜开关右侧，可在「组件布局 → 右上工具栏」排序或隐藏；隐藏按钮后快捷键仍可用。旧排列保留其他按钮的顺序与显示偏好。

## 文件与预览

- 正文中可点击的文件引用复用输出卡片的完整右键菜单；按引用路径与所属会话处理，左键保留宿主原有行为。
- 文件菜单增加退场过渡；普通网页链接继续使用浏览器菜单。
- 侧栏边缘拉手位于宿主图片预览与覆盖层下方，放大图片时不再遮挡预览或抢走点击。

## macOS 兼容

- 工具栏按独立入口识别多层包装，排序和显示开关分别生效；关闭昼夜切换只隐藏自身。
- 支持中文访达与英文 Finder，保留打开方式组合按钮及其原有事件。
- 收起左侧栏时使用宿主 `shell.leading` 控件，避免再次投影侧栏与新会话按钮。
- macOS 识别与布局修正按平台隔离，Windows 沿用既有实现；补充 Windows 连续快速开合、三种按钮背景及覆盖模式的动画帧回归。

## 验证与升级

完整回归还修复了一处流式文字渐显设置更新问题：初始关闭或运行中关闭时释放高亮，强度与处理方式随当前设置更新。

发布检查记录见 [validation-0.5.3.json](validation-0.5.3.json)。浏览器自动回归在 Windows Chrome 的独立页面运行，使用安装版 DSH 的原生组件与合成数据；macOS 分支模拟不能替代 Mac 实机验收。搜索范围限于已加载且展开的会话内容。

安装本 Release 的 `dsh-ui-beautify.tgz`，与带版本的 `dsh-ui-beautify-0.5.3.tgz` 内容相同；`SHA256SUMS.txt` 提供校验值。升级后按宿主提示重载，已有源码链接窗口按 Ctrl+R 刷新前端。既有版本、标签及安装包保持不变。
