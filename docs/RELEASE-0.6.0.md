# dsh-UI美化 0.6.0

本版新增预设市场、魔方开屏与「镜海」动态背景，并调整单图消息与用户气泡。升级保留现有偏好与导入素材。

## 预设市场

- 入口在「设置 → dsh-UI美化 → 全局配置 → 预设市场」，「全局配置」下分为「本机配置」与「预设市场」两个子 TAB。
- 市场包含「发现」与「投稿」：按整套 / 单项、分类、官方 / 社区来源、名称、作者和标签筛选，查看详情后应用或保存到本机预设。
- 单项预设只替换对应设置和素材，整套预设替换整套配置与两种聊天宽度；应用复用现有导入的事务回退与撤销。
- 市场不再自带默认预设；网络不可用时使用最近 30 天内的缓存目录，没有缓存时展示空状态。
- 投稿包、GitHub 投稿模板、维护者审核发布与官方上传流程一并提供；预设资源与插件版本分开发布。详见 [预设市场](PRESET-MARKET.md)。

## 魔方开屏

- 开屏欢迎新增内置类型「魔方 · 按住复原」：纯白背景中的黑白 3×3 魔方，按住（鼠标、触屏或空格）逐层复原，松开停在整面、再按住从当前进度继续。
- 复原后带宿主 Logo 的一面转到正面，透视压平并融入背景，只留下 Logo 与名称；点击空白处、Enter、Esc 或「跳过」随时进入，12 秒无操作自动复原。
- 场景由独立工作区 `dsh-cube-opening` 用 three.js 构建，预构建产物放在 `vendor/cube-opening/`，与代码开屏共用隔离 iframe，仅在选中时执行，结束后释放 WebGL。详见 [自定义开屏](CUSTOM-OPENING.md)。

## 镜海背景与气泡

- 全图背景新增内置 HTML 预设「镜海」：日间 / 夜间两张同构图壁纸跟随宿主主题过渡，海面逐行涟漪、光斑粒子与指针视差，支持减少动态效果。
- HTML 背景体积上限由 2MB 放宽到 4MB，导入、预览与应用共用同一份限制。
- 镜海果冻气泡 v3：去掉小尾巴与扫光，悬停按果冻物理挤压回弹、按下再压扁；旧版镜海气泡读取时自动升级。
- 单图消息按附件元数据宽高比自适应，横图与竖图不再留方形空边；无元数据时回退到透明方形占位。

## 验证与升级

发布检查记录见 [validation-0.6.0.json](validation-0.6.0.json)。浏览器自动回归在 Windows Chrome 的独立页面运行，使用安装版 DSH 的原生组件与合成数据；macOS 分支模拟不能替代 Mac 实机验收。

安装本 Release 的 `dsh-ui-beautify.tgz`，与带版本的 `dsh-ui-beautify-0.6.0.tgz` 内容相同；`SHA256SUMS.txt` 提供校验值。升级后按宿主提示重载，已有源码链接窗口按 Ctrl+R 刷新前端。既有版本、标签及安装包保持不变。
