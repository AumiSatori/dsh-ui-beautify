# dsh-UI美化 0.6.1

状态为待发布，记录日期为 2026-11-09。当前修改先提交主分支，后续按下列未完成项继续。

本版修复 DSH 0.2.2 更新后的侧栏与页头兼容问题，并适配新版用户消息气泡。

- 侧栏从 Windows 标题栏下沿开始，修复顶部多出一段空白的问题。
- 点击历史会话后，先核对宿主列表中的持久记录，避免内存对象释放通知使该会话行消失或被标记为不可用。
- 调整新版页头标题区域的边距，标题和右侧工具各自保留空间。
- 自定义用户气泡支持新版公开标记，覆盖用户消息、补充消息和待提交消息。

验证记录见 [validation-0.6.1.json](validation-0.6.1.json)。回归使用 Windows Chrome 独立页面、安装版 DSH 原生组件和合成数据。macOS 分支在 Windows 上模拟，Mac 实机验收尚待进行。
