# dsh-UI美化 0.6.1

发布日期 2026-11-09。本版修复 DSH 0.2.2 更新后的侧栏、页头、气泡与表格兼容问题，并保持 0.2.1 可用。插件按元素、属性和接口是否存在选择写法，不按版本号判断。

- 侧栏从 Windows 标题栏下沿开始，修复顶部多出一段空白的问题。
- 点击历史会话后，先核对宿主列表中的持久记录，避免内存对象释放通知使该会话行消失或被标记为不可用。
- 调整新版页头标题区域的边距，标题和右侧工具各自保留空间；覆盖式侧栏较宽时，页头内容从侧栏右缘之后开始。
- 自定义用户气泡支持新版公开标记，覆盖用户消息、补充消息、待提交消息和提问回答卡片。
- 拖动调宽覆盖式侧栏时侧栏实时跟随（[#2](https://github.com/AumiSatori/dsh-ui-beautify/issues/2)）。宽度依次读取 `--dsh-windows-sidebar-width`、frame 内联首列宽度与旧版侧栏根节点宽度。
- 正文调宽拉到最窄时不再来回跳动；拖动侧栏期间只做轻量同步，减少掉帧。
- Windows 标题栏点击「应用 / 编辑」不再误触窗口最大化。
- 轮次卡片中的宽 Markdown 表格收在卡片内横向滚动（[#1](https://github.com/AumiSatori/dsh-ui-beautify/issues/1)）。

## 兼容范围

声明范围 `>=0.2.1-rc.2 <0.3.0-0`。本机实测宿主为 DSH 0.2.1-rc.5 与 0.2.2-rc.1，均为 Windows。macOS 仅在 Windows 中模拟过，尚未实机验收。

## 已知问题

1. 浏览器回归 `test:sidebar-overlay` 整脚本执行时，左右侧栏同时打开的动画采样仍有长帧，根因未确认；独立场景与本机实际页面拖动正常。
2. Windows 标题栏菜单占位层的修复只在 0.2.2 桌面窗口中出现，本次没有在桌面窗口实测。
3. 真实发送消息与流式输出没有在 0.2.2 上重新实测，本版未修改相关代码。
4. macOS 待实机验收。

Release 提供带版本安装包、固定名 `dsh-ui-beautify.tgz` 与 `SHA256SUMS.txt`。插件市场继续使用固定的 latest 下载地址。源码链接安装更新后按 Ctrl+R 刷新。
