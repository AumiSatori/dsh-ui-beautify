# dsh-UI美化 0.6.2

发布日期：2026-11-13。整合 0.6.1 之后已合入主分支的界面动效、会话提醒和新版 DSH 兼容修复。

- 修复 DSH 0.2.2-rc.2 中「对话延伸到输入栏后方」失效的问题。兼容新版首页外层容器，保留输入栏尺寸、滚动范围与交互遮罩。
- 玻璃侧栏底部以内容渐隐衔接同一层玻璃背景，消除明暗主题下突兀的实色色带；默认材质保留宿主渐变。
- 侧栏会话提醒在原来的图标气泡内展开列表，悬浮展示全部待提醒会话，点击条目切换会话；宽高、条目与收起过程均有过渡。
- 子智能体与后台任务列表保留宿主原来的底色、边框、阴影和透明度，开合只加位移与缩放。子智能体入口再次点击或使用键盘激活可收起。
- 思考动图的文案设置改为自定义 CSS，提供固定文案、随机文案与整行样式示例，旧偏好自动迁移，用时继续由宿主更新。
- 图片预览增加 280ms 缩放、位移、淡入和模糊消散，保留宿主及表情查看器的缩放、关闭与键盘操作。
- 适配新版页头的原生上下文菜单按钮。工具栏分组尚未挂载和重新安装展示层时，已有菜单仍能被正确识别；正文上下文菜单不受影响。

## 验证

使用安装版 DSH 0.2.2-rc.2 的原生代码或样式、合成数据与隔离的无头 Chrome，没有操作正在使用的 DSH 桌面窗口。

发布范围的 12 组、298 项检查通过：165 项 Node 检查，以及输入栏、输入栏延伸、发送滚动、首次发送、玻璃侧栏渐隐、会话提醒、页头菜单、思考 CSS、预设迁移、配置转移和图片预览。动效检查包含真实中间帧、快速反向和清理；明暗、窄屏、减少动态效果与强制颜色均有相关覆盖。重建一致性、包结构、敏感信息扫描及独立安装导入检查另行记录在 [validation-0.6.2.json](validation-0.6.2.json)。

本轮同时执行了完整的 72 组回归，首次结果为 43 组通过、29 组未通过。主要原因是旧测试依赖的宿主组件边界、文案或控件已变化，以及可选第三方插件路径未配置。会话控制器、页头菜单与提醒的相关检查已修正并复验；其余旧提取脚本仍待适配。该完整回归记录不能视为全量通过。

## 保留事项

- 旧版原生组件提取脚本的剩余适配、此前记录的侧栏页头对齐检查仍待完成，未通过的项目见验证记录。
- macOS 尚未实机验收；没有将 Windows 中的平台模拟当作 Mac 验收。
- 本轮没有在真实用户会话中发送消息；发送、流式输出和滚动使用隔离页面验收。

Release 提供带版本安装包、固定名 `dsh-ui-beautify.tgz` 与 `SHA256SUMS.txt`。既有市场条目继续使用 latest 下载地址。更新后按宿主提示重载，源码链接安装按 Ctrl+R 刷新；从需要重载后端服务的旧版本升级时，完整退出 DSH（含托盘）后重新打开。
