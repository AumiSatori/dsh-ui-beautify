# dsh-UI美化 0.6.3

发布日期：2026-11-13。修复不可见启动造成的开屏降级，并为预设市场增加非商业二创许可。

- **开屏不再在看不见时播完。** 以前只检查页面是否隐藏：DSH 在全屏应用后面、最小化、以隐藏窗口创建或没有焦点时启动，开屏会在用户看不见时跑完计时，代码开屏的画布也可能停在降级状态，表现为没有加载动画、背景变淡、开屏自绘的指针消失，重启后才恢复。现在遮罩立即覆盖界面，开屏内容在页面可见、获焦并连续正常出帧后才开始；无焦点时暂停等待，不跑帧循环，获焦或指针移入后开始。介绍阶段被隐藏、停帧超过 1 秒或持续失焦超过 1.5 秒时释放内容，回到前台后从头补播；短暂切走、焦点移入开屏 iframe 不会触发。介绍结束后的退场、跳过与原有资源清理不变，兼容 DSH 0.2.1 与 0.2.2。
- **预设市场支持 CC BY-NC-SA 4.0。** 许可可选 CC-BY-4.0、CC-BY-SA-4.0、CC-BY-NC-SA-4.0、CC0-1.0、MIT。素材本身是非商业二创时选择 CC-BY-NC-SA-4.0，并在简介写明原作者与二创作者。详情页和预设 Release 说明会标注“仅限非商业使用，改编须以相同许可分享”。旧版插件会拒绝该许可的预设，需要先升级到本版本。
