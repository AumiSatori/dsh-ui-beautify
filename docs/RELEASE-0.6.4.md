# dsh-UI美化 0.6.4

发布日期：2026-11-13。让预设市场向前兼容：以后上传预设、增加许可都不需要发布插件，旧版本插件的市场也恢复正常。

- **单个条目不再拖垮整个市场。** 0.6.0–0.6.3 遇到一个无法识别的目录条目（例如 0.6.3 新增的 CC BY-NC-SA 4.0 预设）就丢弃整个目录，市场显示为空并提示“网络暂不可用”。现在逐条读取，只跳过本版本无法识别的条目。
- **许可由仓库目录决定。** 可接受的许可写在仓库发布脚本和 `catalog-v2.json` 中，插件从目录读取投稿选项；读取预设只要求许可标识格式正确。新增许可只改仓库。
- **跳过新版设置。** 更新版本导出的预设含当前版本不认识的设置或素材分组时，安装会跳过这些部分并在详情中说明，不再整包拒绝；越过所选分类的已知设置仍被拒绝。
- **最低版本标注。** 目录条目可声明 `minPluginVersion`（发布时 `--min-version`）。版本不够时卡片显示“需要 x.y.z+”，查看时提示先更新插件。
- **兼容旧版的两份目录。** 完整目录为 `market/catalog-v2.json`，由 0.6.4 起读取，本机后端新增 `/dsh-ui-beautify/preset-market/catalog-v2` 路由。`market/catalog.json` 只保留 0.6.0–0.6.3 能识别的条目，所以旧版本立即恢复显示魔方预设；鲸鱼娘 · 镜海（CC BY-NC-SA 4.0）在 0.6.4 中显示。

## 验证

- Node 检查 176 项：175 项通过、1 项跳过、0 项失败，新增未知设置与素材跳过、版本标注与目录许可、两份目录一致性、后端 v2 路由下载 4 项，目录容错与许可用例按新规则更新。`check:lens`、`check:release`、`market:validate` 通过，客户端可由发布源码重建。
- 兼容矩阵：用 0.6.0、0.6.1、0.6.2、0.6.3 发布源码中的目录解析读取新的 `catalog.json`，均列出魔方预设，不再报错；0.6.4 读取 `catalog-v2.json` 列出两个预设。

## 保留事项

- 市场界面的新标注（“需要 x.y.z+”、跳过说明、目录提供的许可选项）只有单元测试覆盖，本轮没有在实际 DSH 页面截图核对：本机 8442 Web 入口在 DSH 0.2.2 上未开启。
- 0.6.3 用户在升级前看不到鲸鱼娘 · 镜海预设。
- 本版新增后端路由，从旧版本升级后需完整退出 DSH（含托盘）再打开；未重启时 0.6.4 前端会通过 raw / jsDelivr 读取目录，但 v2 独有预设的下载要等新后端加载。

Release 提供带版本安装包、固定名 `dsh-ui-beautify.tgz` 与 `SHA256SUMS.txt`。
