# dsh-UI美化 0.6.5

发布日期：2026-11-14。

- **预设市场标签。** 卡片上的标签显示为可点击的 #标签，点击后只看带该标签的预设，再点一次取消；筛选区新增「预设标签」一行，列出目录中出现过的标签（按使用次数排序，最多 16 个）；详情页同时列出标签。标签来自市场目录，上架新标签不需要更新插件。
- **HTML 动态背景按键转发。** 指针消息 `{type:'dcb-background-pointer',x,y}` 新增 `buttons` 字段，为当前按下的鼠标键位掩码。按下、松开和取消立即转发，移动仍限制在约 20Hz，背景据此区分拖动与悬停。雾玻璃 · 鲸鱼娘预设在本版本中按住左键拖动写字，旧版本仍按悬停写字；未使用 `buttons` 的背景行为不变。

## 验证

- Node 检查 176 项：175 项通过、1 项跳过、0 项失败；`check:lens`、`check:release`、`market:validate` 通过，客户端可由发布源码重建。
- 在内置浏览器中加载发布客户端与实时市场目录：卡片标签筛选与取消、标签行筛选、详情页标签、选中样式均正常。
- 按键转发：用回显指针消息的 HTML 背景验证，悬停为 `buttons:0`，按下立即为 1，拖动中的移动按 50ms 节流并带 1，松开与取消立即为 0；卸载后不再转发，背景 iframe 已移除。
