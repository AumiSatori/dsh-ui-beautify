# dsh-UI美化 0.6.6

发布日期：2026-11-14。

- **预设市场不再停留在旧目录。** 市场同时向本机后端、GitHub raw 与 jsDelivr 读取目录，过去采用最先返回的结果。jsDelivr 让浏览器缓存 `@main` 7 天，本机缓存中的旧目录总是最先返回，因此新上架的预设（例如雾玻璃 · 鲸鱼娘）可能一周都看不到，刷新也没有用。现在读取目录时绕过浏览器缓存；第一份结果到达后再等其他来源约 1.2 秒，按目录中最新的发布时间选用最新的一份。本机后端路由同样选择最新目录。
- **发布后自动刷新镜像。** 官方发布脚本推送目录后，会请求 jsDelivr 刷新 `catalog.json` 与 `catalog-v2.json`。

## 验证

- Node 检查 178 项：177 项通过、1 项跳过、0 项失败。新增两项：先返回的旧目录不会覆盖稍后到达的新目录，且读取时使用 `no-store`；发布后刷新两份 jsDelivr 目录。`check:lens`、`check:release`、`market:validate` 均通过。
- 本机桌面版的市场缓存中，确认此前取得的是 11-14 09:17 的旧目录；同一时刻 raw、jsDelivr 与代理返回的都是最新目录。修复后 8442 后端路由与绕过缓存的 jsDelivr 请求都返回三个预设。
