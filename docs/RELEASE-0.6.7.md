# dsh-UI美化 0.6.7

在 **设置 → dsh-UI美化 → 全局配置 → 本机配置** 中选择预设。升级沿用现有配置，两个新预设都需要手动应用。

| 预设 | 应用后的变化 |
| --- | --- |
| 接近原生 | 关闭任务面板、开屏、粒子、全图背景、消息入场和流式渐显等效果，输入栏、侧栏、按钮与气泡使用原生样式。沿用宿主主题，保留两种窗口的聊天宽度与本机素材。 |
| 轻量玻璃 | 在接近原生的设置上给输入栏加 2px CSS 模糊，关闭小按钮动态玻璃。 |
| 插件默认 | 原「默认值」。恢复所有美化选项和聊天宽度，重新启用 9600 颗粒子，保留本机素材。 |

上述切换均可在本页撤销。关闭任务面板也会关闭与它联动的插件会话搜索。要搭配暗色，可在切换预设后使用日夜开关。

本版还包含主分支已有的图片预览动效、任务结束状态和其他会话提醒修复。安装地址、兼容范围、宿主回归版本及首次安装／卸载的完整退出步骤见 [首页](../README.md)。

## 性能对照

Apple M6、无头 Chrome、1440 × 1000、100 轮合成会话。启用粒子的组使用 9600 颗内置鲸鱼娘粒子、WebGL2、50% 成形。每组连续滚动并模拟侧栏宽度变化，每段丢弃预热帧后记录 120 个 requestAnimationFrame 间隔。通过 `npm run bench:appearance` 可复跑。

| 设置 | 滚动 P95 | 侧栏调宽 P95 |
| --- | ---: | ---: |
| 两项全关 | 16.7 ms | 16.7 ms |
| 仅输入栏轻量玻璃 | 16.8 ms | 16.7 ms |
| 仅粒子 | 16.8 ms | 16.7 ms |
| 轻量玻璃和粒子 | 16.7 ms | 16.7 ms |

这台机器上四组的 P99 均为 16.8 ms，本轮采样无法区分其流畅度。轻量预设沿用现有 2px 材质并默认关闭粒子。Windows 核显、功耗与真实桌面拖动仍待实测。
