# dsh-UI美化 0.6.8

从 DSH 插件管理器安装、启停、更新或卸载时，按宿主显示的结果操作。支持热加载的 profile 可以在当前窗口生效。若宿主提示需要重启，等当前任务结束后重启对应 profile；Desktop 完全退出时包括托盘。源码登记脚本只写入配置文件，不能确认运行中的插件是否已切换。

## 宿主兼容

- 展开侧栏时检查宿主发布的像素宽度。若缺少有效值，沿用宿主布局，保留用户的覆盖偏好。在窄屏 Web 已启用原生抽屉的窗口里，保留宿主抽屉、遮罩与展开入口。
- 适配新版侧栏滚动容器，展开动效覆盖其中的会话列表。页头避让打开的侧栏，宽屏工具栏与右侧按钮垂直对齐。
- 客户端仍声明五个 UI 注入项。普通安装通过 bundle 注册插件。兼容范围仍为 DSH `>=0.2.1-rc.2 <0.3.0-0`，0.3.x 待实测。

## 热装卸验收

在 macOS 上用 DSH 0.2.2-rc.5 启动独立的 Web profile，通过实际插件管理器安装本地源码目录，启用、停用、再次启用，再卸载。整个循环使用同一浏览器页面和宿主进程。

| 检查对象 | 启用 | 停用 | 再启用 | 卸载 |
| --- | --- | --- | --- | --- |
| 插件主样式数量 | 1 | 0 | 1 | 0 |
| 搜索快捷键打开的插件搜索栏数量 | 1 | 0 | 1 | 0 |
| 合成会话的粒子画布数量 | 1 | 0 | 1 | 0 |
| 粒子管理器 | 已挂载 | 已释放 | 已挂载 | 已释放 |
| 无参数请求预设包路由 | 400 | 404 | 400 | 404 |

宿主设置入口在两次启用时均只有一个，停用时为零。400 是已注册的路由拒绝缺少标识的请求；404 是路由已卸下。卸载后 profile 清单的依赖与 bundle 登记均已移除。此源码目录安装方式在隔离 profile 的 node_modules 下留有链接。没有操作使用者的现有会话。

## 回归范围

测试读取器支持带源码区域标记的旧包与单行压缩的新包。使用 0.2.2-rc.1 和 0.2.2-rc.5 的实际宿主归档，分别核验正文调宽（11 项）、轮次卡片（22 项）、设置导航（12 项）和侧栏覆盖（14 项）。侧栏单元测试覆盖宽度缺失、恢复及再次失效。Web 热装卸已验证；Windows Desktop 托盘重启、无 HMR 的宿主和 0.3.x 未实机验证。
