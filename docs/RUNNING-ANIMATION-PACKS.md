# 思考动图与动图包

入口：**设置 → dsh-UI美化 → 思考动图**。原 `dsh-whalechan-running` 的“深度求索中”图标功能已整合到这里。

- 默认内置鲸鱼娘 51 个动作，不需要另装插件。
- 发布包只包含插件实际使用的压缩 WebP 动作包；原始 PNG 源素材不随包发布。内置小图标运行素材为 640×384 精灵表（每帧 64×64，保留高分屏显示细节），保留 10×6、60 帧和透明通道。
- 勾选哪些动作可以出现；“全选动作”恢复全部，“全部取消”显示宿主原生图标。
- 开启随机动作时，每次新的思考从勾选动作里抽取，尽量避免连续重复；关闭随机后固定使用列表中第一个已勾选动作。只想显示一个动作，勾选一个即可。
- 图标大小 16–80px，文字间距 0–24px。列表缩略图保持静止，点击“预览动作”只播放一个预览。减少动态效果时显示静止首帧。
- 关闭总开关保留动图包和选择。导入包可以单独删除，内置包始终保留。

## 思考文案

图标后面的“深度求索中……”可以换成自己的话：

- **思考文案**每行一条，最多 20 条、每条 40 字；写一条就固定显示这一条。
- **随机文案**开启时，每次新的思考从这些文案里抽一条，尽量避免连续重复；关闭后固定用第一条。
- 填写后整行换掉“深度求索中”，宿主的“用时 N 分 N 秒”默认接在文案后面（`鲸鲸正在想…，用时 12秒 …`），并且逐秒更新。
- 想把用时放到别处，就在文案里写占位符 `{time}` 或 `{用时}`：`想好了，{time}` → `想好了，12秒`；`{time} 之前想到的` → `12秒 之前想到的`。占位符可以放在任意位置，也可以只用一次。
- 文案里不写占位符就保持“文案 + 用时”的默认顺序。留空立刻恢复宿主原文。
- 宿主每秒都会改写这一行，插件因此沿用它的 DOM，只替换文字并同步高亮副本的 `data-shimmer-text`，所以扫光字体效果和用时都还在，也不会出现“换上去又闪回”。
- 换文案或清空都不影响已选动作和动图包。

## 下载可直接导入的格式示例

在导入区点击 **下载格式示例 ZIP**，即可保存 `dsh-running-pack-example.zip`。下载不会改变当前动图包或设置。

示例内含 `manifest.json`、一张可播放的鲸鱼娘精灵图、中文 `README.txt` 和素材 `LICENSE`。ZIP 可直接导入试用，也可解压后通过“导入文件夹”载入；制作自己的包时，按说明替换图片、作者、授权和动作参数。中文说明同时提供普通 GIF / APNG / WebP 的目录组织和 JSON 示例。

示例随客户端提供，保存时不需要访问外部网站。源码在 `assets/running-example/`，素材复用 `assets/running-whale/a001.webp`，运行 `npm run build:lens` 会重新生成 ZIP 并嵌入客户端；`npm run check:lens` 会检查示例与客户端是否一致。

## 最简单的制作方法：普通动图

1. 准备 GIF、APNG 或动态 WebP，每个文件是一个完整动作。静态 PNG / WebP 也可以。
2. 用动作名称命名，例如 `认真工作.gif`、`打瞌睡.webp`。建议透明背景、主体居中、四周留空；正方形画布在小图标里更自然。普通动图建议 128–256px，减少文件体积。
3. 把图片放进同一个文件夹，压缩成 **ZIP**；也可以直接导入这个文件夹。不需要说明文件。
4. 在“思考动图”页点击“导入 ZIP 动图包”，或把 ZIP 拖入虚线框。导入成功会自动切换到新包，文件名作为动作名称。

ZIP 可以直接装文件，也可以在外层多包一个目录；包含 `manifest.json` 时，图片路径相对于这份说明文件。普通 ZIP 不执行任何代码；不支持 RAR、7z、加密包、SVG、HTML 或网络图片地址。分享前确认素材允许转发。

## 精灵图或自定义名称：附上说明文件

精灵图是一张静态 PNG / WebP，所有帧按**从左到右、从上到下**排列在等大的正方形格子里。不能把整张精灵图当普通图片导入，否则会显示整张拼图。

```text
我的动图包/
  manifest.json
  工作.gif
  吃饭.png
  LICENSE
```

`manifest.json` 必须使用 UTF-8、标准 JSON，不写注释：

```json
{
  "format": "dsh-running-pack",
  "version": 1,
  "name": "我的动图包",
  "author": "作者名",
  "license": "自己的素材授权说明",
  "actions": [
    { "id": "working", "name": "认真工作", "file": "工作.gif" },
    {
      "id": "eating",
      "name": "吃米饭",
      "file": "吃饭.png",
      "type": "sprite",
      "frames": 60,
      "columns": 10,
      "fps": 12.5
    }
  ]
}
```

| 字段 | 含义 |
| --- | --- |
| `id` | 包内唯一的英文、数字、下划线或短横线 ID；后续选择用它识别动作。 |
| `name` | 设置里显示的动作名称。 |
| `file` | 包内相对路径，支持中文文件名；不能包含 `..` 或绝对路径。 |
| `type: "sprite"` | 声明精灵图；普通 GIF / APNG / WebP 不写这个字段。 |
| `frames` | 有效帧数，2–240。 |
| `columns` | 每一行多少格，行数按帧数向上取整。 |
| `fps` | 每秒多少帧，1–30；不写时默认 12.5。 |

例如每格 64×64、60 帧、每行 10 格，整张图就是 **640×384**。动画绘制工具导出时不裁掉各帧透明边距，不加格子间隔；不足一行的尾部保留空格。可以直接复制 `assets/running-whale/manifest.json` 并替换自己的素材与名称。

## 限制与保存位置

- 一个包最多 100 个动作、128 个文件；单张不超过 8 MB，总素材不超过 96 MB；ZIP 文件不超过 100 MB。
- 图片最长边 4096px，最多约 800 万像素；`manifest.json` 不超过 64 KB。导入会解码检查并生成静态缩略图，损坏包不会替换原来的选择。
- 动图包保存在**当前浏览器来源的 IndexedDB**，选择保存在美化插件的本机设置。桌面窗口、不同浏览器、不同站点地址之间不自动同步；清理站点数据会移除导入包，请保留原 ZIP。DSH 地址/端口变化后可重新导入原 ZIP。
- 内置包随插件提供，只按需加载图片。动态图标在页面隐藏或离开可视区后暂停；设置页切走会释放预览。关闭功能不保留后台动画或定时刷新。

## 源码用户的打包命令

也可以直接使用系统的 ZIP 压缩功能。仓库内有一个不需要额外依赖的打包工具：

```powershell
node scripts/build-animation-pack.mjs "D:\素材\我的动图包" "D:\素材\我的动图包.zip"
```

打包内置鲸鱼娘素材作为可导入样例：

```powershell
node scripts/build-animation-pack.mjs assets/running-whale whale-animation-pack.zip
```

生成 ZIP 的工具会检查类型、说明和数量；最终尺寸、解码与精灵图排列仍在导入时验证。

## 从旧插件迁移

仅整合功能不会自动卸载其他插件。源码安装用户可以先预览迁移计划：

```powershell
node scripts/migrate-running-plugin.mjs --profile desktop
```

检查目录正确后，明确执行本地迁移：

```powershell
node scripts/migrate-running-plugin.mjs --profile desktop --apply
```

迁移只处理该 profile 的 `dsh-ui-beautify` 链接、`dsh-whalechan-running` 安装链接、两者依赖与 bundle；保留旧源码、旧配置及其他插件。先备份 package.json、锁文件和原链接目标；具体备份目录会打印出来。不接管未知的实际目录或重复补丁注册。旧插件的本机尺寸、路径配置不自动覆盖新的动作选择；需要自定义素材时重新导入。

**迁移后完整退出并重新启动 DSH 一次**：旧插件有启动脚本和定时器，刷新页面不足以确认移除全部旧注入；新内置素材服务也需要宿主重新加载。不要同时启用旧插件与新功能。

此操作不提交、不推送、不改版本、不发版。开发链接指向的工作目录在实际使用期间需要保留。回退时按备份中的原链接目标恢复链接及 package.json、锁文件，再重启 DSH；不要删除原源码目录。
