# 设置分组与工具栏

设置按一级分类展示；每个一级下面放两条彼此独立的二级栏，保持并列，不增加第三层标题。切换后只挂载当前页，并保留每个一级最后打开的页面。原有页面记忆自动沿用，素材库与功能开关不迁移、不清空。

| 总分类 | 子页面 |
| --- | --- |
| 全局布局 | 输入栏、侧栏、右上工具栏、开屏欢迎、全图背景、粒子背景 |
| 对话布局 | 任务面板、思考动图、对话动效 |

全局布局的两条二级栏分别是「界面布局」（输入栏、侧栏、右上工具栏）和「背景与欢迎」（开屏欢迎、全图背景、粒子背景）；对话布局的两条二级栏分别是「任务面板」和「动效与反馈」（思考动图、对话动效）。

在「全局布局 → 右上工具栏」拖动把手或点击上下箭头排序，逐项切换入口显示。把手也支持键盘上下方向键。项目文件夹及其打开方式菜单作为一组移动。

入口包括项目文件夹、更多操作、昼夜切换、纯背景、任务面板、设置和右侧栏；保留宿主原按钮、菜单、点击事件和图标材质。仅修改视觉顺序，不重建原生控件。无会话的欢迎页出现哪些入口，就对这些入口应用已有选择。

入口显示与功能开关分工：

- 任务面板的原功能开关优先；关闭后，工具栏对应入口开关禁用并解释原因。再次开启功能时恢复原来的入口偏好。
- 隐藏纯背景入口不退出模式，Esc 和已有退出控件继续有效。
- 隐藏右侧栏入口不关闭已经打开的侧栏。
- 隐藏设置入口后，仍可从左下账号菜单进入设置。
- 背景、粒子、思考动图、日夜切换等原有配置不随入口隐藏而改变。
- 其他插件自己注册的图标保留原逻辑，不强行接管。

「恢复工具栏默认排列」仅恢复入口顺序和显示；全局恢复默认及撤销也包含这些偏好，不移除导入素材。默认显示现有入口，沿用原排列。

排列与隐藏存储在现有外观偏好的 `toolbar.order` 和 `toolbar.hidden`；父子分类记忆独立于外观配置。未识别的入口 ID 会丢弃，新增入口自动补齐。

验证：`node test/settings-hierarchy-toolbar-browser.mjs`。用当前安装的 DSH 样式运行时需指定 `DSH_ASAR`；截图等产物通过 `DSH_CLAUDE_OUTPUT_DIR` 放到集合目录 `.scratch/`。
