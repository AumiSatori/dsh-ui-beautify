# 设置分类与工具栏

一级分类为「组件布局 / 全局布局 / 对话布局」，每个一级仅显示自己的二级选项。没有第三级分类，也不同时挤入两组二级栏。

| 一级分类 | 二级页面 |
| --- | --- |
| 组件布局 | 输入栏、侧栏、右上工具栏 |
| 全局布局 | 开屏欢迎、全图背景、粒子背景 |
| 对话布局 | 任务面板、思考动图、对话动效 |

仅挂载当前页面；每个一级分别记忆最后打开的二级。旧页面记忆按页面 ID 自动归属新分类。页面使用显式 ID 对应，不再依赖子元素位置；旧版本没有的功能页不会出现空白入口。素材与功能设置不随分类改动迁移或清空。

## 右上工具栏

拖动把手、上下箭头或把手的键盘方向键排序；逐项控制入口显示。项目文件夹及其打开方式菜单作为一组。

入口包括项目文件夹、更多操作、昼夜切换、纯背景、任务面板、设置和右侧栏。沿用原按钮、菜单与事件。欢迎页仅对当时存在的入口应用配置；其他插件入口不强行接管。

- 隐藏入口不关闭功能。任务面板原功能开关优先，功能关闭时对应显示开关禁用；再开启仍保留入口偏好。
- 隐藏纯背景入口后，Esc 和退出控件仍可退出模式。
- 隐藏右侧栏入口不关闭已展开的侧栏。
- 隐藏设置入口后仍可从账号菜单打开设置。
- 恢复工具栏默认排列只恢复顺序与显示；全局重置/撤销包含这些偏好，保留导入素材。

顺序与隐藏分别保存为 `toolbar.order` / `toolbar.hidden`；分类记忆与外观配置分开。支持方向键、Home/End、窄屏、减少动态效果和强制颜色。快速反向取消过期过渡，最终只保留当前页。
