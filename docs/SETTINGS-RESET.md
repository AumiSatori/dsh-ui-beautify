# 全部恢复默认值

美化设置页顶部提供「全部恢复默认值」，一次恢复任务面板、输入栏、侧栏、顶部布局、开屏欢迎、全图背景、粒子背景、思考动图、对话样式和动效的默认配置，同时清除普通窗口与全屏／最大化各自保存的聊天宽度，恢复自动适配。

点击后立即生效并保存，不额外弹确认框。「撤销恢复」可找回恢复前的设置、自定义 CSS 和两种窗口宽度；关闭再打开设置仍可撤销。修改另一项设置或刷新整个页面后，本次撤销记录失效。重复点击恢复不会覆盖原来的撤销记录。

已导入的背景图片／视频、开屏媒体、粒子图和动图包保留在原有本机素材存储中；恢复默认不删除素材库。当前设置分类、宿主设置窗口的插件页面选择、聊天草稿及其他插件配置保持原样。未保存的设置编辑草稿和正在播放的设置预览随恢复重建，恢复之前开始的异步导入不能重新启用旧配置。

如果浏览器不允许保存设置，页面会明确提示「仅当前窗口生效（未能保存）」，仍可撤销。

验证：`npm run test:settings-reset` 使用合成会话和合成素材覆盖所有配置、撤销、素材保留、刷新、跨窗口、延迟导入、明暗主题、窄屏、键盘、减少动态效果、强制颜色和资源释放；`npm run test:conversation-width` 验证本机宿主原生拖动控件与宽度恢复。产物保存到集合目录 `.scratch/`，不读取或重置真实用户配置。
