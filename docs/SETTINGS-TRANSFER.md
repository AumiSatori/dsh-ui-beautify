# 全局配置导入与导出

入口：**设置 → dsh-UI美化 → 全局配置**。此处可保存、命名和切换本机预设，或导入、导出配置。

- **配置预设**：输入名称并保存当前配置，点击「切换」即可应用；也可重命名或删除。每个预设独立保存配置和本机素材，素材较多时会占用更多本机存储。切换素材后若页面提示刷新，请保存正在编辑的内容并刷新界面。
- **默认值**：内置预设，切换后恢复默认设置及聊天宽度，保留已导入素材；可通过「撤销上次应用」返回切换前的配置。

- **导出配置**：默认下载 `.json`，包括所有分类的已保存选项、独立黑白主题与气泡配色、自定义 CSS、工具栏顺序与隐藏项、普通窗口和全屏的聊天宽度，以及分类记忆。不会导出尚未保存的编辑草稿。
- **包含本机素材**：开启后下载 `.dshui` 完整备份，包含以上配置，以及美化插件本机保存的背景库（图片、视频、HTML 与名称）、开屏媒体与代码、粒子图片与 SVG、分隔动图、自定义思考动图包。内置素材由插件本身提供，无需重复打包。
- **导入配置**：选择 `.json` 或 `.dshui`，先查看文件名、设置数、素材记录数和大小，点击「应用配置」。仅替换本美化插件配置，其他插件、账号、模型配置和聊天记录不参与操作。
- **撤销上次应用**：恢复最近一次导入或切换预设前的配置与本次写入的素材记录；关闭设置后重新打开仍可撤销，刷新页面或重启后撤销记录释放。

轻量配置只保存素材引用，适合在同一来源恢复选项或分享配色。跨设备、桌面与浏览器之间迁移时，建议开启「包含本机素材」。未打包的素材必须已存在于目标来源，插件不会自动从原设备取回文件。

配置导入后立即应用。完整备份会合并素材，不批量清空目标素材库；同标识的备份记录替换目标记录，其他背景名称和素材保留。已有绘制器可能缓存旧素材，因此导入或撤销素材后使用「刷新界面加载素材」。刷新前可先保存正在编辑的内容。界面不会擅自刷新或重启 DSH。

完整备份最多 **512 MB**，单项二进制素材最多 **256 MB**，配置目录/JSON 最多 **8 MB**。二进制素材直接保存，避免 Base64 扩大文件与内存开销。导入先检查格式、版本、存储白名单、条目长度和 SHA-256 校验，再写入；保存失败会尝试恢复导入前的记录与选项，并明确显示失败/回退结果。

备份保存在用户选择的下载位置，不上传网络。自定义 HTML、开屏代码、CSS 和图片等原始内容也可能包含用户自己的信息，请按个人文件管理备份。版本 1 的完整备份是带目录的本插件二进制格式，并非 ZIP；请保留 `.dshui` 扩展名。

验证：`node test/settings-transfer-browser.mjs`，覆盖真实设置页导出/导入、独立主题与宽度、取消与撤销、空白来源的素材恢复、已有图库合并、损坏/无效文件拒绝、写入失败回退、明暗/窄屏/键盘/减少动态效果/强制颜色。测试使用合成配置和素材。
