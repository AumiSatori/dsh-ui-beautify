# 其他会话状态提醒

左侧栏收起时，左侧中部把手旁出现小型气泡，提示当前窗口之外的会话有新状态：

- 绿色对勾：完成且未读，对勾描边与外圈轻弹。
- 紫色圆点：等待回答或权限确认，按一个、两个、三个点循环。
- 红色感叹号：执行失败，轻摇并带扩散光圈。

图标使用 SVG 路径和圆形绘制。同种状态合并计数，三个状态并排时不超过 140px 宽，单项按钮为 36px。点击任何图标会展开原生侧栏；点击或手动展开侧栏均以位移、缩放、淡出和模糊过渡消失。同一条已查看状态不重复提示，新的运行或新的提问可以再次提示。

侧栏中部的边缘把手始终显示箭头：收起时朝右，展开时朝左，方向平滑切换。可视部分宽 18px、高 40px，鼠标悬停时展开到 22px；保留 44×64px 点击区域、原生开合动作和键盘操作。

读取宿主 `sessions.list` 与 `uiSession.sessionStatus` 的真实状态，完成采用 `completionUnread`，待回答采用 `pendingInteraction`；失败采用宿主 `api-session/error` 和已保留会话的最新 `turn/end`。不主动打开其他会话、读取完整历史、显示错误原文或修改宿主未读标记。不提示当前窗口会话、子智能体、已知取消或停止的轮次。旧的静止会话不作为刚完成处理。

浅色、深色、窄屏、减少动态效果、强制颜色、插件停用和卸载均有对应处理。纯背景模式隐藏提醒。订阅随插件卸载释放，无定时轮询或常驻 JavaScript 动画循环。

验证：`node test/sidebar-attention-browser.mjs`，涵盖真实浏览器的状态源订阅、SVG 图形、中间帧、逐点动画、单项宽度塌缩、点击/展开消失、重复抑制、失败/取消区分、主题及清理。截图和记录默认写入工作区 `outputs/sidebar-attention-qa/`，可用 `DSH_CLAUDE_OUTPUT_DIR` 指定位置。更新源码后运行 `npm run build:lens`，源码链接安装的 DSH 窗口按 Ctrl+R 加载。
