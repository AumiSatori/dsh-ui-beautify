# 其他会话状态提醒

左侧栏收起时，左侧中部把手旁出现小型气泡，提示当前窗口之外的会话有新状态：

- 绿色对勾：完成且未读，对勾描边与外圈轻弹。
- 紫色圆点：等待回答或权限确认，按一个、两个、三个点循环。
- 红色感叹号：执行失败，轻摇并带扩散光圈。

图标使用 SVG 路径和圆形绘制。同种状态合并计数，三个状态并排时不超过 140px 宽，单项按钮为 36px。点击任何图标会展开原生侧栏；点击或手动展开侧栏均以位移、缩放、淡出和模糊过渡消失。同一条已查看状态不重复提示，新的运行或新的提问可以再次提示。

鼠标悬停气泡会展开会话列表，展示所有待提醒会话的名称和状态。列表有淡入、位移、缩放和模糊过渡，条目依次展开。鼠标从气泡经过间隙进入列表时保持展开，移出后平滑收起。长列表可滚动，窄屏时自动避让窗口边缘。

点击某一条会话，使用宿主的原生入口切换到该会话，只消除这一条当前状态的提醒，其他提醒继续保留。悬停本身不会清除提醒。名称和状态在列表打开期间同步更新，消失的条目以高度塌缩和淡出过渡移除。查看后再切走，同一条待回答状态不会重新提示，出现新的提问后可再次提示。

键盘聚焦提醒图标也可展开列表，方向键移动到会话条目，Enter 激活。Escape 平滑关闭并返回触发图标，点击外部同样关闭。减少动态效果时直接完成状态切换。

收起标记只表示目标状态。提醒会等待实际侧栏轨道、边缘箭头和宿主收缩动画全部结束，再从最终收起位置入场；展开时停留在原来的收起位置退场，不随侧栏移动到正文。连续开合会按最新状态判断，重复刷新不会重启退场，也不使用固定延时猜测收缩时长。

侧栏中部的边缘把手显示箭头：收起时朝右，展开时朝左，方向平滑切换。可视部分宽 18px、高 40px，鼠标悬停时展开到 22px；保留 44×64px 点击区域、原生开合动作和键盘操作。把手位于侧栏和宽度拖动条上方、宿主覆盖层下方；放大用户图片或打开弹窗时由覆盖层接收点击，关闭后原把手继续可用。

读取宿主 `sessions.list` 与 `uiSession.sessionStatus` 的真实状态，完成采用 `completionUnread`，待回答采用 `pendingInteraction`。失败采用宿主 `api-session/error` 和已保留会话的最新 `turn/end`。列表名称取自原生会话摘要，用户点击条目时调用 `uiWorkspace.openSession`。当前窗口会话、子智能体、已知取消或停止的轮次均不提示。

浅色、深色、窄屏、减少动态效果、强制颜色、插件停用和卸载均有对应处理。纯背景模式隐藏提醒。订阅随插件卸载释放，无定时轮询或常驻 JavaScript 动画循环。

验证：`node test/sidebar-attention-browser.mjs`，涵盖真实浏览器的状态源订阅、SVG 图形、中间帧、逐点动画、单项宽度塌缩、点击/展开消失、重复抑制、失败/取消区分、主题及清理；另逐帧记录收缩、展开与连续反向，验证收缩未结束不显示、展开退场不移位。截图和记录默认写入工作区 `outputs/sidebar-attention-qa/`，可用 `DSH_CLAUDE_OUTPUT_DIR` 指定位置。更新源码后运行 `npm run build:lens`，源码链接安装的 DSH 窗口按 Ctrl+R 加载。
