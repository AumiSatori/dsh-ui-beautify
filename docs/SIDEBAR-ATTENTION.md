# 其他会话状态提醒

左侧栏收起时，左侧中部把手旁出现小型气泡，提示当前窗口之外的会话有新状态：

- 绿色对勾：完成且未读，对勾描边与外圈轻弹。
- 紫色圆点：等待回答或权限确认，按一个、两个、三个点循环。
- 红色感叹号：执行失败，轻摇并带扩散光圈。

图标使用 SVG 路径和圆形绘制。同种状态合并计数，三个状态并排时不超过 140px 宽，单项按钮为 36px。点击任一图标查看全部会话详情；手动展开原生侧栏后，提醒以位移、缩放、淡出和模糊过渡消失。同一条已查看状态不重复提示，新的运行或新的提问可以再次提示。

点击时，原来的图标气泡本身扩宽、增高并变成会话列表，展示所有待提醒会话的名称和状态。原图标随过渡隐去，列表在同一个气泡内部淡入、位移并逐项展开。悬停不展开，移出不关闭；点击标题右侧“收起会话详情”按钮、外部或 Esc 后，列表退场，原气泡平滑缩回图标状态。长列表可滚动，窄屏时自动避让窗口边缘。

点击某一条会话，使用宿主的原生入口切换到该会话，只消除这一条当前状态的提醒，其他提醒继续保留。打开或收起详情本身不会清除提醒。名称和状态在列表打开期间同步更新，消失的条目以高度塌缩和淡出过渡移除。查看后再切走，同一条待回答状态不会重新提示，出现新的提问后可再次提示。

键盘聚焦提醒图标后，Enter / 空格展开详情，方向键展开并移动到会话条目，Enter 激活。点击收起按钮或按 Escape 平滑收起并返回触发图标，点击外部同样收起。减少动态效果时直接完成状态切换。

收起标记只表示目标状态。提醒会等待实际侧栏轨道、边缘箭头和宿主收缩动画全部结束，再从最终收起位置入场；展开时停留在原来的收起位置退场，不随侧栏移动到正文。连续开合会按最新状态判断，重复刷新不会重启退场，也不使用固定延时猜测收缩时长。

侧栏中部的边缘把手显示箭头：收起时朝右，展开时朝左，方向平滑切换。可视部分宽 18px、高 40px，鼠标悬停时展开到 22px；保留 44×64px 点击区域、原生开合动作和键盘操作。把手位于侧栏和宽度拖动条上方、宿主覆盖层下方；放大用户图片或打开弹窗时由覆盖层接收点击，关闭后原把手继续可用。

读取宿主 `sessions.list` 与 `uiSession.sessionStatus` 的真实状态，完成采用 `completionUnread`，待回答采用 `pendingInteraction`。失败采用宿主 `api-session/error` 和已保留会话的最新 `turn/end`。列表名称取自原生会话摘要，用户点击条目时调用 `uiWorkspace.openSession`。当前窗口会话、子智能体、已知取消或停止的轮次均不提示。

优先使用宿主 `sessions.list.ids` 的普通会话列表，避免把 `byId` 中补入的子智能体目录也当作聊天；兼容仅提供 `byId` 的旧宿主。Mnemon 在部分新版宿主中把自动任务登记成普通根会话，因此另外排除其保留 ID：`mnemon-task-v1-<UUID>`、`mnemon-run-v1-<UUID>`、`mnemon-review-v1-<UUID>`。过滤在绑定事件源前完成，不额外订阅内部任务。识别不依赖可编辑标题；普通同名会话、具有父会话关系的用户分支照常提醒。这只改变提醒列表，不删除宿主保存的会话。

浅色、深色、窄屏、减少动态效果、强制颜色、插件停用和卸载均有对应处理。纯背景模式隐藏提醒。订阅随插件卸载释放，无定时轮询或常驻 JavaScript 动画循环。
