# 鲸鱼入口状态

顶部鲸鱼后方显示当前状态，不再混用文件数、资源数或轮次作为入口文字。

| 状态 | 入口文字 |
| --- | --- |
| 正在执行有未完成项的当前任务清单 | 当前步骤 / 总步骤，例如 `2/5` |
| 普通运行 | 处理中 |
| 存在正在执行的已知工具 | 读取文件、修改文件、执行命令、检索资料等 |
| 宿主有待处理的提问或确认 | 待确认 |
| 已结束且选中范围有输出文件 | 查看成果 |
| 已结束且选中范围没有输出文件 | 概览 |
| 轮次结束事件明确记录停止、中断或取消 | 已停止 |
| 轮次结束事件明确记录错误 | 执行出错 |

运行中的进度只取最新一轮自己写入的任务清单。浏览步骤、阅读历史或切换“全部轮次”不会把历史任务数量当作当前进度；新一轮没有任务清单时，不继承旧清单。查看历史时使用该轮的输出和结束原因。普通命令显示“执行命令”，不根据命令名称推断测试通过。

同一会话内的文字变化使用 `src/motion.js` 的约 280ms 内容过渡：小幅上下位移、淡入淡出、最多 1px 模糊和入口宽度过渡。快速反向从当前文字位置、透明度和宽度继续；最多保留两层不可交互、读屏忽略的退场文字，不积压动画。文字相同不重播，切换会话直接建立新状态。

页面隐藏、减少动态效果、强制颜色或插件卸载时收束并清理动画。静态状态没有常驻帧循环，保留原入口点击、悬停、面板固定和键盘焦点行为。

验证：`node --test test/summary-entry-status.test.mjs`；`node test/summary-entry-browser.mjs`。浏览器验证使用合成会话，不向真实聊天发送消息。
