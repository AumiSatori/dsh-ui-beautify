# 按钮背景样式

在「侧栏 → 按钮背景样式」选择：

- **默认**：恢复原有按钮背景和原有按钮玻璃选项。
- **轻量底板**：统一底板和背景反馈，不增加背景模糊。
- **轻玻璃分组**：左右工具区分别共享一层轻背景模糊，当前默认选用此项。

只调整背景填充、底板圆角、细边缘、阴影和悬停/按压反馈。鲸鱼 LOGO、原生 SVG/图片、文字、颜色、尺寸、排版及按钮内部的动效全部保留，不插入替代图标，不隐藏原有内容，不修改按钮内的节点。

适配原生顶部工具区、侧栏、对话操作和输入栏中可识别的功能按钮；未知按钮及其他插件的自有面板不处理。原生事件、ARIA、快捷键、状态与弹层位置保留，可在设置中立即恢复。

## 材质和资源

左右分组各采用一层 8px CSS 背景模糊、细边框与轻阴影，不建立 WebGL 或 SVG 滤镜，不增加持续帧循环。输入栏已具有自己的材质，不对每个按钮再加一层模糊。启用底板样式期间释放旧小按钮的 Lens 绘制，保留该选项的偏好，切回「默认」后恢复。昼夜按钮完整保留原有的玻璃胶囊、太阳/月亮、云朵/星星以及切换动效，不套用通用按钮样式。其原有动画与滤镜仍有各自的资源开销。

侧栏开合、菜单、流式更新和会话切换不重建图标树。卸载或恢复默认会清理共享材质、样式标记和观察器。减少动态效果取消底板过渡；强制颜色和减少透明度时停用模糊，使用可辨的系统色或实色表面。

动态背景仍需合成共享模糊，开销随设备、背景和面积变化。隔离对比仅用于发现明显退化，不能冒充实际桌面 GPU/CPU 百分比。

## 验证

运行 `npm run test:unified-icons`。测试使用安装版 DSH 的原生布局与侧栏组件，内容和草稿均为演示数据。设置 `DSH_ASAR` 指向已安装的 `app.asar`，可用 `DSH_CLAUDE_OUTPUT_DIR` 将截图和记录输出到集合目录 `.scratch/`。设置 `DSH_ICON_BENCHMARK=1` 时，模块测试额外进行原生、轻量、玻璃三种样式的交替动态背景测量。


## 顶部工具与兼容性

右上新增“打开设置”，优先调用宿主原生 settings.open 命令进入 DSH 设置；旧宿主未提供该入口时回退原有账号菜单，三种按钮背景模式均可使用。新会话利用宿主 conversation.header.leading 插槽显示原有主题、专注按钮和设置入口；已有会话继续使用原来的工具插槽。

收起时，侧栏与新会话两个小按钮下移到页头工具行，与右上工具对齐，并使用同样的轻玻璃底板。展开时，收放按钮位于原有鲸鱼 LOGO 的右端，新会话恢复下方原生整行按钮。保留原生 SVG、鲸鱼 LOGO、文字、快捷键和事件。共享玻璃底板仅在收起时显示，放在同一个侧栏根节点内、原按钮下方，避免 body 浮层遮住图标。全屏继续沿用原有全屏工具布局。顶部与正文之间的分割线加粗为 2px，颜色读取宿主明暗主题。

启用“侧栏覆盖主屏幕”时，在页面启动且原生侧栏就绪后收起一次；初始已经收起也视为完成，后续手动展开与切换会话不会触发再次自动收起。
