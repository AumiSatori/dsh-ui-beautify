# DeepSeek 会话与上下文粒子背景预览

独立离线 HTML 原型。模拟上下文占用，粒子数量与人物聚合程度连续变化；不连接 DSH，不改插件设置。

默认是 DeepSeek 风格的会话页面：左侧模拟历史会话、右侧正文、深度思考折叠区、底部输入框。右上角明确区分「黑色 / 白色」，两套主题分别使用深灰和纯白背景；粒子颜色跟随主题平滑过渡。链接加 `?theme=light` 可直接进入白色主题，默认或 `?theme=dark` 进入黑色主题。

侧栏支持展开/收起、切换示例、开启新对话；输入框支持 Enter 发送、Shift+Enter 换行，只在本页展示模拟回答。深度思考和联网搜索按钮只模拟选中状态，不请求模型或搜索服务。窄窗口自动收起侧栏，背景固定，正文单独滚动。

页面结构、样式和交互分别在 `shell.html`、`shell.css`、`shell.js`，`preview.html` 保留粒子渲染器；构建时全部内联。

从参考立绘提取点云，在一个 WebGL2 画布中绘制；白底只去除与图像边缘连通的浅色区域，保留围裙和蕾丝。WebGL2 不可用或上下文丢失时使用低粒子数 Canvas 2D 回退。后台暂停，尊重系统减少动态效果，支持暂停、占用拖动/键盘、演示、压缩、主题、粒子质量与对话视图。

默认「轻量 + 80%」，约 5300 颗粒子；轻量档上限 6400、标准档 8000、细腻档 10000，实际数量受图形采样点数限制，Canvas 2D 回退上限仍为 4500。0 / 5 / 10 / 20% 约为 112 / 539 / 910 / 1600 颗，数量持续增长但保持疏朗，后半段逐渐聚合；不再采用高数量、前段陡增的曲线。

粒子从人物四周不规则厚度的椭圆外围生成，沿不同的弯曲路径向各自的形象采样位置汇入；取消均匀矩形自由点阵。占用固定时，尚未归位的粒子仍缓慢流入，循环起止通过透明度渐隐消除跳变。四周只有少量环境微光，正文中央在低占用时保持留白。GPU 和 Canvas 2D 使用相同的外围区域、路径和淡入淡出规则。

会话视图中，人物按会话区域水平居中，完整身体落在输入框上方。修正 WebGL 透明画布的预乘颜色与独立 Alpha 混合，防止浏览器合成时重复压暗。50–100% 连续融入同一素材的去底细节层，同时淡出颗粒，100% 呈现完整立绘或 SVG；原始颜色和白色围裙保留。细节层与粒子在同一画布内合成，仅在素材切换时上传一次纹理，不创建逐粒 DOM。会话背景保持适当透明度；纯背景视图达到 100% 时使用完整原色。

底部「导入 SVG」选择本地文件，或直接把 SVG 拖到页面；支持静态路径、填充、描边、渐变、透明度、内部引用及基础文字。按透明像素提取图形，不对白色图形去底；宽幅和纵向图形按可用区域等比适配。导入时保留占用比例并交叉淡入淡出，点「鲸鱼娘」恢复内置立绘。自定义 SVG 仅在本页内存中使用，刷新回到鲸鱼娘，不修改原文件。

SVG 限 2 MB / 25000 节点。脚本、事件、外链资源、嵌入 HTML 与动画不进入渲染；空白或解析失败时保留原图形。复杂滤镜与外部字体不支持，建议使用透明背景并将文字转为路径。

```powershell
node prototypes/context-particles/build.mjs <参考立绘.jpg> <输出HTML路径>
node prototypes/context-particles/check.mjs <输出HTML路径> <截图目录>
node prototypes/context-particles/check-svg.mjs <输出HTML路径> <截图目录>
node prototypes/context-particles/check-shell.mjs <输出HTML路径> <截图目录>
node prototypes/context-particles/check-refinement.mjs <输出HTML路径> <截图目录>
```

构建时把参考图嵌入单个 HTML，不依赖网络、服务或相邻图片。预览中的占用百分比和消息都是演示数据，粒子上限与帧率读数不代表 DSH 长对话的性能验收。

SVG 回归检查 0/10/20/30/40% 的实际可见像素变化、静态 SVG 导入与真实淡入淡出中间帧、宽幅细描边、无效文件保留、外链清理和恢复鲸鱼娘。

会话页面回归检查黑白主题截图、正文与控制区不重叠、思考区真实高度/模糊中间帧、历史会话与输入模拟、侧栏恢复，以及 1000 / 760 / 430 / 390 像素宽度的可用边界。截图只验收独立预览，不替代 DSH 宿主验收。

还原回归在真实会话布局下分别抽黑白主题的 0 / 5 / 10 / 20 / 40 / 60 / 80 / 100% 截图；用隔离界面后的画布像素检查前 20% 可见变化，断言默认轻量/80% 的数量、四周均有来向、低占用中央没有铺满、固定占用仍在移动，以及人物居中且没有被输入框裁切。另用已知颜色 SVG 验证实际页面合成颜色符合一次 Alpha 混合，纯背景 100% 保持原色。
